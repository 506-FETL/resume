## 视觉与数据验收

- 对照原稿两页，核对单栏白纸、蓝色章节细线、浅灰圆角经历栏、右侧日期、右上头像、紧凑正文、蓝色技术小标题、代码底色和技能边框段落。
- 原稿专有系统字体以自托管 Tinos Latin / 思源黑体组合替代，字形存在区别。企业 logo 使用语义图标；原稿手工续页标题不固化，正文随实际内容自动分页。
- 示例两页，真实导出后生成首页预览。原稿真实姓名、联系方式及经历未写入公开示例。
- 新头像字节一致；照片删除、重新添加、政治面貌和新增自定义字段显示正常。
- 元信息全部为空时不保留孤立人物图标；仅有工作年限或仅有元信息时仍可正确显示。
- 教育模块隐藏、项目与实习重排、字号/行高/页边距/主题修改通过。
- 富文本嵌套文字保留，用户内联颜色优先于模板元素样式；字段主投影唯一，富文本评论块数量不变。

## PDF 回归

通过编辑器“导出简历 → 导出 PDF”入口执行打印前字体、照片、分页和副本签名检查，然后以真实打印文档输出 PDF。未绕过或放宽签名验证。

| 模板 | 短内容     | 页底临界内容 | 多页长内容  |
| ---- | ---------- | ------------ | ----------- |
| 阿酥 | 1 页，2 段 | 1 页，42 段  | 3 页，72 段 |
| 默认 | 1 页，2 段 | 1 页，43 段  | 3 页，72 段 |

每种情况分别关闭、开启背景图形，共 12 份 Chrome PDF。检查唯一标记、完整段落、字形边界与页数，均通过；背景开关的逐页栅格比较通过。虚构示例另检查两种背景输出并人工查看两页。无缺字、重复正文、越界字符或空白末页。

WebKit 26.4 另外从云端加载新模板，验证 Tinos 字体、富文本样式、评论投影及真实打印入口的布局签名，通过两页打印文档准备检查。WebKit 检查不等同于已生成系统打印 PDF；最终 PDF 文件验收使用 Chrome。

## 云端实际入口

使用隔离浏览器上下文和公开模板 API，未伪造模板响应：列表首页缩略图、完整预览、点击“使用此模板”创建本地简历、刷新恢复均通过。通过工具栏先更换为默认模板，再更换为阿酥，点击当前提示的撤销按钮恢复；每一步均比对简历正文、照片、顺序、显隐与外观设置保持一致。

一次云端请求超时通过页面重试恢复；未更改产品请求超时设置。测试仅创建隔离上下文中的本地简历，不改已有用户简历。
