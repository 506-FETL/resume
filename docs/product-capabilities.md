# GResume 产品能力

本文记录 GResume 已实现的主要产品能力与使用边界。README 负责帮助第一次访问仓库的人快速理解项目，这里承接需要进一步了解的功能细节。

## 简历创作

### 模块化编辑器

简历内容按基本信息、求职意向、教育、工作、实习、校园、项目、技能、证书、自我评价等模块组织。用户可以调整模块顺序和显示状态，并在编辑时实时查看最终排版。

富文本区域基于 Tiptap，支持常用文本格式、列表与图片。简历内容和模板配置分离，同一份内容可以切换不同模板而无需重新录入。

### 模板中心

模板中心包含官方、社区和个人模板。内置模板覆盖通用单栏、紧凑排版、侧栏布局、ATS 友好布局等场景，也可以复制后调整：

- 布局骨架与内容区域；
- 模块顺序、可见性和展示样式；
- 字体、颜色、间距、密度与圆角；
- 模板名称、说明、公开范围和发布状态。

### 导出

简历支持 PDF 和 Word 导出。预览、打印和分享页面复用同一套模板运行时，尽量避免不同交付方式产生排版差异。

## 岗位定制与 AI 优化

### ATS 分析

AI 从 ATS 解析度、格式可读性、内容完整度、影响力量化和职位匹配度五个维度分析简历。问题会定位到具体字段，并给出文本替换、字段补充、日期规范化或内容增强建议。

### 划词改写

在支持的富文本字段中选中内容后，可以生成 2–3 个候选版本。改写方向包括 STAR 化、量化、强动词、语言润色和 JD 关键词靠拢。候选内容会先经过 HTML 安全处理，只有用户确认后才写回原选区。

### JD 派生简历

粘贴目标岗位描述后，系统会解析岗位关键词，并从源简历创建独立草稿。派生任务只改写允许优化的描述性字段，同时保留：

- 源简历与派生简历的血缘关系；
- 改写前后内容、命中关键词和修改理由；
- 任务进度、取消、重试与丢弃状态；
- 原始简历、派生版本和多层派生的筛选能力。

原始简历不会因派生任务被直接覆盖。

## 版本、分享与协作

### 历史版本

每份简历拥有独立的版本时间线。用户可以预览快照、对比两个版本，并恢复到指定历史状态。版本还可以关联对应的求职岗位，帮助解释某次修改发生的背景。

### 按版本分享

云端简历可以创建多个独立的只读链接。创建或更新链接时，可以选择当前内容或指定历史版本：

- 分享内容固化为快照，后续编辑不会自动改变已发布内容；
- 链接可以独立命名、设置有效期、启停或删除；
- 可以设置、修改或移除访问密码；
- 管理页展示查看次数和最后访问时间；
- 查看者可以按分享快照的模板下载 PDF。

离线简历需要先同步到云端，才能生成外部可访问的分享链接。

### 实时多人协作

结构化简历文档通过 Automerge CRDT 合并并发修改，富文本字段通过 Yjs 进行字符级协同。Supabase Realtime 负责实时消息传递，本地 IndexedDB 保留离线数据。编辑器可显示协作者光标，并按登录身份稳定去重。

## AI 求职助手

AI 助手以独立工作区呈现，支持持久化会话、流式响应、Function Calling 和历史正文搜索。它可以读取：

- 当前用户资料、时间与会话上下文；
- 简历正文、版本历史和派生血缘；
- ATS 分析结果与模板信息；
- 求职看板中的岗位和进展。

涉及简历或岗位修改时，助手会先展示确认卡。只有用户明确确认，变更才会通过既有 Store 或 Supabase 数据层执行；取消任务、切换会话或离开页面会停止未完成操作。

当前版本不宣称支持联网搜索或图片理解。

## 求职追踪与 CRM

求职看板提供看板和列表两种视图，覆盖已保存、已投递、筛选中、面试中、已录用和已终止状态。岗位记录可以包含：

- 公司、职位、城市、薪资、岗位描述和来源链接；
- 申请日期、当前状态和多轮面试子阶段；
- recruiter、内推人等联系人及沟通备注；
- 自动状态变更记录与手动备注、面试、跟进事件；
- 下一步动作和到期日期；
- 归档状态与批量管理操作。

Dashboard 聚合已投递、面试、Offer、平均 ATS 分、待跟进岗位、求职漏斗、ATS 趋势和本周活跃度，帮助用户决定今天应该推进什么。

## 离线与云端

未登录用户可以在浏览器中创建和编辑离线简历。登录后可以把本地简历同步到 Supabase，并在多个设备之间继续使用。

能力边界如下：

| 能力                 | 离线模式  | 云端模式             |
| -------------------- | --------- | -------------------- |
| 简历编辑与模板预览   | 支持      | 支持                 |
| 本地持久化           | IndexedDB | IndexedDB + Supabase |
| ATS 与 AI 改写       | 不支持    | 支持，需要模型代理   |
| 历史版本与多设备同步 | 不支持    | 支持                 |
| 实时协作             | 不支持    | 支持                 |
| 外部只读分享         | 不支持    | 支持                 |
| 求职看板与 CRM       | 不支持    | 支持                 |
