## 性能观测

当前两套模板冷加载共 6 个请求：目录、筛选选项各 1 次，定义／示例各 2 次。原始 JSON 总计 12,438 字节，其中目录与筛选约 1.2KB。打开已加载预览、创建及刷新编辑器新增模板请求均为 0。

一次真实线上浏览器观测中，资源请求耗时约 682～1473ms，开发环境冷页面到两个完整预览就绪约 5.6 秒（包括前端与字体加载）。暖缓存刷新到两个预览就绪约 970ms，模板请求 0 次。这些是当前本机网络和 Vite 开发环境的观测，不是生产 SLA，也不把本地 SQL 耗时当作公网速度。

列表按页读取和视口加载限制未来目录增长带来的请求／渲染成本；首次访问仍受 Supabase 所在地区和字体加载影响。需要进一步降低公网首次加载延迟时，可在现有 transport 外增加公共缓存层，并用指定版本的静态预览替代列表实时排版。
