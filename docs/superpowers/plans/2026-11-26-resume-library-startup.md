# 我的简历加载优化实现计划

1. 保存旧生产构建，解析用户录制。分别记录简历摘要、统计、预览正文与外壳请求，对照浏览器帧核查头部重播。
2. 修改简历库路由启动、页面和骨架。共用一次账户确认后的读取，保持页头和搜索常驻；淡入只作用于更新的内容。审查关闭的对话框、额度和整库状态订阅。
3. 修正列表 store 和离线、云端读取。分别交付有序混合条目和计数，保留深页边界、错误重试、来源隔离、写后更新和缓存。
4. 检查每行卡片、模板名与预览。可见性触发目标读取，交互实现按需加载；保持键盘、重复打开、取消和只读预览行为。
5. 用同一浏览器、相同延迟与样本复测新旧生产包。检查慢分包、空态、失败、翻页、账户及真实交互，运行格式、类型与构建检查，清理临时样本，将结果交用户审查。
