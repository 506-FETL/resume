# 新增 50 套模板实施计划

**目标：** 在已有十二套基础上新增五十套独立样式，发布到当前链接 Supabase 项目并完成真实 PDF 验收。

**架构：** 复用云端声明式模板、公共 A4 分区分页器、现有示例与正式打印入口。规格见 `../specs/2026-10-23-qm-hot-fifty-templates-design.md`。

**执行：** 当前分支、不提交或推送、不建立新的根目录资源库。选型、验收工具和分组资源制作按明确的文件边界分派；集成与发布由主代理负责。先完成可审查的资源与验证，再执行已获授权的发布。

## 全局约束

- 新增恰好五十套，不以翻译、换色或同版式不同职位凑数；保留原有十二套。
- 定义版本 1，协议 schemaVersion 3 / declarative-page@1，前端无模板 ID 分支。
- 每套两个示例、两张精确生成的预览；不得复制参考站个人资料或把整页图片当正文。
- 不放宽分页稳定性检查；测量、展示、打印字体和几何一致。
- 执行期间测试和验收工具放 tests/resume-template-fifty；大型生成物由输出目录参数写入临时目录。按后续更新的 AGENTS.md，验收完成后删除本次新增测试目录，工具随证据归档到临时目录。
- 不修改用户已有简历、登录状态或用户正在使用的浏览器数据；浏览器验收使用隔离上下文。
