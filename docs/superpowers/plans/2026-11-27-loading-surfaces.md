# 加载反馈与档案表单修正计划

1. 审查路由、浮层、工具、菜单、列表和预览的加载分支。保留与实际内容对应的首读占位；从共享分包组件移除默认假表单和临时 Dialog。
2. 手机侧栏使用已有的 MobileSidebar，分享管理使用 ShareDrawer，职业档案使用 ResponsiveDialog。聚焦或指针移入入口时提前准备分包；点击后只挂载最终面板。保持表单的禁用、退出、回焦及账号隔离。
3. 职业档案两个页签共用内容区，两种输入方式切换时标题、页签和操作栏保持原位。桌面优先横排文件操作，手机保留适合触摸的入口。
4. 从实际页面验证冷开、慢分包、失败重试、两轮开合、关闭中重开、窄屏长队列与减少动效。记录工程检查和用户审查状态。
