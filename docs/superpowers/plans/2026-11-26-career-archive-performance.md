# 职业档案性能优化计划

1. 保留修改前的生产构建，解析开发录制中的业务请求、绘制候选和长任务。分别记录首页列表、外壳、详情与上传的静态依赖。
2. 在 `src/main.tsx`、路由入口和职业档案页面按账户和导航目标启动实际需要的请求。复用现有页面骨架和在途请求，延迟上传与阅读模块。
3. 在职业档案页面和共享资料 store 核查查询、分页、选择、原件读取及写后失效。针对重命名、未知上传结果和批量操作，保留幂等与权限检查，并检查真实网络次数。
4. 在旧、新生产包比较首卡和可操作时间。复核列表失败、深链、搜索、原件与真实保存，运行类型、格式和构建检查，清理本轮测试数据并交用户审查。

实施完成，本地验证通过，Edge 修复已发布并通过线上核验。前端等待用户审查。详见[验收记录](../specs/2026-11-26-career-archive-performance-acceptance.md)。
