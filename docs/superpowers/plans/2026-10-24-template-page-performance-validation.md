## 浏览器测量方法

使用同一台机器、同一内嵌浏览器、1280 × 720 视口及相同网络。修改前保存生产构建副本，修改后使用最终生产构建；临时本地服务器仅注入测量面板，不进入交付代码。以导航起点计时，100ms 采样真实图片完成与解码后的展示状态。首屏目录 12 条，其中 2 张可见、6 张进入预加载范围。

测量使用不同本地端口隔离应用的 IndexedDB/状态。**不同端口不保证隔离浏览器 HTTP 图片缓存**：优化后第一轮为本次浏览器首次访问这些 CDN 图片，后两轮可以复用同站点的图片缓存，因此单独报告，不混合计算冷缓存均值。CDN 在同步校验后已被预热。修改前第 2、3 轮标签页曾接近同时打开；数据为小样本现场结果，不能据此承诺所有网络环境的提升比例。

| 修改前第 1 轮 | 2127.9ms | 3823.7ms | 4722.8ms |

首屏数据库业务 API 从 8 次减为 2 次；首次总 GET 数仍为 8，另外 6 次变成可缓存的普通图片请求。不能把这个结果表述为“所有网络请求减少 75%”。新图片请求不携带 API 自定义认证头。当前浏览器接口没有导出 OPTIONS 的能力，Resource Timing 也不能完整统计预检，因此本次不提供 OPTIONS 实测数量。

跨域响应没有提供可用的 Timing-Allow-Origin，浏览器的 transferSize/encodedBodySize 为 0，不表示实际零流量。另用 Node HTTPS、Accept-Encoding: gzip, br 对同一组 6 张图测量响应正文：旧 Base64 JSON gzip 后合计 **1,191,965 字节**，新 PNG 合计 **1,183,678 字节**，下降约 **0.70%**。这组字节来自独立 HTTP 探测，不是浏览器流量统计；不包含请求头、响应头和预检。全部图片响应为 `image/png`、`Cache-Control: public, max-age=31536000`、`cf-cache-status: HIT`。收益主要来自消除素材数据库查询、并发图片交付和缓存复用，而非图片体积优化。
