# 求职跟进性能实施计划

1. 固化当前生产包，对照既有跟进业务验收，记录桌面及窄屏首访、筛选、详情和写入。
2. 在岗位查询与页面 store 中拆分首批摘要、范围统计、按需翻页及目标详情，保留完整范围操作和账户隔离。验证云端授权与旧调用方。
3. 在路由入口并行准备首屏视图和数据。拆分看板、列表和操作面板，检查慢分包、重复操作、焦点恢复及错误重试。
4. 复核新增、绑定、跟进和投递的候选、写入及缓存，核对实际保存后的请求。按屏幕展示需要分批挂载条目，核验滚动、排序、全选和拖动。
5. 复测生产构建，执行格式、类型和构建检查。部署并核验本期数据库变更，清理临时数据，分别记录实施状态、技术验收和用户审查状态。
