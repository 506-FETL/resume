# AI 助手性能优化实施计划

目标是让已恢复的对话尽早可读，减少画布、历史和输入菜单的无效查询。沿用 React、Zustand、Supabase 与现有消息滚动组件。

- 提取录制中的已登录导航、业务请求、LCP 元素与布局偏移，保存现有生产产物，建立隔离浏览器对照。
- 在助手路由、会话读取与侧栏实现提前启动、分页和在途复用。回归空白对话、快速切换、读取失败、搜索和写入后的列表。
- 沿实际选择逻辑裁剪画布查询，验证当前目标、缺失回退、关闭和重新打开。把无关的重模块移出首开依赖。
- 调整输入引用、出处核验与流式渲染，分别核实加载菜单、历史附件、账户变化和未打开入口的请求。
- 运行格式、类型、构建与同机新旧浏览器验收，再检查请求、布局与关键路径。记录测量条件，清理临时数据并交用户审查。
