## 导出与分页修正

编辑器短内容实际触发 PDF 打印，回调在原字体及布局签名校验后执行，保存为一页 PDF。历史页全模块样本实际点击导出，捕获校验通过的打印 iframe，再由 Chromium 保存为两页 A4 PDF。

首次检查发现原分页可以从标签文字底部断开，将边框留到下一页。新增标题／标签的 `data-pagination-atomic`，分页排除原子元素内部候选点，并把边框底部纳入内容高度。复测原子元素内部断点为 0，两页 PDF 边框完整；第二页无上一页半圈边框，末尾“摄影／旅行／跑步”完整。默认未分页几何仍与基线一致；没有放宽字体或布局签名门禁。

使用 pdfinfo 确认两页 A4、pdftotext 检查逐页文本，并栅格化两页目视检查。证据在 `.superpowers/template-baseline/history-multipage.pdf` 与相关截图。

Word 从实际编辑器下载为现有 HTML `.doc`，不是图片或 DOCX；系统 textutil 能解析姓名、联系方式、教育、工作、项目、技能、自我评价。Microsoft Word 要求激活／登录，未完成原生编辑；Pages 打开流程也没有成功证据，因此不宣称兼容编辑器验收通过。

## 未通过或未覆盖的验收

1. **本地协议 v1**：协作者在原有 open_automerge_peer lease 鉴权处返回 403；协议 v2 的普通字段和富文本同步通过。未修改协作服务或绕过权限。延长会话后的经历增删／排序／隐藏、重连矩阵没有完成，不能声称全部协作场景通过。
2. **匿名评论**：匿名分享读取通过；本地 gateway 注入的旧 anon JWT 与既有鉴权要求不一致，评论 bootstrap 返回 401。已登录评论新增／回复／解决通过，匿名评论没有在此环境通过。
3. **Word 原生编辑**：受本机应用激活状态限制，只有实际下载及文本解析证据，没有 Word 内编辑保存证据。
4. **扩展矩阵**：未穷尽分享过期、账号切换、多页跨块评论在各种字体／缩放下的几何、跟进和 AI 画布的完整操作。这些入口已迁移或继续使用公共预览、显式快照外观及既有权限路径；源码核对不等于交互验收。

这些限制不能通过默认回退、切换存储、删除权限或重建文档绕过。生产发布前应在目标鉴权配置和可用 Word 环境补齐相应矩阵。

## 实现差异与维护

- schema.ts 成为新协议出口；无人使用的旧 runtime barrel 删除，消费者直接引用 resolver。
- 小型目录加载 effect 保留在页面，只拆出实际需要的示例与创建 hooks，没有增加空壳 hook。
- 教育／工作／实习复用统一经历部件；不为业务模块分别复制视觉实现。
- 历史预览及历史 PDF 补传既有 projection_reference_date，保持冻结时的年龄和评论投影。
- source/index.ts 是唯一数据源装配入口；缓存、创建、分享、AI 列举共用，远端实现尚未开发。
- 标签边缘的分页断点有意修正；未分页样式、正文及评论身份不变。

后续新增模板、版本更新、下架、回滚和远端迁移的步骤见 `docs/resume-template-maintenance.md`。
