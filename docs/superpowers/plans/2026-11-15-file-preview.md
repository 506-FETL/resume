# 常用文件预览实施计划

**目标：** 使用成熟库完成职业档案及助手引用中的原件预览，补齐图片和表格的上传链路。

**依据：** `docs/superpowers/specs/2026-11-15-file-preview-design.md`，当前用户已授权实施，沿用当前分支。

1. 固定 docx-preview、SheetJS 官方包和 react-photo-view 版本；新增类型注册与受限预览容器，复用现有缓存、错误和下载入口。
2. 接 DOCX 渲染、图片手势查看；接 SheetJS Worker 的读取、文字提取和分段表格预览，保留真实数字格式/工作表名。
3. 扩展上传 accept、共享类型、Edge 格式校验及数据库约束；完善图片无文字状态和 AI 按需读取语义。
4. 更新类型图标、文案、详情与助手引用查看；所有新预览按需加载，旧 PDF/文本链路回归。
5. 在 `tests/file-preview/` 放临时样例及验收脚本，验证真实库、实际页面、权限、缓存、移动端和加载失败。执行改动文件格式、类型与生产构建检查。
6. 隔离验证 SQL 后部署 linked Supabase 迁移和 experience-sources，核对迁移账本/版本/线上 smoke。删除测试数据、脚本和临时服务；写验收证据与防回归约束。

组件检索结果见设计文档。数据解析和文件格式渲染交给库，项目仅组合工具条、生命周期、权限及分页。不要重写 Office 引擎，不调用在线 Office viewer。

状态：实施完成；验证完成；云端迁移与函数部署完成；用户验收待进行。详见 [验收记录](../specs/2026-11-15-file-preview-acceptance.md)。前端尚未发布。
