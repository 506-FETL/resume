# 文件预览性能修复计划

依据：`../specs/2026-11-16-file-preview-performance-design.md`。不新增运行时依赖。

- [x] 保存旧组件，建立同机、同 PDF 的基线时间线。
- [x] 详情读取、原件下载、viewer 准备并行，保持已知版本与账户隔离。
- [x] PDF 首屏有限复用，保留按页渲染、销毁 worker 和失败重试。
- [x] 拆分所属资料详情、上传对话框和全局资料 store，每个源码不超过 400 行。
- [x] 验证首屏、重复打开、翻页、失败重试、换版本/账户；记录测量边界。
- [x] 类型、格式、构建与本期整体验收，删除临时脚本，交用户审查。
