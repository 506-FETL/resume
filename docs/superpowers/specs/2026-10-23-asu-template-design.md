# 阿酥模版设计

沿用用户已批准的远端声明式模板架构及直接实施流程。用户要求依据提供的两页 PDF 新增“阿酥模版”，换用 avatar.jpeg；已确认云端示例使用虚构内容，不上传原简历姓名、联系方式和真实经历。

## 视觉要求

- 单栏 A4，白纸，左右约 42 CSS px，原稿正文宽约 710px。
- 姓名左上约 30.7px，求职方向在下一行；联系方式、元信息分组显示，带深灰图标，自定义字段随可用宽度换行。新头像置于右上，不将示例头像写死在模板里。
- 标题约 21.6px，主色 `#2458b8`，底部 1px 蓝线；姓名及经历标题深黑，正文深灰。
- 学校、公司、项目标题使用浅灰 `#f2f4f7` 圆角横条，图标在左，标题与角色相邻，日期右对齐。
- 正文约 13.6px、1.4 倍行高；蓝色小标题、紧凑项目符号、浅灰行内代码；技能与工程实践为细边框段落卡片。
- 原稿中文为黑体、英文为 Times。使用可自托管的 Tinos 与现有思源黑体混排，避免依赖访问设备的系统字体；字形与原 PDF 的专有字体存在区别。
- 内容继续使用语义字段和公共自动分页。参考稿中的真实公司 logo、手工续页标题和硬编码页码不写进通用模板；相应位置采用语义图标，分页随用户正文变化。

## 资源和边界

模板 ID `asu`、版本 1、名称“阿酥模版”、风格“简约”、布局“单栏”。独立示例 `asu-fullstack@1` 使用相近层次和篇幅的虚构教育、实习、项目及技能内容，头像原样读取用户 JPEG，通过现有照片 schema 保存。

云端保留不可变定义、独立示例、目录及真实静态预览。测试和发布输入放在临时目录，不恢复 template-resources，不改已有模板版本或已有用户简历。应用入口仍可更换模板并保留个人外观和照片。

## 公共能力

增加 `tinos` 字体选项，配套字体加载与打印等待；保持所有原有字体默认值。

声明式 richText 节点可选受控 `elementStyles` 字典：仅允许段落、标题、列表、强调、代码与链接等固定 HTML 标签，值为定义内样式 ID，需声明 `rich-text-styles` 能力。复用现有样式白名单和颜色 token；无任意 CSS 选择器、脚本或外部 URL。解析后的样式应用于净化后的富文本元素，保留用户已有内联样式及评论块身份；测量、显示、打印和简化 Word 共用同一 DOM。

## 验收与发布

先在隔离浏览器中装载候选资源，检查页头、头像、标题、经历条和富文本。验证照片替换/删除、字段编辑、隐藏和重排、切换已有简历保留内容、外观设置有效。

阿酥与默认模板均通过真实 PDF 导出入口，覆盖短内容、单页临界内容和多页长内容，背景关闭/开启分别输出，检查字段次数、全文、照片、正文边界和逐页图像。示例另生成整份 PDF 与首页缩略图。类型检查、ESLint、构建和协议校验通过后，以事务发布示例、定义和目录，并从匿名 API 回读哈希、从真实模板入口创建与导出。若无数据库或函数代码变更，不做额外迁移和函数部署。
