## 2. 方案比较

| 方案                          | 优点与取舍                                                                             |
| ----------------------------- | -------------------------------------------------------------------------------------- |
| 资料卡片库 + 按需阅读（采用） | 大部分空间用于查找材料；正文摘录帮助识别文件；少量和十项分页都自然；手机可直接单列。   |

## 3. 页面结构

### 资料库首页

- 页面标题“经历资料”，说明“保存周报、项目记录和旧简历，写简历时随时取用。”；右侧沿用上传资料与粘贴文字的真实动作。
- 通栏工具区：全部/文件/文字筛选；搜索资料名称；网格和列表切换。手机拆成上下两行，搜索获得完整可用宽度。切换有读屏名称、aria-pressed 与键盘焦点。
- 工具区下显示当前真实筛选总数及“最近更新”。不新造排序入口、文件夹、收藏或伪造计数。
- 默认网格，卡片以格式图标、最多两行名称、真实摘录、更新时间组成。卡片整体可通过键盘打开；按钮和文本不嵌套交互控件。PDF/DOCX/TXT/MD/粘贴的类型有小面积区别，状态异常显示真实提示。
- 桌面根据容器宽度排列 2–3 列；窄屏单列。卡片内字号和间距统一，正文摘录固定最多三行，长标题和超长连续文本不会撑宽。卡片宽度由网格决定，图标等局部尺度固定。
- 紧凑列表保留同一批数据、筛选、分页与点击能力。每页仍最多十项，切换视图不重新请求。分页计数来自后端 total；回页复用现有缓存。
- 初次进入不自动选中第一份资料，不请求正文。新上传完成关闭弹层后在资料库显示对应新资料；只有用户打开或外部来源定位才进入阅读。
- 初始空态给出明确上传/粘贴入口与可保存材料说明；筛选无结果提示清除筛选；加载展示与网格/列表对应的骨架；失败保留已有资料并提供局部重试。

### 阅读视图

- 点击资料在同一页面进入独立阅读视图，所有宽度都采用同一导航逻辑。顶部返回资料库、资料类型和使用/管理动作；正文使用约 65 字符行宽的阅读区域，不保留左侧常驻资料列表。
- 标题最大两到三行的合理字号，元信息位于标题附近次级位置，完整标题可读取。原文由现有 ExperienceSourceReader 分段加载；保留指定旧版本和段落定位、下载、重命名、更新、关联简历、删除及失败恢复。
- 页内导航状态由 Zustand 保存；关闭阅读保留搜索、类型、分页、视图与列表滚动位置，焦点回到原资料卡片/列表项。目标已删除时回资料库上传按钮。外部 URL 指定 sourceId/versionId/blockId 时直接进入精确阅读。
- 上传新版本的旧回调不能切走用户当前选中的别份资料；A→B→A 的选择代次检查保留。账户切换清页面状态，旧请求不回写。

## 4. 组件与代码边界

不新增依赖。复用已有 shadcn Card、Item、Button、ButtonGroup、Tabs、InputGroup、DropdownMenu、Empty、Skeleton、Spinner、ResponsiveDialog、AlertDialog 及公共经历组件；无需自建 Sheet。完整阅读采用页内导航，避免给已有重命名/删除/更新弹层增加一层模态嵌套。

将原单个约 780 行 workspace 拆成资料库、工具栏、卡片/行、阅读页与原文管理内容。跨组件 query/filter/offset/view/selection/navigation/upload 状态提升到页面 store；确认框输入和忙碌状态保留在自身组件。保持 `components/`、`hooks/`、`const.ts`、`index.tsx`、`store.ts`、`types.ts`、`utils.ts` 的现有页面结构。

## 5. 动效、性能与验收

- 使用 transitions-dev 的页内切换思路，复用公共 CONTENT_SWITCH/DURATION/EASE。退出内容 inert、焦点先移到保留容器，进入后回到返回按钮或原资料项；两轮往返和退出中重开不出现两个可交互页面。
- 卡片首次进入最多前六项按 30ms 错峰；筛选/刷新复用内容不持续重播。悬停只做背景/边框反馈；不加倾斜、光斑、循环装饰或全页滚动劫持。减少动效运行中生效，手机保留短过渡。
- 列表与网格只用摘要元信息，阅读才取原文；切视图零业务请求。上传解析仍按需装载，资料页不自动调用 AI。
- 实际页面覆盖 1440/1024/768/390/320px、深浅色、长标题、十项分页、空/加载/失败、上传与粘贴、两种视图、往返保留、指定旧版本、删除当前项、账户切换、键盘和触屏。
- 验证真实已有动作没有丢失，重读页面文案；运行 Prettier、ESLint layout、TypeScript、构建及最终全项目格式检查。临时脚本和样本放 tests，最终删除。设计与实现验证完成后，再交用户审查。
