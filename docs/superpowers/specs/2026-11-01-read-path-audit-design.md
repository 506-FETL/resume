# 全站读取链路审计与优化

日期：2026-11-01。用户明确要求排查并修复 JD 同类读取问题，本期实施已授权，完成实现和验证后交用户审查。

## 目标与方案

减少无关字段、未使用历史正文、重复请求和无依赖的串行等待。按实际调用方收紧查询，在已有页面资源中复用结果和在途请求；写入、刷新与账户切换按已有规则失效。不引入全站通用缓存框架，不改变业务内容、授权、界面布局与模板精确绑定。

比较三种方案：仅删星号不能解决重挂载重复加载；全局长效缓存需要扩展全部写入失效协议；本次采用按调用场景的字段投影及局部资源复用，保留需要最新数据的读取。完整编辑、历史恢复、材料预览确实需要正文，不以裁掉正文或权限验证换取速度。

## 已确认的问题与修复边界

1. 求职详情：摘要、详情重挂载重复读取同一投递；更正历史在组件中丢失已完成结果；原件预览关闭后丢失结果及在途请求。统一放进已有投递 slice，按记录/历史版本、账户与投递 revision 复用。更正历史展开前不请求，展开后有独立加载、失败、空态。原件 Blob 只保留数据，object URL 仍由预览组件创建及释放。新修订和账户变化失效，旧响应不可回填。
2. 简历摘要：分享及岗位选择只需要 ID、名称和类型，却读取 JD、衍生过程和模板绑定并触发修复。为这些入口提供最小摘要；首页和其他只展示列表的本地读取复用已有摘要接口，完整正文留到预览或实际动作。精确核对各消费者，不能误删列表所需的派生状态、日期或模板标识。
3. 历史快照：预览、对比和导出并发读取同版本时只有结果缓存，没有在途复用；账户或简历变化后旧请求可能填回。共享 Promise 与当前账户/页面目标检查，失败清理后可重试。
4. 助手：岗位选择和统计使用完整岗位接口；上下文无关的资料、简历和岗位读取串行。按用途提供轻查询，独立资源并发启动，状态分别发布；工具过滤和数量限制尽量下推查询。画布重开复用数据，业务更新后失效。
5. 简历优化：初始化下载全部历史报告再选择每份简历的最新报告；分析正文读取带上无关布局、模板等。报告列表通过调用者权限视图按稳定顺序取每份最新一项，分页读取 ID、简历 ID、日期和分数四项摘要；首次并发取目标最新单份正文，后续按报告 ID 读取，正文分析投影仅保留实际需要模块。初始化合并在途请求，刷新和写入后读取最新数据，失败不当空数据。

## 审计补充与实现决定

- 首页最近预览复用简历库真实第一页成品；简历选项、历史说明更新与分享历史候选各自缩小投影，重入不重复排版。
- 普通简历列表与派生关系只展示 JD 前 80 字，新增 `resume_jd_excerpt(resume_config)` 安全调用者计算字段；模板与详情仍读全文。摘要字段使用 `linked_jd_excerpt`，不能冒充 `linked_jd_text`；再次定制在动作时读取完整 JD，覆盖父简历已删除的派生记录。
- 实测原全报告读取 2 行为 9421 字节、624ms，摘要 255 字节、562ms 加当前详情 4939 字节、575ms 的串行拆分会增加等待，故不采用串行冷载。新增 `latest_ats_reports` 调用者权限只读视图，保留基础表双归属 RLS 和日期/ID 稳定排序。冷载并行读取轻摘要与当前最新单份详情；首页历史分数和最新建议也独立并发。
- 首页历史趋势只取历史分数；建议待办只读取每份简历最新报告的 findings。无关 todo_items 和旧报告建议不下载。保持现有全部数量、最近八次趋势和旧格式建议兼容。
- 优化页自己的简历选择也使用轻摘要，避免从重的通用简历列表入口把 JD 与改写记录重新带回来。工具读取结果按正文更新时间复用；实际采用建议后明确失效，格式整理成功直接更新缓存正文。旧在途结果不能跨失效代次回填。
- 派生关系 Popover 与完整 Dialog 复用请求及结果；真实打开才读取，独立显示加载、失败和空状态，提供重试。账户或简历列表变更失效。
- 本地元信息和正文仍保存在同一 IndexedDB record。此次避免整份 hydrate、模板修复及把正文存入列表状态；不宣称物理磁盘正文读取为零，也不为这个任务迁移存储结构。

## 约束与验收

- 复用现有 shadcn、AnimatedContent、Collapsible 和公共动效；新出现的历史空态明确显示“暂无更正记录”。保持重复开关、键盘焦点和减少动效。
- 同账户并发相同资源只有一次请求，已完成资源重复展开零新增请求；修改后重取，失败可重试。切换账户 A→B→A 旧响应不能发布。
- 用真实数据读取代码和合成 HTTP 边界验证字段、请求数量、过滤和限制。真实线上 smoke 只读，不写用户数据、不调用付费模型、不打印正文或个人信息。
- 涉及数据库迁移时用 CLI 生成文件，隔离验证现有归属权限，再部署当前 linked 项目并核验账本和线上查询；无关表与函数不改。
- 临时脚本与夹具置于 tests/read-path-audit，完成后删除。执行改动文件 Prettier、ESLint layout、类型检查、构建及全项目格式检查。
- 审计记录列出已覆盖入口及确实需要完整读取的排除项；不把静态检查称为全部真实业务运行。
