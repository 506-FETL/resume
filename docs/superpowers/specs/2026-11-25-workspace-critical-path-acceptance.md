# 首页首开与预览优化验收

本轮覆盖侧栏首页 `/workspace`，对应[用户提供的开发模式录制](2026-11-25-workspace-load-trace-review.md)。前端代码已落地，验证通过，待用户审查。未发布前端；本轮没有数据库迁移或 Edge Function 变更。

## 已实现

- 选中首页后立即准备数据模块，SDK 确认账户后并发发起六项业务读取。初次身份恢复和组件使用同一认证订阅，各卡片直接消费自己的状态。页面挂载前完成或失败的请求均能交接，离开、重新进入和切换账户时按页面与账户生命周期处理。
- 第二轮生产复查发现，四项统计和云端简历卡先等待各自的查询分包。现将这些轻量函数随首页数据模块加载，SDK 在实际读取时共用。公共官网首开没有加载工作台外壳或简历生成器。
- 工作台外壳仍在加载时，首页展示真实的页面标题和结构骨架，沿用侧栏展开偏好。真实卡片、岗位提醒和待办可以在旧骨架退出时开始挂载。提醒骨架按一条可用内容的高度占位，两条真实提醒时允许卡片自然长高。星标区域预留宽度。
- 可见卡片直接向既有预览队列申请目标简历，正文读取与生成器下载并行。云端按账户、简历 ID 读取排版所需的 19 个字段。本地旧外观、旧模板绑定均可只读恢复。两份正文可以并发准备，重排版仍逐份执行，返回时复用同版本成品。

## 生产构建对照

Chrome 158.0.8127.89，无扩展，1200 × 1000，DPR 2。旧包取自本轮开始时的 HEAD。新旧均使用相同的两个官方示例、default v3 模板、一个收藏岗位和三个检测分数，真实执行 SDK 请求、React 渲染和第一页排版。首页接口、预览正文和官方模板分别注入固定 320、420、85 毫秒响应等待。每次清空浏览器上下文并禁用浏览器网络缓存，正常主机负载下交替测量各 5 次。以下为相对导航的中位数，单位为毫秒，CLS 除外。

| ------------------------------ | --------: | -------: |
| 首页 6 项请求中首项 / 末项发出 | 430 / 434 |  38 / 39 |
| 首页 6 项全部返回              |       757 |      362 |
| 首页标题出现                   |       390 |       77 |
| 可操作的岗位待办出现在可见帧   |       955 |      427 |
| 两张最近简历卡出现在可见帧     |       959 |      427 |
| 卡片响应到首份预览正文请求     |       545 |       73 |
| 两张预览均 ready               |     1,992 |    1,104 |
| 两张预览均在可见帧显示真实正文 |     2,009 |    1,121 |
| 图表挂载                       |     1,297 |      912 |
| LCP                            |       960 |      492 |
| CLS                            |  0.032794 | 0.000021 |

两张预览可见的五次范围分别为 1,955–2,021 毫秒和 1,104–1,138 毫秒。测量要求纸页存在、包含正文、布局有尺寸，且祖先累计不透明度至少为 0.1。LCP 的候选元素会变化，旧包三次记录真实提醒，分别为 960、1,148、960 毫秒，另外两次为加载文案；最终包五次均为同一真实提醒，范围为 456–496 毫秒。旧包有两次分别出现 51 和 52 毫秒长任务，最终包五轮未观察到超过 50 毫秒的任务，因此保留现有图表引擎、字体与真实模板渲染。

另一次主机高负载时独立测试了五对。旧包与最终包两张真实预览可见的中位数分别为 4,090、3,439 毫秒，两个构建均出现较长的主线程任务。该组 LCP 中位数为 592、892 毫秒，旧包三轮采到加载文案，另外两轮真实提醒为 1,592、1,668 毫秒，新包五轮同一提醒为 724–1,136 毫秒。未将该组与正常负载结果混算。以上耗时来自本机受控比较。

## 功能与数据核验

- 挂起工作台应用分包，6 个首页请求各发一次。恢复挂载后没有重复读取。ATS 接口延迟 1.7 秒时岗位待办先显示；首次 ATS 失败，点击重试只补该项。访客不发账户业务请求。账户 A→B→A，迟到的第一代 A 结果不能覆盖最新 A。
- 同版本回页重新读取 6 项首页数据、预览正文零次；只更新一张卡片的版本，仅该目标重读正文。离屏 1.5 秒无正文读取，滚入视口后才读取和生成。单份正文失败只重试该简历。准备期间离开视口，响应到达后不启动排版。
- 使用真实云端临时账户创建两份简历和一个收藏岗位。六项业务接口各读取一次，两份不同的正文各读取一次并使用 19 列投影，两张预览均 ready。读取前后两条简历的更新时间一致，未观察到页面异常。临时账户和数据已清理。
- 本地旧简历缺少模板绑定、外观字段时，真实 IndexedDB 数据可生成预览，未修改原记录。桌面慢外壳下标题位置在侧栏展开时为 (256, 88)，收起时为 (80, 88)，390 像素手机为 (16, 80)；外壳到达前后坐标一致。三个场景均通过两轮打开、关闭创建表单和焦点恢复；覆盖默认与减少动效。
- 两条到期跟进和两条重点关注的补充样本中，桌面提醒卡可自然长至 192 像素。收集加载阶段的布局偏移合计约 0.000022，滚动到图表后可看到真实图表。
