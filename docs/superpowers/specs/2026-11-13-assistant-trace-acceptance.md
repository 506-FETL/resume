# AI 助手 Trace 升级验收

日期：2026-11-13。对应 [规格](2026-11-13-assistant-trace-design.md) 与 [计划](../plans/2026-11-13-assistant-trace.md)。

## 交付内容

- 引入 shadcn 官方 Base Trace、Message、Bubble、Message Scroller；Scroller 使用 `@shadcn/react` 0.3.1。组件只适配本地图标、样式、公共动效和减少动效，未另写滚动引擎。
- 思考、技能加载、工具运行、失败与取消、真实参数及结果、写入确认改为 Trace 组合；用户消息和回复采用 Message / Bubble，保留 Markdown、差异计算和原业务动作。
- 输入器改为现有 shadcn InputGroup / Popover / Command / Badge 组合，支持快捷指令、技能、简历与职位引用、中文输入、发送与停止。引用分别显示加载、失败、空数据并可独立重试。
- 删除无消费者的 Gaia Composer / SlashCommandDropdown、旧 Reasoning / Shimmer。共享导航、画布业务、页面 store、AI 协议、数据库和 Edge 未改。
- 按用户补充反馈修复深度思考：开启使用主色底和反色文字，关闭为 ghost；悬停不会覆盖开启态。按随后要求移除勾选标记，仅保留原图标和名称。

## 审查发现与修复

1. 固定首尾占位行与历史 user anchor 破坏 Scroller 的追加/补入判断；移出哨兵，只标记末尾 user，删除手动滚动补偿。
2. 官方样式中的未知高度占位使搜索定位过程中高度发生变化；移除 `content-visibility: auto`，按真实布局定位。没有修改依赖源码。
3. 停止按钮同步从 button 切到 submit 会误发草稿；固定按钮类型，显式调用动作。
4. 外部筛选 Command 时旧候选仍被保留；使选中值跟随查询，同时保留方向键选择。
5. 条件 streaming 行销毁了确认卡的退出宿主；外层 AnimatePresence 保留行，确认区处理自身 pending 变化，退出阶段禁止交互；后续空白修复移除了会阻止空确认区卸载的内层 propagate。语义状态变化恢复局部 AnimatedContent，折叠实例保持稳定。
6. 深度思考 ghost 的 hover 盖住开启样式；改用不同 Button variant，按用户最终要求不使用额外勾选。

独立规格、质量与 review-animations 审查经过修复后通过；最终复查覆盖历史行 memo 及无勾选的深度思考按钮。长期约束已写入防回归清单第 28 节。

## 性能样本与边界

开发模式、同机 60 条合成历史、每 50ms 更新一次、共 200 次的样本中，历史外壳纳入 memo 前后长任务从 49 次变为 6 次，最大长任务分别为 141ms 与 152ms。该样本仅说明重复渲染减少，不能证明最大阻塞改善、生产帧率或真实手机性能；滚动稳定性单独以几何偏移验收。没有做线上模型或生产用户数据基准。
