# 简历评论视觉与交互精修设计

## 1. 背景与目标

当前版本评论的数据、权限与增量链路已经完成，但桌面与移动端仍存在若干会破坏理解和操作连续性的视觉问题。本轮只调整展示与交互状态，不改变评论权限、版本归属或数据库模型。

目标：

- 分享页在手机竖屏、横屏和常见设备模拟模式下始终使用底部 Drawer。
- 评论书签缩小为贴在预览右边缘的轻量入口。
- 历史版本评论审阅是明确、持续可见且可一键退出的只读状态。
- 评论树默认清晰展示三层父子关系，深层回复通过逐层钻取继续查看。
- 关闭评论后锚点立即稳定回到弱高亮。
- 评论遮罩只降低背景亮度，不模糊简历内容。

## 2. 已确认根因

1. `CommentsPanel` 使用 `useIsMobile()` 的 `< 768px` 判断。手机横屏、宽度刚好 768px 的模拟视口会走桌面右侧 Drawer。
2. `CommentBookmark` 固定使用 `h-14 w-12`、20px 图标和较重阴影，视觉尺寸明显大于参考。
3. 历史来源仅显示在 Drawer 内；来源切换同时关闭编辑侧栏，Drawer 关闭后页面没有任何审阅状态说明。
4. `CommentTree` 的递归条件是 `depth < 1`，主视图只能展示两层；详情状态是单一 `detailRootId`，返回只能清空到顶层。
5. 高亮层直接使用 store 的 `activeThreadId/hoveredThreadId`。Drawer 关闭后鼠标重新落到锚点命中层会再次写入 Hover 状态。
6. 通用 `DrawerOverlay` 默认带 `backdrop-blur-sm`，评论 Overlay 没有覆盖能力。

## 3. 响应式 Drawer

新增评论领域专用移动布局判定：

- 视口小于 768px：移动端；
- 或设备为 `hover: none`、`pointer: coarse` 且视口不超过 1024px：移动端；
- 其余使用桌面右侧 Drawer。

编辑页和分享页继续复用同一个 `CommentsPanel`，避免入口各自判断。移动端使用 `swipeDirection="down"`、底部定位、固定 `60vh` 高度和虚拟键盘 Provider；头部、筛选栏与输入区固定，评论列表或评论树使用剩余空间独立滚动，切换筛选和详情时不改变 Drawer 高度。桌面仍从右侧进入。

## 4. 书签入口

- 默认约 36×40px，图标 16px；
- 右侧贴边、右边框隐藏、左侧圆角约 12px；
- Hover 只向左增加约 4px 宽度，不做大幅扩张；
- 使用轻阴影和实色背景，不使用背景模糊；
- 未读点缩小并贴近右上角。

## 5. 历史版本审阅态

历史版本被选中后，在简历预览顶部持续显示紧凑审阅条：

- 时钟图标；
- 文案“正在查看 Vx · 名称的评论”；
- 次级文案“历史版本只读，返回当前版本后可继续编辑”；
- 主操作“返回当前版本”。

审阅条位于评论 Drawer 之外，因此关闭评论后仍然可见。桌面和移动端共用组件；不会遮挡正文，窄屏允许文案截断。返回动作复用现有来源切换和编辑 UI 恢复逻辑。

## 6. 三层评论树

### 6.1 默认展示

主视图从根评论开始展示三层：根评论为第 1 层，直接回复为第 2 层，对这些回复的回复为第 3 层。第 3 层仍有后代时才显示“继续查看 N 条回复”。

### 6.2 连接线

- 父评论头像中心下方延伸 1px 中性色竖线；
- 子评论前使用圆角折线从父竖线连接到子头像中心；
- 同一父节点的多个子评论共享主竖线，最后一个子节点处结束；
- 采用舒展的 28px 圆角支线，保留层级呼吸感；子轨道使用固定偏移，不再按深度叠加额外位移，避免第三层错位；
- 相邻节点的竖线在盒子边界重叠 1px，避免抗锯齿形成断缝；
- 删除评论保留头像占位和连接线，避免树结构跳变。

### 6.3 深层钻取

详情使用 `commentId[]` 导航栈：

- 点击“继续查看”将当前评论压栈；
- 新详情页以该评论为根，重新获得完整宽度并继续展示三层；
- 返回按钮只弹出栈顶，逐层回到上一个回复上下文；
- 栈为空时才回到线程的顶层评论树。

按钮使用消息气泡图标和“继续查看 N 条回复”，不使用“深层”“层级”等技术词。

## 7. 高亮状态

强高亮只在评论 Drawer 打开时接受 `active/hovered` 状态。关闭开始时立即清空当前主题和 Hover，并停止关闭状态下的 Hover 写入；弱高亮始终保留。这样不会因为关闭动画后指针重新落在锚点上而反弹为强高亮。

## 8. 评论遮罩

为 `DrawerContent` 增加可选 `overlayClassName`，评论面板覆盖为 `backdrop-filter: none`。遮罩保留半透明暗色和淡入淡出，不模糊简历正文。其他 Drawer 保持原有视觉。

## 9. 验证

- 静态验证移动判定包含窄屏和粗指针横屏条件。
- 验证主评论树递归上限为三层，深层按钮仅在第 3 层出现。
- 验证详情导航使用栈并逐层返回。
- 验证关闭 Drawer 时强高亮输入被屏蔽。
- 验证评论 Overlay 覆盖背景模糊，其他 Drawer 不受影响。
- 运行评论专项脚本、TypeScript、目标 ESLint、生产构建和 `git diff --check`。
