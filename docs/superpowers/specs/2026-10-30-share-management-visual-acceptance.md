# 分享管理视觉实施验收

对应[设计](2026-10-30-share-management-visual-design.md)与[计划](../plans/2026-10-30-share-management-visual.md)。用户已确认效果稿，本文件记录正式页面实施与验证，不代替最终用户审查。

## 实施

标题与新建分享同排，统计收进页头辅助行。五个状态页签保留数量，手机搜索与简历筛选同排。卡片使用用途、名称、版本与权限、访问、组合操作五个区域；边界与浅灰操作区沿用主题 token。有效状态为绿色小圆点加文字，过期为琥珀色，关闭与归档为中性文字。

现有记录的用途不推断。手机号与邮箱四种公开组合准确展示，current 显示“随保存更新”，history 显示固定版本号。保留密码、有效期、历史原件删除提示、访问数据及全部原有菜单动作。新建分享仍使用右侧宽抽屉。没有修改后端、公开阅读页、简历模板或导出。

复用现有控件；新增 ButtonGroup 来自已检查的官方 radix-vega 分组容器，适配本地 cn，不增加依赖。CardActions 只承接原菜单与直接操作，保留菜单关闭后的弹层交接和焦点恢复。

## 动效复核

按 review-animations 的检查项复核，仓库已确认的 DURATION / EASE / SPRING 与减少动效规则优先。

| 调整前                                         | 调整后                                                 | 原因                                         |
| ---------------------------------------------- | ------------------------------------------------------ | -------------------------------------------- |
| 旧加载骨架不对应新卡片，组件自身未接入减少动效 | 骨架对齐用途、名称、权限和操作区；偏好启用时停止 pulse | 减少内容出现时的布局跳动，并与卡片降级一致。 |
| 卡片 hover 只有时长，缓动未明确采用项目预设    | 使用 DURATION.base 与 EASE.out，减少动效为 0s          | 与列表和浮层的既有节奏一致。                 |

结论：通过本轮动效复核。保留原先列表轻位移、错峰和重排，退出沿用仓库的更短时长与退出曲线；没有新增持续装饰或长时间动画。本轮未修改共享弹层动画；系统偏好运行中切换与所有共享控件的完整媒体查询回归不在上述模拟验证范围。

## 2026-10-31：尺寸与用途位置修正

用户指出卡片体积过大，并提供“测试用”被放在标题、左上角仍显示“未设置用途”的截图。本轮为原实施的审查修正。

根因有两项：普通记录被重复名称与过大的段落间距撑高；设置保存的 label 与左上角读取的 purpose 不同，卡片又优先将 label 作为标题。已将用途显示改为 label → purpose 分类 → 未设置用途，主标题只使用简历名。未改写数据库字段或权限分类。

- 实际管理页普通卡片高度从 291px 降为 219px；1512px 视口、展开侧栏时列宽约 295px，可容纳四列。
- 隔离页使用实际 Content 与 Card，复现截图数据：修正前首行为“未设置用途”、标题为“测试用”；修正后首行为“测试用”、标题为“测试1”。无备注时分别显示“请人审阅 / 正式投递 / 公开展示”，两项都为空才显示“未设置用途”。
- 320px 视口卡片宽 288px，390px 视口宽 358px，均无横向溢出；长备注截断但 title 保留全文，长简历名最多两行；额外密码、有效期自然增加高度。
- 1280px 隔离页四列，各宽 295px，普通卡片高 219px；同行底部齐平。新骨架实测高 219px。
- 三个操作按钮仍为 36px 高；更多菜单打开后 Escape 返回原按钮。深浅色已检查，隔离页控制台 error / warn 为空。此次未改动动效定义及共享浮层。
- 临时隔离页 `tests/share-card-density` 已删除；截图 `.superpowers/share-card-density/fixed-purpose.png` 使用示例数据，展示实际组件的字段位置。
