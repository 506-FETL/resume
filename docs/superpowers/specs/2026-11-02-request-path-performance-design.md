# 全项目请求链路复查与优化

用户授权继续全项目排查过量字段、重复请求、不必要串行和执行地区，并直接修复已确认的问题。本期在当前分支实施，开工工作区与暂存区干净，不提交、不推送；实施、验证、用户审查分别记录。已读取防回归清单及此前读取链路、简历库分页、编辑启动和分享写入验收，既有成果作为基线。

## 证据与取舍

近 24 小时日志中，resume-comments 在 us-west-1 / 首尔分别执行 120 / 85 个成功 POST，网关中位耗时约 974 / 1435 ms；job-submissions 的 7 次成功 POST 均在首尔，中位约 1576 ms。数据库在 us-east-1。样本混合业务与此前验收，不作为优化对照。代码确认评论默认 auto、协作调用同一函数却未沿用区域配置，投递也未指定区域。

仅改地区无法消除过量正文与重复查询；将所有流程改为大型聚合接口或全量缓存会扩大数据一致性和权限改动。采用按实际消费者收紧字段、复用既有权限实现、局部并发与已有状态管理的方案，不改布局、打印、模型语义和全局鉴权。

## 本期修改范围

1. 数据库密集的 resume-share、resume-comments（含协作）和 job-submissions 共用轻量区域配置，默认当前数据库 us-east-1，可配置统一区域和单函数覆盖，auto 保留。fetch 使用 query 参数，SDK 使用原生 region 选项，公开分享入口不能因此静态加载 SDK。模型代理、JD 识别与导入保持原地区策略，不凭数据库位置推断模型链路更快。
2. 评论增量没有 threadIds 时直接返回空线程结果，继续保留事件游标；协作续期只读实际使用的 scope 元信息；同步正文时独立的线程和快照读取并行，认证、限流、修订检查及事务顺序不变。非 bootstrap 权限解析不再把整份 anchor_document 送到 Edge：新增服务端 v2 薄包装复用 v1 全部校验，仅删除返回中的锚点正文，旧 v1 留给旧部署。bootstrap 和真实锚点验证继续使用完整正文，不删 lease 复查。
3. 投递下载按实际 action 读取文件定位字段，历史下载从 before_snapshot 投影必要文件信息；平台材料预览仍读取完整快照。岗位归属检查完成后才下载文件。
4. 简历库五个并行 HEAD 计数合为一个 SECURITY INVOKER 聚合 RPC；五种统计条件保持不变。冷载第一批最多 10 条云端摘要与统计并行，后续混合分页沿用原游标、稳定排序、缓存和账户代次。空云端首屏可返回空批次，不借统计缓存推断正文存在。
5. 岗位上下文通过外键嵌入只读关联简历名称和类型，去掉一次串行 GET；绑定先验证目标归属，复用实际 UPDATE 返回的岗位，保留不存在和不可见错误。记录投递后只重读目标岗位，不再下载全部岗位。
6. 历史页关联岗位选项只读 id/company/position，页面 store 共享结果和在途请求，账户与页面访问周期失效，失败可重试且不当成空结果。首页岗位定制名称选择使用已有轻量简历选项接口，不在选名称时读取 JD/改写正文或修复模板。
7. 派生简历完成时，真实调用已经完整传入关键词及修改结果，去掉被完全覆盖的旧 metadata 读取；以 UPDATE RETURNING 保留存在性。助手首轮成功持久化回复后只执行带标题的更新，省掉重复 touch；非首轮保留 touch。这不宣称缩短模型首字时间。

## 保留与边界

不改必要的文件归属检查、密码/评论授权、版本一致性、Automerge 保存、AI 额度交付/结算和头像引用确认后的清理。不把 auth.getSession 当网络请求；当前 SDK 跨 client 缓存 JWKS，新建 client 本身不是证据。深层血缘遍历依赖前级结果且暂无真实瓶颈测量，本期记录审计结论，不盲目改写递归协议。无证据不增加索引或重写 RLS。

## 验收与交付

真实模块与 SDK 在 HTTP 边界记录请求数、字段、并发时序与受控延迟；数据库在隔离 PostgreSQL 验证 invoker、service-only、匿名/跨账户拒绝和旧协议。使用本任务合成账户进行同区前后比较和部署后 smoke，禁止操作真实用户业务数据或真实付费模型。页面覆盖简历分页 10/10/3、历史选项重复开合、失败/空态、账户切换、岗位绑定及投递目标刷新。

开发和隔离验证后部署本期迁移及变更函数，核对全部账本、版本、线上权限及区域。运行 app/node/Edge 类型、构建、局部 Prettier→ESLint layout 与全仓格式检查，独立审查。测试脚本/夹具仅 tests/request-audit，结束删除并清理云端合成账户和临时服务；永久记录明确区分受控实验、真实公网及尚未发布的前端。
