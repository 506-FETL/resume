# 首页首开与预览

用户已确认按[录制复核](2026-11-25-workspace-load-trace-review.md)优化首页，代码落地后验收。首页路由与身份确认后，六个读取应与页面渲染并行。预启动和组件消费同一批结果，覆盖挂载前已完成、失败重试、账户切换和回页刷新。访客保留本地简历读取能力。

最近简历已有卡片立即入场，可见的卡片启动现有预览缓存，渲染与正文读取并发；保留版本、账户、退出释放和减少动效。依据实际区域高度控制提醒骨架、空态到内容的位移。生产对照验证图表长任务后再决定是否调整挂载。模板、打印和数据库协议沿用现有实现。

使用同一浏览器、视口、两份简历和网络条件测量首个业务请求、卡片、两份正文请求、两个预览 ready、LCP、CLS、长任务。分别记录受控测试与用户的开发模式录制。
