# 加载期间的导航、浮层和职业档案表单

手机主导航的链接在工作台外壳挂载后就已确定。点击菜单直接展开真实导航抽屉。新建分享沿用右侧抽屉，职业档案沿用桌面居中表单和手机底部抽屉。两者都只打开一次；重表单、候选数据和保存逻辑可以分别按需准备。

全项目逐项检查 Skeleton、手写灰条、Suspense 和共享分包入口。页面首读、列表和纸面预览保留能对应到实际内容的占位。已有文字可以直接阅读。小菜单和工具面板只在等待较久时就地说明状态。尚未就绪的整项操作保留原入口和取消、重试路径，完成后只呈现真正的浮层。

添加档案的两个页签叠放在同一网格内，由较高的一页决定内容高度。上传区填满这一空间，文字页签从上向下排列名称和正文，长文字在输入框内滚动。打开时焦点先进入对应页签，再由浮层隔离背景。短屏和长队列仅滚动正文，保存按钮留在可见区域。

验收从真实路由进入，区分短等待、延迟、失败和取消；检查首个浮层的类型、数量、可操作性、关闭回焦及两轮开关。用桌面和窄屏检查两种输入方式、批量队列和减少动效。
