# 创建信息、简历搜索与求职浮层修正

日期：2026-11-11。用户在 workspace-controls 本轮实施期间追加三项需求，已明确授权实施和动画设计。本期完成实现与验证后统一交用户审查，不重复索要许可；不扩展到新的产品期次。

## 已确认的交互

### 创建简历

保留现有导入 / 从零 / 岗位定制入口。导入和从零两条新建路径在选择模板后增加填写信息步骤。模板卡片点击仍用于比较和选中，页脚主动作改为“下一步”；填写信息后才出现“创建简历”。

信息表单包含“简历名称”和“描述（选填）”。名称初始为“示例简历”，描述为空，两项都允许清空。提交入口去掉首尾空白，空名称统一保存为“示例简历”，空描述保存为空字符串。返回模板保留已选模板及输入；关闭仍按原约定回到创建方式入口，主动继续才恢复草稿。已提交但结果未知时冻结本次名称、描述、正文、模板和操作 ID，重试确认同一份简历，不重复创建。

### 模板到表单的连续动画

采用同一模板工作区的连续布局变换。其余模板用 DURATION.fast 淡出；选中纸张从实际位置移动到左侧，复用 DURATION.slow 与 EASE.out；移动开始后以 DURATION.fast 为间隔，让表单用 DURATION.base 淡入并上移 8px。首尾状态清楚，不增加旋转、循环或夸张回弹。返回时纸张回到列表位置，其余模板再进入。

不选“整个步骤先退再进”，因为会割断选中纸张的连续性；不新增整套动画依赖。复用 Motion 布局投影、既有缩略图缓存、Button、Input、Textarea、Label、Dialog 和草稿 store。模板与信息共用稳定的外框、标题和固定页脚，目录及预览保持可复用；正文有独立高度边界。

用户在实际页面审查后修正视觉方向：选中的简历在信息步骤中作为背景铺满左侧，从左向右渐隐，表单在右侧留出清晰、舒适的填写区域。详情态取消卡片描边、勾选与底部名称条，保留页脚已有的模板说明。背景使用真实选中模板，按比例放大裁切，不拉伸纸张内容；动效由原卡片展开成背景，返回恢复原位置和目录滚动。表单按可用正文高度合理居中，避免顶部挤在一起、底部大片空白。

手机最初采用顶部背景向下渐隐到表单，用户在实际页面指出只能看到页头。按[后续返修规格](2026-11-11-creation-tracker-followup-design.md)和用户最新纠正，继续保留全宽向下渐隐形式，仅将背景增高到约 320–384px 并下移渐隐起点和表单；不采用独立纸张缩略图。长描述和短屏在正文内滚动，创建按钮始终可达。减少动效时直接进入最终布局，不保留位移或延迟。切换先移交焦点，退出内容不参与点击与 Tab；完成后键盘可顺序填写，返回能找到原选中项。桌面继续沿用左侧渐隐背景。

### 简历搜索

在“我的简历”的常驻筛选区域增加搜索，按名称或描述的连续片段匹配，英文大小写不敏感，去掉搜索词首尾空白。百分号、下划线、逗号、引号等作为用户输入的字面字符处理，不改变查询结构。空搜索恢复完整列表。

搜索与全部 / 原始 / 岗位版本相交，变更条件回第一页；页数、总数和实际结果使用相同条件。适配中文输入法，组合输入结束再查询，并对连续输入短暂防抖。清空立即生效，输入过程中不抢焦点，真实失败可重试，零匹配有“清空搜索”入口。

云端新增两个搜索专用函数，以 strpos / lower 参数化匹配，避免 PostgREST OR 字符串转义分歧；空搜索沿用原接口。两个函数为 SECURITY INVOKER，只允许 authenticated 且限制 auth.uid() 归属，不扩展表权限。本地增加名称和描述键索引，以 openKeyCursor 扫描匹配 ID，不读取全文遍历匹配。云端查询仍每批最多 10 条，按原更新时间和稳定 ID 混排本地数据；不下载全库正文或把当前页当全量。缓存按规范化搜索词、分类、页和原账户/数据代次组织；完整已加载的摘要可复用，缺页只读取必要结果。清空回到已缓存列表不重取。摘要只包含实际列表字段，统计延续调用者权限与 RLS，原未搜索接口保持兼容。

### 求职浮层

先使用真实组件和隔离状态复现，再修复已证实的原因。下拉开启 / 关闭不应改变弹窗尺寸或底层页面位置；嵌套弹窗内输入、选择、日期、取消、确认和 Escape 只作用于对应层。关闭后回焦有效入口，原职位抽屉及已填内容保留。

已实测确认：Base UI Combobox Portal 挂到 Radix Dialog 的 grid 节点时，Portal 包装层作为额外网格项引入 gap；嵌套 Select 的选择操作又会触发 BODY 上的 outside-press，使 Drawer 误关。分别在包装层布局和下层关闭边界修正。测量结果与实际 dismiss reason 已写入[验收记录](2026-11-11-resume-workflow-acceptance.md)，没有替换组件库或加入全局事件拦截。
