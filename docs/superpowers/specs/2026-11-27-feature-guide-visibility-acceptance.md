## 入口与恢复

- **排序。** 桌面和 320 px 手机分别往返编辑与检查两轮。桌面开关导出弹窗，手机开关真实排序面板，回到编辑后提示可恢复。用键盘关闭引导后，桌面焦点回到对应手柄，手机回到「调整模块顺序」。刷新后同一身份的排序提示保持关闭。生产包单独复核了检查、导出和退出中重开。
- **评论。** 桌面与 390 px 手机都从「看看」进入，走完评论栏、划词、演示发送和高亮，返回上一步后再次完成。桌面在评论栏说明步骤通过键盘打开导出弹窗，评论演示和提示一起隐藏，Escape 关闭导出后恢复原步骤。浮窗可从已收起的演示抽屉继续移到正文。
- **助手。** 桌面和手机通过真实画布、已排版的示例正文和引用演示完成前进、后退与结束。手动打开手机画布时，首次提示让出界面，Escape 关闭画布后再次出现。助手能识别晚于旧空态到达的正文，说明中的「简历预览」与实际页签一致。
- **动效与打印。** 引导显示期间切换减少动效偏好后，继续走完评论与引用步骤。打印媒体下排序提示不可见。逐项通读了实际页面中的首次提示与详细步骤。

详细交互使用隔离浏览器、仓库的应届生示例和公开默认模板 v3。登录身份与业务接口使用本地夹具，简历写入隔离浏览器的 IndexedDB。手机验证使用浏览器窄屏视口。前端未发布。

TypeScript 检查、生产构建、全仓格式检查及差异空白检查通过。全仓 ESLint 为 0 个错误、59 条警告，本次修改的引导源码单独检查通过。

## 排序提示首次定位补验

此前的滚动验收覆盖了手柄进入视野后的表现，遗漏了基本信息表单尚在加载的首屏。这次使用同一份带照片的本地简历，对比修复前后的 Chromium 生产构建。从点击「编辑简历」前开始采样，保持初始滚动位置，记录真正可点的手柄、浮窗和 SVG 箭头在屏幕上的位置。箭头逐段绘制，测量取路径画完时尖端应落的位置，保留设计中的手柄间距。

| 场景                                 | 结果                                                                                                                                                  |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1800 × 1200，基本信息分包延迟 1.2 秒 | 旧版的提示在占位期间出现，表单挂载后箭头最大偏差约 621 px。修复后，加载期间提示保持隐藏，首次显示即对准「求职意向」左侧的手柄。                       |
| 1440 × 920，相同延迟                 | 表单就绪后首屏只有基本信息，卡片与箭头均未显示。向下滚动让手柄进入视野后出现提示，滚回顶部时消失。                                                    |
| 编辑栏开合、栏目折叠、检查页签       | 在编辑栏退出中重开，再连续收起、打开两轮。折叠和展开基本信息各两次，提示在栏目高度变化期间收起。返回编辑后定位到可见手柄，键盘关闭后焦点回到该手柄。  |
| 减少动效与手机                       | 桌面开启减少动效后，首个可见箭头仍与手柄对齐。320 px 和 390 px 手机抽屉中，箭头仍指向「调整模块顺序」，打开排序面板时让出界面，按 Escape 返回后恢复。 |

两个桌面视口分别静置 60 个绘制帧，手柄矩形读取次数均为 0。已通读真实页面的提示文案，实施和本地验证完成，待用户审查。前端未发布。
