## 补齐过程新增发现

- 历史消息编辑和重生成只判断运行锁，保存结果未知时仍能截断消息并启动模型。真实按钮路径已复现；与重试、队列一样先核对待保存结果。
- 确认后的 apply 在切换会话后仍更新旧确认卡，新会话会显示旧方案。切换展示范围需清理旧卡，实际写入和原会话持久化继续收尾。
- 简历名称/描述修改没有核对预览基线；采用前只核对本次修改的字段。真实工具与受控 REST 验证：同字段手改零写入，其他字段手改不误拦。
- 新建简历请求已经发出后切换账户，旧响应无条件修改当前简历。保留原账户实际创建结果，禁止旧响应改动新账户当前目标与本机当前简历键；受控延迟响应已验证。
- 画布字段没有直接 Tab 入口；补上后发现分页的 `overflow:hidden` 会在原生聚焦时内部滚动。只装饰助手可见分页，按页、区域及片段的实际裁剪交集过滤文字，并使用 `overflow:clip` 阻止内部滚动。卸载恢复原属性；同一正文几何在装饰、卸载与重挂三阶段一致。
- 本机导入原文读取接入后，换目标简历还需过滤旧工具原文并使旧摘要失效。当前目标 ID 纳入摘要指纹，历史来源快照仅用于回看，不授予本轮读取范围。

## 已取得的补齐证据

以下是定向验证的边界，不替代最后的完整集成验收。

- 上下文真实函数 11 组通过，包括完整摘要请求预算、重复只读裁剪、已撤销状态、软阈值失败回退、硬阈值暂停、压缩失败不自动再收费、两次整理与检查点重开、来源/目标变化后的隔离。
- 真实模型 usage 校准使用三个合成样本：中文笔记、富文本经历、长 JD；实际输入分别为 899、2089、2304 token。校准后保守估算分别为 1725、2507、4582。仅为本次小样本，不宣称精确计数或固定网络耗时。验收账户已删除。
- 受控流式传输持续 12.55 秒，期间连续输入 100 次，输入到下一帧 p50 15.7ms、p95 18.9ms、最大 19.7ms；首个流式字节 155.5ms、首段渲染 472ms。是本机受控传输结果，不是公网服务承诺。
- 会话菜单在 1440/390/320px 通过内置搜索、无结果、重命名取消、两轮开关与反向、键盘回焦、运行中减少动效检查。
- 画布已实测跨普通/富文本字段、字素、同名条目重排后唯一重连、歧义拒绝、0.5/0.75/1.25 缩放、键盘整字段和空字段引用、触摸气泡引用。浏览器手机仿真未覆盖真实系统原生选词手柄；不将触摸整字段引用替代路径写成原生选词通过。
- 运行控制普通与减少动效各 13 项受控验证通过，真实队列消费使模型背景和工具实际目标依次采用冻结的 A/B；账户切换期间返回的结果只在原账户补存、不重复 apply。后续独立审查发现均已修复复验，批量停止另增 9 条验证记录。
- 选区搜索迁移已在隔离 PostgreSQL 17 验证 7 项，完整摘录后半段可由表达式索引检索；已部署为 20261114145803，线上完整摘录搜索通过。

## 最终联调发现与闭合

- 批量重试在前项 finally 清空运行器后丢失停止信息：单项返回是否允许继续，保存未知、取消或身份变化立即结束批次；9 项独立复验通过。
- 画布撤销重新解析当前绑定会写错目标，批量正序撤销会停在中间版本，两个状态集合无法表示再次撤销：按实际变更目标、逆序撤销/正序重做、单一状态记录修复；真实云端 A/B 和多次往返通过。
- 新建简历模块原值 null 不能传入对象 patch；撤销用既有规范化恢复空模块。确认前画布状态不再提前显示已应用。真实模型保存后撤销/重做通过。
- auth 管理角色级联删除消息时，调用者权限触发器无法删除摘要：新增受限内部触发器迁移 20261114150719，严格原消息 owner/会话/边界，撤销直接执行，不扩大表权限；隔离 PG17 与真实云账户删除通过。
- 真实摘要曾把资料原文放在“已确认事实”下：明确用户核实事实和资料记载两类，真实模型复验给出“已确认事实：暂无”，保留出处及待核实内容。
- 本期资料函数 ACTIVE/version 2，四条迁移均已部署，75 条完整账本双向差集为空；真实模型完整链路四条费用记录均 settled/completed。基础资料操作前后费用记录数相同。
- 最终独立源码审查已复核上述修正，无剩余确定重要问题；不把此结论当作用户产品验收通过。
