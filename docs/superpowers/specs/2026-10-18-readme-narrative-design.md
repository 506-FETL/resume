## 结构

首页用一句定位、主图和简短导航介绍项目。按用户补充要求，主体分别展开六个场景：

1. 岗位定制与历史版本：版本容易混淆、修改需要回退 → 独立派生、对比恢复和职位跟进 → 父子关系与历史快照分开保存。
2. 简历优化：评分与内容质量不等价 → 原文依据、修复清单和辅助分析 → 按实际内容构造评估与结果归一化。
3. AI Agent：复制粘贴和内容失真 → 多步工具操作、技能资料与确认 → 流式参数、结构校验、取消与额度结算。
4. 分享审阅：对外版本与反馈需要确定 → 固定分享、原文评论 → 内容和模板快照、锚点迁移与有序事件恢复。
5. 实时协作：来回传文件、解释位置和合并副本 → 同一文档共同编辑、实时光标 → 双 CRDT、增量回填与回环阻断。
6. 分页交付：预览和输出变化 → 可检查的 A4 页面 → DOM 行测量、布局稳定签名与打印复核。

末尾说明本地编辑与云端依赖，并保留本地启动、开发入口、贡献与许可证。部署操作移入独立指南，不建立单独的产品篇和技术篇。
