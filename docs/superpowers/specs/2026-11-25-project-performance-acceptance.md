## 其他入口和后端

- 覆盖官网、登录、注册、找回和重置密码、更新日志、个人资料、公开分享、失效链接和 404 等入口。路由冒烟共 20 个场景，其中公开分享使用真实临时链接。
- 官网冷启动首批 JS 的 gzip 传输从 195,635 B 减至 155,463 B。同机合成手机条件下三轮中位数从 999 ms 降至 888 ms。更新日志的六张图片按展开加载，首次从六张降至零张，逐条展开后验证实际解码。
- 评论计数在数据库按评论范围汇总，Edge 收到未解决、已解决和已脱离三项计数。隔离 PostgreSQL 用 1,500 条评论验证跨行数上限、已删除评论排除和权限。首页 ATS 的 550 份合成样本从 496,957 B 降至 49,914 B；前 500 份的数据端暖执行中位数从 2.80 ms 增至 5.54 ms，节省的是正文传输和浏览器解析。
- 人为阻断请求与合成大账户用于验证边界，结果不用作公网耗时保证。AI 工具的真实保存与恢复经过确认链路，本轮未发起付费模型生成或对外投递。
