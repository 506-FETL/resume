# 求职跟进流畅度与手机布局

依据用户本轮四项明确要求执行：全面排查重复请求和无效渲染，优化手机列表与顶部筛选，修复切换卡顿；保留自动保存、确认、键盘操作和减少动效支持。

## 已确认根因

- ListView 同时挂载桌面表格与手机卡片，只通过 CSS 隐藏，产生两套职位树、订阅和布局动画。
- 多处 Zustand 全量订阅，保存状态、单字草稿、选择一条记录使无关列表、统计、抽屉一起刷新；编辑会创建新的 jobs 引用，单独替换订阅仍不能隔离这些刷新。
- 列表筛选、排序和看板分组反复计算，Motion position layout 没有限制测量依赖。
- AnimatedContent 的 wait 模式把退出 140 ms 与进入 200 ms 串行执行；重内容切换还需等待挂载。
- 简历列表/预览只在文档组件本地缓存，Tab 卸载后丢失；新增职位重复读取同一列表，异步响应缺少关闭/重开保护。
- 关闭详情时立即重置到跟进标签，在退出动画首帧卸载当前内容并挂载时间线；轮次名称与保存提示刷新还会连带渲染笔记编辑器。

## 设计

### 渲染与交互

- 显示区域消费稳定的职位展示快照：所有卡片字段和历史进度变化必须刷新；备注、联系人和保存反馈变化不触发背景列表重绘。打开与写入始终按 ID 使用最新 store 数据。
- 组件只订阅消费的数据/动作。缓存过滤、分组和排序；行/卡片单独感知自己的选中状态。只挂载当前断点的列表树。
- 布局动画仅在展示数据（含标题、下一步引起的高度变化）、排序、筛选、增删和列折叠时测量；保留进入、退出和位置过渡。页面切换使用即时进入的短过渡，消除 wait 引入的空档。修改限定在 tracker 调用和 tracker 本地组件。
- 详情退出时保留当前内容，下一次打开前再重置；笔记编辑器单独订阅对应职位、阶段或轮次的笔记，名称和保存提示更新不重建编辑器配置。
- 详情草稿及 3 秒防抖保存继续由现有队列管理；不得给输入回调再套会在卸载时丢值的防抖。

### 请求

- 页面内共享简历列表与按 ID 的预览请求；复用在途 Promise，短期缓存成功响应，失败可显式重试，不缓存失败。
- 缓存按登录身份隔离，身份切换清除缓存和过期结果。详情与新增职位共享列表，加载状态仍各自独立。
- 查询/绑定响应有生命周期和版本保护，快速折叠、切 Tab、换简历、关闭重开不能被旧结果覆盖。

### 手机布局

- 列表卡片使用紧凑三行以内的职位条目：职位名称优先；公司与城市合并；状态和更多操作在右侧。隐藏展开式下一步详情及薪资，只有必要的待跟进提示保持可见；完整信息在详情可查。
- 顶部四个指标改为一条连续的分段筛选栏，数值与标签同排，保留选中反馈、可再次取消、加载态和完整无障碍名称。桌面继续使用现有统计卡。
- 搜索保留主要宽度，将手机阶段/排序统一到带文字的筛选入口，面板分组显示当前阶段和排序；归档/批量操作保持可达。
- 320/390/430 px 下无横向溢出；控件具有合理触摸区域；保留 shadcn/Radix 风格及原有颜色语义。

## 验收

- 记录真实页面渲染次数、同时挂载职位树数量及重复读请求次数，做前后对照；掉帧测量与固定动画等待分开报告，不以主观流畅代替证据。
- 保存状态变化、连续备注输入不触发背景整页和无关职位重绘；手机不挂载桌面表格。
- 多次切回文档/展开/新增使用共享读取；换用户、失败重试、绑定新简历不串数据。
- 回归现有 41 组保存检查，以及列表/看板切换、筛选排序、批量选择、详情开关、终态确认、手机宽度和减少动效。
- 完成本轮 ESLint、TypeScript、构建和增量范围审查。当前分支开发，不提交、不推送，不修改数据库。
