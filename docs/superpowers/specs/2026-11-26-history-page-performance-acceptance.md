# 历史版本页面性能验收

## 场景与复测方式

用同一台机器上的生产构建，检查从工作台打开历史版本、直接访问、从岗位进入、选择简历、时间线翻页、筛选、版本详情、对比、导出与恢复。测试账号有 31 份简历，选中的简历有 45 个冻结版本。桌面记录真实版本出现和纸面排版就绪，390 × 844 手机分别记录时间线和首次打开详情。首次加载使用新浏览器上下文，数据库恢复与写入用临时登录账号和真实 RLS 核验。

## 读取与缓存

- 选中简历的正文与版本时间线并发读取。原来先下载 31 份简历候选，再取 45 条历史元信息；现在时间线每次返回 10 条元信息、准确匹配数和该简历的最新冻结版本摘要。初次读取的简历与版本业务响应从 3 次、51,093 B 降至 2 次、6,170 B，按解压后的 JSON 计，不含模板及静态资源。
- 未选简历时探测结果为 1 条、151 B。展开候选后再取首批，已有探测项继续使用。简历和岗位选择器每批展示 10 条，多取一条判断是否可续页。23 个岗位候选按 10/10/3 展示；键盘续页后焦点到第一条新增记录，重复打开和选择已读项的新增请求为 0。岗位候选使用受控数据，临时草稿未保存。
- 五页依次显示 10/10/10/10/5 条，账号只能读取自己的记录。跨页搜索、标签、重点、来源及新旧排序已与完整数据对照。已访问的页往返为 0 次版本查询。分别令当前正文、时间线失败或延迟时，另一部分仍可使用，失败的部分可以单独重试。
- 元信息未改时为 0 次写入；改掉末页唯一匹配标签后回到正确页。最早在前时创建新记录无需重读当前页；删除筛选外的最新版本能更新全局同步依据。只有受影响的页需要补齐时才重新读取。对比的两份版本快照各读取一次。
- 相同内容连续保存只产生第一笔写入。普通保存只发出一笔业务 POST，返回 587 B。恢复时分别验证取消、直接恢复、先保留一份备份再恢复。真实云端与刷新后的简历均核对通过，直接恢复增加一条恢复记录，带备份恢复增加备份与恢复两条记录。
- 快照哈希复用同一份稳定序列化实现。乱序键、数字键、Unicode、空值和嵌套数组与旧实现结果一致。2,000 条合成经历的序列化体积为 661,793 B，21 次交替测量中，计算 SHA-256 的中位数从 7.70 ms 到 6.31 ms。

## 预览与打印

手机只读时间线时不创建测量纸张。打开选中的版本时取其快照、载入详情和排版代码，返回后释放隐藏测量节点。同一份已完成纸面再开可以复用。打印直接使用就绪的选中版本，实测新增排版次数从 1 次降为 0 次。检查了短内容 1 页、距分页边界 0.46 px 的 26 段内容 1 页以及 100 段内容 3 页，背景开关两种输出均经过真实打印入口。PDF 文本核对了冻结版本姓名。

## 云端接口

新增迁移 `20261126130000_history_version_pages` 已部署至关联 Supabase 项目。部署后 93 条本地与远端迁移记录一致。新 RPC 按调用者权限执行，匿名请求返回 401，另一个已登录账号查询验收简历得到 0 条、最新版本为空。首批 RPC 含 11 个展示与操作所需字段，响应 3,411 B，旧版全量时间线为 24,466 B。此次没有 Edge Functions 变更。

## 写后读回与失效

- 从历史页编辑一条冻结版本并选择首批以外的岗位，已在云端读回新名称和岗位主键，刷新后名称一致。从菜单删除后再次查询，目标记录已不存在。岗位无权访问时只发归属核验，未登录时简历业务请求为 0。
- 普通保存前后都是 1 个 POST，返回值由含整份快照的 3,910 B 减至 587 B。带备份恢复实测由 11 次业务读写减至 8 次，当前表单写入只返回所需元信息，已确认的快照同步到页内。
- 在另一入口删除页外版本并更改最新版本的名称，重新打开后可见新名，旧条目和正文缓存均被清除。通过实际 SDK 切换账号 A→B→A 并延迟释放旧 A 请求，页面保持实际 45 条总数与 10 条首批。单独检查了从侧栏离开时已读快照、当前正文和版本目录引用的释放，返回后能重新读到云端数据。

## 页面、弹窗与分包

- 手机上先进入历史列表、再打开某版、返回列表、重开、改变宽度、离开页面，测量纸张的实例数依次为 0/1/0/0/1/0。整轮只读了一次这份冻结快照。同一份两页官方模板示例在模板页重开也能复用纸面。
- 对比、恢复和保存弹窗分别经过两轮开关，关闭后焦点返回原操作。比较两个冻结版本、左右同选当前内容、从下一批选择基准版本均已验证。给生产比较入口 JS 的首次请求注入 HTTP 503 后，点击局部重试实际重新发出请求并显示 1 处差异。
- 用历史页真实导出按钮启动打印与就绪校验，从其生成的打印 iframe 通过 Chromium 输出 PDF。按页提取中文文本并在 72 dpi 栅格化对照。短样本、手机、临界分页和 3 页长样本的新旧输出像素一致。临界样本正文高 1,090.06 px，可用高度 1,090.52 px，仍为 1 页。

- 工作区入口和日期组件分别注入了真实 HTTP 503。曾复现工作区重试后列表能显示，后续详情仍因纸张上下文位于失败分包中而打不开。交付构建将工作区入口单独打包，点击重试会发出一次新的请求。冻结版本详情、编辑和日期弹层均能继续使用。静态子依赖永久不可用和其他浏览器的模块缓存行为未纳入这项故障注入。

## 冷启动与按需加载的取舍

- 桌面直接打开至当前简历纸面就绪为 4,084→3,114 ms。无目标提示为 2,851→2,043 ms；首次展开后看到完整一批候选为 92→354 ms。原本在首屏完成的候选下载及手机排版现在由具体操作触发。搜索包含 200 ms 输入防抖和一次服务端查询。
- 手机上点击某版后，只根据该快照的真实绑定发模板请求。一次受控采样中，快照在点击后 302 ms 到达，模板请求在 326 ms 发出；改进预取前，两者相隔约 316 ms。该例需要的 9 段字体到达后，纸面在 1,048 ms 就绪。只浏览列表时该模板的请求为 0。
