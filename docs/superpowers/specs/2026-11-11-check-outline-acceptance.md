## 实现与边界

错误用红色、待核对用琥珀色、建议用蓝色。预览纸张在深浅界面中都为白色，因此边框和文字使用同组深色，保持反差。1.5px 描边使用 4px 圆角，从左上沿顺时针闭合，内侧不铺底色。进入 280ms，同步完成描边和文字染色；退出 140ms，同步淡退和恢复原色。沿用公共 `EASE.out` / `EASE.in` 与 `DURATION.slow` / `DURATION.fast`，减少动效时归零。

原文按稳定字段、条目和第几次出现定位。跨文本节点的引用按各节点原色分组登记；相同颜色只使用一组。每页可见内容的范围合为一个矩形，测量源和隐藏页不参与。分页、字体和正文布局没有修改，缩放仅重新测量位置。

GSAP 负责 SVG 描边、覆盖层透明度与临时文字着色比例。文字使用浏览器原生范围着色，不再使用 Magic UI / rough-notation 的荧光笔，不包装或改写正文节点。浏览器 API 的依据见 [MDN CSS Custom Highlight API](https://developer.mozilla.org/en-US/docs/Web/API/CSS_Custom_Highlight_API)。着色规则限于屏幕，范围只绑定当前预览；不支持该 API 的旧浏览器仍显示描边。

新目标等待旧目标退出，快速操作最终只保留当前目标。卸载时撤销 GSAP 样式并删除本组件登记的文字范围。切换填写、关闭面板、收起问题、筛选隐藏问题及进入历史版本的既有可见性条件保留。
