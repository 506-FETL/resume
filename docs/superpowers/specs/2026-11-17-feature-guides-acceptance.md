## 追加验收：仅主动结束与全账户首次重置

日期：2026-11-17。本节覆盖前文“外部操作接管”和“Escape 退出”的旧规则。用户最新要求为：点击别处不得中断提示，只通过明确的引导操作推进、关闭或完成，并让所有用户重新看到首次引导。

根因是引导 hook 的全局 pointerdown、input、keydown 和 Driver interaction 都将外部操作当作关闭；评论 Drawer 与手机画布也有默认退出路径。现已移除自动接管，Popover 阻止 Escape，评论演示取消默认关闭，手机画布在引导期间仅接受其明确关闭按钮。既有动效、非模态展示、上下文清理保持不变。

首次记录只在 localStorage，未发现云端首次使用字段。保留存储键，将 persist 版本由 0 升到 1；迁移清空旧记录中的全部账户及访客。加载新版只重置一次，随后主动关闭按账户继续保存。此改动不涉及数据库和 Edge Functions，前端未发布，不能把本地迁移验证描述为所有线上浏览器已经重置。

## 再次返修：螺旋绘制与关闭回闪

日期：2026-11-17。用户确认上一版实际使用仍有箭头闪现、关闭后再闪回的问题，要求螺旋箭头与旋转绘制；不能沿用前文的动效通过结论代表本次用户审查。

### 根因与修复

- 在正式 MotionProvider 下复现：原浮层约 146 ms 时透明度已降至 0.09，约 155 ms 又回到 1，随后播放第二次 140 ms CSS 退出。GSAP 完成后关闭 Popover 并还原样式，而 Radix Popper 已覆盖内联 `animation: none`，默认退出仍在运行。
- 新浮层由 AnimatePresence 保留退出节点，局部 CSS 真正停用默认动画，GSAP 从当前状态过渡，结束后直接卸载。退出期间冻结锚点；Driver 确认新目标后，旧步骤退出完再挂载新步骤，避免新内容先出现在旧位置。使用 Popover 的公开挂载回调 `onOpenAutoFocus`，不依赖未公开的 `onPlaced` 参数。
- 箭头和引用演示卡原来的 `revertOnUpdate` 会先恢复隐藏样式，再重新变成可见并淡出。现在只取消被替代的 tween，从当前透明度继续；箭头完整退出后才清除路径和位置。
- 螺旋箭头使用 40 × 32 px SVG、1.4 px 细线，逐段画出单圈曲线，箭头尖随切线旋转，最终指向入口；绘制使用公共 slow + base 共 480 ms，不阻塞按钮、不循环。浮层仍为 200 ms 进入、140 ms 退出。
- 验收发现零时长完成通知早于父级 Presence 登记，留下不可见浮层；完成通知现等本次提交结束，并确认仍在退出。另修正 320 px 下增加箭头间距后提示被裁掉的问题，虚拟锚点给完整提示留出空间，箭头继续连接真实入口。

最初隔离夹具未挂载 MotionProvider，CSS 动画时长为 0，未能反映真实回闪；本轮补齐并断言正常模式 CSS 时长为 0.2 s。后续必须连同正式动效环境逐帧验收，不能只靠截图或最后是否消失判断通过。
