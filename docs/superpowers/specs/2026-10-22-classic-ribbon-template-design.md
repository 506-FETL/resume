# 经典蓝金模板设计

依据：用户提供的蓝灰／金色参考图，以及已确认的配置式模板架构。本次直接实现第二套模板，默认模板保持原版本和原样式。

## 呈现与范围

- 新模板为 `classic-ribbon@1`，目录名“经典蓝金模板”，风格“经典”，布局“单栏”。
- 顶部“个人简历 / Personal resume”双语标题、金色图标及蓝金斜切分隔线。
- 基本信息用带标签的双列字段；所有章节共用蓝灰色斜角标题与细横线，正文左侧有连续细线。
- 教育、工作、实习、校园和项目共用日期／机构／职位三列条目头，描述沿用公共富文本。
- 技能使用三列进度条，证书与兴趣继续复用公共标签；新增条目自动使用当前部件。
- 使用现有应届生、前端示例；不复制第三方正文。当前 schema 无头像，暂不增加头像业务或不可编辑的假头像。

## 配置与代码边界

新增受控的 `ruled-column@1`、`banner-profile@1`、`ribbon-heading@1`、`aligned-entry-list@1`、`skill-meters@1` 视觉能力，注册到现有白名单。模板定义包含可选的严格十六进制主色和强调色；主题选择为“默认”时使用模板主色，用户已有主题选择继续有效。

默认定义和旧视觉部件不修改。新布局仅渲染实际显示的章节，默认布局继续保留其原有占位几何。内容适配增加已有工作年限字段的呈现，字段 nodeKey、条目 ID、富文本内容和协作文档身份不变。

模板来源继续为前端 Local Source，新增独立定义、目录项和精确版本索引；保留未来远端读取接口。分享移除仅 default@1 的限制，发布已通过协议校验的完整定义，冻结定义与引用保持一致。

## 验收

检查目录、两种示例预览、桌面弹窗／手机 Drawer、创建后绑定及外观、编辑器渲染、默认模板回归、模块隐藏和重排、全部字段评论锚点、分享定义往返、A4 多页分页、PDF／Word 输出。运行模板专项脚本、TS、ESLint、构建；不改写固定评论基线。浏览器验证与未实际验证的线上能力分开记录。
