# 全站界面与动效精修设计

日期：2026-10-28。

状态：用户于 2026-10-28 明确授权按推荐方案写好计划后直接实施，无需再次等待规格确认。实施与本轮验证已完成，具体覆盖和未通过项见 2026-10-29 验收记录；最终用户审查尚未进行。

## 1. 目标与范围

按用户要求，审查并优化整个前端的布局、文字、组件状态和动画。覆盖全部主要路由及其弹窗、抽屉、表单、列表、空态、错误态和加载态，不能以改完首页或公共样式作为全站完成。

“去掉 AI 味”在本次工作中指具体问题：无关装饰、重复的卡片与说明、主次不清、套话、需要悬停才能发现的关键动作，以及只做首次入场、缺少退出和连续操作反馈的动画。保留真实的 AI 功能名称和必要依据，不通过删除“AI”字样掩盖能力。

覆盖共享 UI、应用外壳、业务页面与编辑器操作界面。模板目录、预览弹窗和导出控件属于本次范围；简历文档本身继续遵守已有模板、字体、分页和打印契约，不借界面精修重做用户文档。

不新增产品路线图中尚未授权的能力。本次不涉及数据库模型、计费、自动投递或新的生成服务。

## 3. 方案选择

| 方案                              | 做法                                                                                                | 取舍                                               |
| --------------------------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| A：保留产品身份，逐页精修（推荐） | 保留导航、工作方式、黑白中性色、首页局部渐变和 ATS 大数字；重新梳理各页密度、动作层级及所有共享交互 | 可覆盖全站，也能保持用户熟悉的操作路径             |
| B：重建全套视觉身份               | 换字体、色彩、导航和主要布局，再重新实现页面                                                        | 改动和回归范围显著扩大，并会覆盖此前已经确认的设计 |

## 4. 视觉与文字

### 4.1 层级与布局

- 延续现有 PageLayout 和 PageHeader。管理页主要内容上限 1280 px，跟进页使用现有宽布局，编辑、助手、历史按工作区分配可用空间，账户表单使用适合阅读的窄布局。
- 保留现有 Inter 与中文回退字体；Racing Sans One 仅用于已确认的 ATS 装饰数字，不扩展到正文和全部统计。
- 页面标题、分区标题、正文与辅助文字各有明确层级。标题默认 24/32，分区标题 16/24，正文 14/22，辅助文字 12/18；窄屏按现有断点调整，不统一放大所有文字。
- 卡片承载独立对象或任务。同一对象内部优先用分区、信息行和间距，消除卡片内再套卡片造成的重复边界。
- 留白按内容和任务调整。空列表不自动占据大幅无意义空间；编辑、对话等需要持续操作的区域保留有效高度。
- 每个操作区域有清晰的主动作，辅助动作依次降低强调。手机上的关键动作无需依赖 hover，图标按钮有名称和可见状态。
- 手机编辑工具栏继续遵守已确认的图标形式，不直接采用审查中的“全部增加文字”建议。通过合理分组、触控区域、间距、Tooltip 与选中态改善辨识；320 px 允许自然换行，不能用缩小到难以点击来强塞一行。

### 4.2 装饰与产品辨识

- 保留首页面试、跟进、重点关注的左上大图标、局部渐变和对应颜色。
- 保留 ATS 结果卡片的真实分数水印、Racing Sans One 字体及评分色；装饰不参与布局和读屏。
- 去掉错误、认证和空数据页面中不服务当前任务的背景特效。404 用清晰的错误说明和返回入口，组件库中的地球、光线等效果组件保留供适用场景使用。
- 色彩继续表达状态和特定模块，不新增遍布全站的彩色图标底座、渐变文字和常驻闪光。

### 4.3 文案

- 标题说明任务，按钮说明动作；状态说明真实结果与可用的下一步。
- 删除重复标题、无意义鼓励、空泛“提升”“赋能”等表述，保留导入范围、保存位置、评分依据和必要风险。
- 公共控件中的读屏名称、侧栏说明、空态与错误提示使用自然中文。
- 注册完成、找回密码、重置失败等结束状态要有可理解的去向；不新增实际不支持的重发、购买或上传动作。
- AI 返回的建议、用户简历正文和岗位事实不作为普通界面文案批量改写。
- 侧栏与浏览器标题使用已经确认的 GResume 名称和既有品牌资产，页面语言标记为中文；不另造新品牌。

## 6. 公共组件修正

先核对底层 primitive，再修样式和动画。当前已确认 Switch 与 Checkbox 将 Radix 状态写为 Base UI 的 `data-checked`；必须恢复基于 `data-state` 的样式，并覆盖选中、未选中、禁用、焦点及中间态。相关 Field 和 Command 状态选择器同时检查实际输出，不能只全局替换字符串。

Button、输入控件、Tabs、列表行及侧栏改为明确的过渡属性。颜色、边框、阴影、位移分别按真实用途选择，避免 `transition-all` 意外使尺寸、布局和内容更新一起缓动。

Tabs 保持原有语义、值控制和方向键交互；选中标记平滑移动，面板切换只由一层负责。已有自行管理切换的工作区不能再次叠加公共内容动画。保留需要常驻的表单与编辑器状态，不为动画重挂载输入。

Empty、Alert、Skeleton 和 Spinner 按内容区域使用一致的标题、说明和操作层级。加载不伪装成空数据，局部刷新不让整页消失。

## 7. 动画设计

### 7.1 工具与预设

- 常见微交互按 `transitions-dev` 实现和调整。
- 复杂时间轴或滚动编排才使用 GSAP Skills；普通工作台操作不为了使用技能而引入时间轴或新依赖。
- 每批完成后使用 Emil `review-animations`；整站最终再做 Impeccable `critique` 与 `polish`。
- 复用 `src/lib/motion.ts` 与 MotionProvider 的 CSS 变量。进入主曲线 `[0.22, 1, 0.36, 1]`，时长沿用 0.14 / 0.2 / 0.28 秒，退出更短，弹性沿用现有 spring。

### 7.2 交互规则

| 场景                    | 处理                                                                                          |
| ----------------------- | --------------------------------------------------------------------------------------------- |
| 路由切换                | 由页面壳负责一次轻微进入；避免页面、分区、子项全部叠加入场造成迟滞                            |
| 局部加载/空态/成功/失败 | 保持稳定容器，由语义状态驱动切换；同状态数据刷新不重播                                        |
| 按钮、开关、选择        | 快速、短距离、明确状态；按钮不在 hover 大幅移动，开关滑块连续响应                             |
| Tabs 与分段选择         | 标记连续移动；旧文本退出与新文本进入衔接，焦点先交接再隔离退出内容                            |
| 弹窗、抽屉、悬浮层      | 遮罩与内容协调，关闭恢复焦点，退出节点不再交互，快速反向操作不中断状态                        |
| 折叠、增删与排序        | 保留仓库既有高度/布局过渡；删除时内容与占位一起退出，焦点接续到有效相邻项或新增入口           |
| 统计数字                | 从当前可见数值继续变化，打断后不跳到旧目标；首帧和减少动效直接显示实际值                      |
| 协作滚动与定位          | 目标以当前容器真实范围为准，越界可结束；新目标可打断，卸载/停止跟随会取消帧；减少动效直接定位 |
| 消息流与富文本输入      | 不按每个 token/字符重播，不让整页参与布局动画；保留当前输入性能边界                           |
| 原文定位高亮            | 仅现有检查高亮保留用户指定的一次划过例外，不扩展到其他动效                                    |

### 7.3 减少动效与性能

所有新增或修改的动态逻辑接入 `useReducedMotion()`；CSS 通过共享变量及系统媒体查询降级。普通动画在减少动效下取消时长或位移/缩放，退出隔离和最终状态仍正确。

动态计算只发生在确有动画的组件，不把全站放进频繁重新测量的布局容器。不动模板缓存、字段订阅、打印快照和真实异步状态，不用固定延时掩盖资源尚未加载。

浏览器审查使用新标签，覆盖已登录业务页和未登录页面。实际保存、生成、投递、删除、AI 调用未在用户数据上执行。静态截图只能证明当前帧，不能证明动画全过程；过渡帧中的淡入、加载和数字变化不直接判为故障。

最终审查报告另行记录检测数量、准确文件位置、误报判断和每页实际覆盖情况。本规格不把尚未运行的验收记为通过。

## 9. 实施组织

完整实现分为四个工作批次，不改变全站交付范围：

1. 公共基础：primitive 状态、动效预设调用、焦点与退出、按钮/输入/Tabs/侧栏、页面壳与反馈组件。
2. 管理与阅读页：首页、简历、模板、优化、分享、公开分享、资料、更新记录、认证和 404。
3. 工作区：跟进、助手、历史、编辑器及跨页流程；核对每个页面对公共变化的适配。
4. 全站复查：实际操作、深浅色、窄屏、减少动效、性能和导出回归；修复后再次通读页面文案。

批次不是用户需要重复批准的范围门禁；书面规格确认后，按覆盖矩阵持续实现并验证至本轮完成。必要的实施计划在规格批准后写入 `docs/superpowers/plans/`。

## 10. 验收标准

### 10.1 页面与状态

- 17 类页面全部记录审查结果、实际改动或保留理由，不能遗留无结论的页面。
- 1440、1024、768、390、320 px 布局检查；主要页面至少保存 1440 / 390 / 320 px 对比证据，工作区额外检查高度不足和软键盘场景。
- 覆盖深浅色、长名称、空结果、加载和失败。除看板、表格或文档明确需要的内部滚动外，不出现页面级横向溢出。
- 关键操作能用键盘完成，有可读名称、可见焦点，关闭后回到有效控件。触屏动作不依赖悬停。
- 实际页面按标题、说明、按钮、状态提示通读，删除重复或无关文案。

### 10.2 动画

- 每类交互检查进入、退出、重复操作和快速反向切换；重要浮层至少两轮完整开关。
- 共享弹窗检查创建简历、创建分享、简历优化；抽屉检查岗位详情、手机侧栏、编辑面板和评论。
- Tabs 检查选中标记、内容、方向键、输入保留与焦点；旧新文字不能叠成残影。
- 列表检查新增、删除中间项/末项、撤回删除和重排；退出项不继续可点击，后续项不二次跳位。
- 系统减少动效覆盖 CSS、Motion、自定义 rAF；检查高亮例外只保留在指定调用点。
- 协作滚动使用不等长容器与超界目标，确认动画能结束；统计在快速连续更新后稳定显示最终值。

### 10.3 性能、数据与导出

- 编辑器连续输入与粘贴各至少 10 秒，覆盖中文组合输入、富文本、已有检查提醒和多页简历；比较处理时长、长任务和内容完整性。
- 模板详情在外层打开完成后再加载重预览，切换示例和关闭重开不丢状态、不重复启用整套分页。
- 涉及编辑/导出交互的变化通过真实出口验证最新正文仍在 PDF；若变动触及打印或文档布局，追加默认模板、短文、页底临界、多页以及背景图形开/关的完整回归。
- 使用隔离的合成数据完成写操作验收，不更改用户岗位、简历、分享权限或投递历史。
- 改动文件运行 Prettier 与 ESLint layout 修复，再执行类型检查、相关 lint、构建；针对实际失败补充验证，不为纯排版创建无价值测试。
- 临时脚本和夹具放 `tests/`，完成后删除。保留不含用户数据的验收说明、覆盖矩阵及必要本机证据。

## 11. 完成定义

2. 布局、文案、交互、动画、减少动效及必要性能/导出检查有实际结果。
3. 记录新问题的触发场景、根因、长期约束和验收方法，更新防回归清单。
4. 汇报真实改动与检查限制，实施完成、验证通过、用户审查通过各自独立。
