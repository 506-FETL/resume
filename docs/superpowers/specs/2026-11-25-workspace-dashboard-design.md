# 首页数据与显示专项

只覆盖侧栏首页 /workspace。按每张卡的实际动作、字段、正式投递记录和所在账户核对首开、返回、故障与重试。在同一生产浏览器比较旧、新两次构建；大账户与局部慢请求用隔离样本，真实接口单独核验。

岗位概况、阶段分布、待办、三组提醒、最近五条岗位动态和七天投递数在调用者权限下汇总；前端继续显示真实总数，提醒只带当前卡片需要的条目。均分只计有数值的报告，未检测份数包含所有真正有报告的简历；两者的分母分开。趋势和汇总分别展示。累计与本周投递按每个岗位的正式投递记录和投递日期计算。

今日待办和动态在第一份可用内容到达时显示，其他来源晚到时补入；局部失败保留已知内容，空态须等相应来源确认。最近简历的两个来源分别重试。真实简历缩略图、缓存失效、跨账户隔离、旧接口兼容按现有契约处理。
