# 编辑检查反馈与布局修正

依据用户 2026-10-26 的九项审查意见，直接在当前分支修正现有交互，不扩大检查规则范围。

## 布局

编辑页隐藏面包屑，导航与主题按钮保留在两侧，操作栏在中间居中。手机端工具栏使用带无障碍名称的图标按钮。填写/检查使用现有 shadcn Tabs，与保存、协作、分享放在同一操作行；窄面板允许自然换行，不再固定占据独立整行。

## 反馈

统一错误红色、待核对黄色、建议蓝色。总体入口采用未处理问题的最高等级，处理完成恢复默认。导出按三个等级分别显示摘要；AI 来源有内容时使用黄色提示。错误仍允许直接导出，保留红色导出按钮。

预览定位必须同时满足：正在编辑当前简历、编辑面板打开、当前处于检查 tab、问题仍在当前筛选结果中且已展开。切换填写、收起问题或面板、进入历史版本立即退出定位。高亮继续使用 Magic UI Highlighter 的 highlight 动画，遵守用户对减少动效的明确例外。移动端保留检查条目中的原文与前往修改入口，不再通过关闭抽屉遗留预览高亮。

填写字段根据未处理问题标记标签与输入边框，同时提供问题说明。该标记独立于预览定位，修正或确认后消失。同字段多问题取最高等级；条目重排后根据稳定 ID 重新匹配；缺失标题的问题只标记标题，其他签名依赖不误标。去掉填写区域顶部残留的检查标题条。

## 滚动与实现边界

保留每个展开模块的最大高度，解除内层阻断滚动链的 overscroll-contain，使触底/触顶后继续滚动父列表。复用现有 shadcn Form、Tabs、Button、Badge 与 Magic UI Highlighter。共享 Form 只增加可选的通用字段反馈上下文，业务问题映射留在编辑页；不修改打印正文、测量或分页算法。

## 验收

桌面与手机实际浏览器验证：工具栏位置、图标名称、紧凑切换、错误/待核对/建议/清空四态、预览高亮退出和严重程度、字段边框/说明、修改后清除、内层滚动链、导出颜色与直接导出。覆盖深色和减少动效，检查无障碍警告。检查面板往返至少两轮及快速切换，确保填写内容和滚动状态不丢失。

## 输入性能补充（同日用户反馈）

连续输入会同步触发本地规则、隐藏的导出检查、排版检查与页面重绘。检查订阅改为独立运行组件；输入停顿 250 ms 后执行文字规则，排版更新复用已有文字结果，已关闭的导出窗口不进行检查。标记仍在编辑时自动更新，导出点击仍核对最新快照；输入等待期间的确认/修改动作需重新校验实际正文签名。用相同离线数据、连续输入及浏览器 CPU 采样比较修复前后，覆盖即时导出和切换简历的边界。
