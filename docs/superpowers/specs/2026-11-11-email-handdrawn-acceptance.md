## 已执行的静态与图像检查

- 使用 XML 解析器检查全部 13 张 SVG，viewBox 均为 `0 0 420 240`，均有可读 title、desc。
- 检查无脚本、动画、外链、外部字体、内嵌栅格、滤镜和渐变。所有场景由可编辑矢量路径组成。
- 检查全部 PNG 为 420×240 RGBA。以实际非透明像素包围盒核验四周至少 16px 安全区，四角透明；最接近边缘的是邀请图顶部 17px、MFA 添加图底部 16px。
- 使用最终格式化 SVG 执行 `python3 scripts/render-email-art.py` 两次，13 张 PNG 的 SHA-256 逐张一致。
- 扫描 13 封邮件 HTML 的图片引用，所有同名 PNG 均存在。没有修改认证 HTML、变量、按钮或链接。
- 对 SVG 显式使用 Prettier 的 HTML parser；默认 parser 无法推断 SVG，此后改用明确 parser 并通过。两个维护生成器通过 Python AST 语法检查，`git diff --check` 通过。
