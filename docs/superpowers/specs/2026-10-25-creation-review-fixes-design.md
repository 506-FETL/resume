# 第二期创建流程审查修正

用户于 2026-10-25 明确要求修正五处体验。按已授权的“开发后审查”执行，最新要求覆盖此前空白创建与自动恢复步骤的设计。

## 交互

- 从零：选择应届生、有工作经验、准备转岗，再选模板并创建。按人群填入完整、明确标记的示例经历；不是空白页。记录示例来源，导出前提醒替换。
- 导入：选择文件或粘贴，核对正文，再选模板并创建。选择模板只改变排版，不混入示例。
- 模板步骤使用已发布目录、精确版本和静态缩略图，分页加载；选中后按钮明确创建。返回修改保留本次选择；保存请求发出后锁定输入，失败沿用同一身份与模板。
- 每次打开固定三个入口。草稿只在主动继续时恢复，恢复内容不意味着自动恢复导航。保存结果未知仍保留重试入口，避免重复创建。
- 标题和底部动作固定，中间单一主滚动区。长输入、原文、模块及模板列表分别验证连续滚轮和反向滚动；不使用滚动事件劫持。
- 删除重复保存说明、长篇填写建议与空页脚。保留一行示例提醒、文件限制及数据用途，错误发生时再给具体原因。

## 数据与验证

沿用账户隔离、精确模板版本、幂等创建和现有检查记录。自带正文的顺序与可见性传入创建流程；证据按最终新 entryId 记录。开关会话版本防止关闭后文件读取结果回写。当前分支工作，不提交不推送，不动 tracker。

验收覆盖三类示例内容与可见性、两条路径选不同模板、导入正文不混示例、反复打开回入口、主动恢复、失败重试与账户切换、滚动中段/底部/反向、桌面和窄屏、两轮弹窗开关与减少动效。执行改动文件格式、layout、lint、类型和构建；临时验证放 tests/，完成删除。
