# 简历优化页面性能

按本期授权，从工作台「简历优化」和岗位深链出发，分别验收打开报告、选择简历、检测、查看过程、打开四个工具以及写后刷新。保持评分依据、证据、用户选择、真实保存和账户访问边界。

- 首次进入只读取当前授权范围的一份报告和选中名称。候选按来源分组、分页查询，分数与对应页匹配。岗位入口先确认归属与准备简历，JD 原文在打开比对时取得。
- 报告、选择器、图表、模型调用、修复、工具的开销按实际用途划分。首屏保留可用标题、操作和评分文本。工具正文、相关分包和岗位原文并发准备，慢分包或失败只影响当前操作。
- 检测、导入本地简历、应用和刷新只处理目标。流终态、保存顺序、版本核对和已完成结果继续使用实际来源。记录优化前后真实浏览器的首屏、弹窗与请求，并覆盖失败、重试、换账户、窄屏、已有报告与无报告。

基线包含上一期已经暂存的模板工作。实施于当前分支，最终交用户审查。
