# 手机端助手画布关闭入口设计

## 背景

助手画布在手机端以接近全屏的右侧 Drawer 展示。由于可点击的遮罩空白区域过窄，用户难以通过点击空白处关闭画布，需要在画布内提供明确、稳定的关闭入口。

## 设计

- 仅修改手机端助手画布，桌面端画布保持现状。
- 在手机端 `DrawerHeader` 右上角放置叉号图标按钮。
- 使用现有 `DrawerClose` 包裹按钮，让关闭行为沿用 Base UI Drawer 的语义、焦点管理和退出动画。
- 标题与说明保留在左侧；关闭按钮位于同一标题栏右侧，不覆盖标签栏或画布内容。
- 按钮使用现有幽灵样式，提供适合触控的点击区域，并设置 `aria-label="关闭画布"`。
- 关闭只改变 `canvasMobileOpen`；当前标签、固定状态和预览内容继续保留，再次打开时恢复原状态。

## 动效与无障碍

- 继续使用 Drawer 既有进入、退出和手势动画，不新增独立动画参数。
- Drawer 已负责减少动效场景的交互降级，本次按钮不引入额外位移或缩放动画。
- 按钮必须可通过键盘聚焦，并通过可访问名称说明用途。

## 验收标准

- 手机端打开画布后，标题栏右上角始终可见叉号按钮。
- 点击叉号后画布关闭并返回聊天界面。
- 再次打开画布时，先前选择的标签与固定状态不变。
- 桌面端只保留原有“收起画布”按钮，不出现重复叉号。
- 连续完成两轮打开与关闭，并验证退出动画尚未完成时重新打开的反向切换。
- 相关 lint、生产构建和助手页面验证通过。

## 范围外

- 不调整手机端 Drawer 的宽度、高度和滑动方向。
- 不更改点击遮罩或滑动关闭行为。
- 不修改桌面端画布布局。
