# 基本信息完整展示与编辑间距修复

## 目标与范围

根据用户反馈，修复政治面貌、自定义字段填写后未展示，以及教育等经历表单的字段与描述紧贴问题。保留现有模板、内容、外观设置和动画；不改简历数据结构，不变更数据库表，不修改已有模板版本。

## 根因

- `resume-comment-core.ts` 的正文投影没有政治面貌、婚姻状况和自定义字段；模板内容依赖该投影，因此即使表单成功保存也无法展示。
- `adapt-profile.ts` 同样没有上述字段。部分模板通过 `fieldKeys` 划分姓名、联系方式和侧栏，简单补充数据仍会被过滤。
- `ResumeFieldFormSection` 的条目正文没有纵向布局间距，多个表单分别输出普通字段组和富文本描述，使两个兄弟块贴在一起。窄侧栏内的日期、自定义字段、技能与证书网格也存在不合理的密集分栏。

## 内容方案

1. 前后端共享投影补充非空政治面貌、婚姻状况及自定义字段；“不填”和空值不进入正文。自定义字段沿用现有数组索引，字段键为 `customFields.<index>`，投影文本仅保留值，标签由内容适配器提供。只填标签没有值时不展示；只有值时仍保留值。
2. 内容适配器将补充信息纳入 `profile.meta` 与 `profile.fields`，继续复用安全文本和评论投影。自定义字段要求展示标签，已有独立标签节点时不重复输出；标签存在判断使用文字映射后的实际结果。
3. 渲染前对各区域实际生效的基本信息节点做覆盖检查，使用与渲染器一致的模块路由和条件作用域。没有被任何区域展示的基本信息，追加到已有基本信息列表，优先元信息列表，其次综合字段列表；继承该列表的模板样式。保留各区域已有字段归属，不重复姓名或联系方式，不修改远端模板，也不按模板 ID 分支。协议校验允许模板显式选择政治面貌和婚姻状况。
4. 测量、预览和 PDF 使用同一补齐逻辑，不修改纸张、字体、分页签名与打印规则。

## 表单方案

- 共用条目容器统一字段组与描述之间的 16px 间距，清理实习模块局部补偿间距。
- 日期行按照编辑面板容器宽度换行，标签与复选框保持间距。
- 自定义字段每行保持标签、值和删除入口，窄宽度不强制多列；输入允许收缩，不挤出面板。
- 技能卡片与证书根据面板宽度减少列数，保留操作入口空间。
- 保留已有入场和布局动效及减少动效设置。

## 验收

使用隔离的本地简历复现政治面貌、自定义字段和间距问题；验证全部已发布模板的字段覆盖、空值和重复标签。真实导出入口覆盖默认、综合信息与侧栏模板的短、临界、多页长内容，核对 PDF 文本、图像和两种背景打印设置。共享投影变更涉及 `resume-comments` 与 `resume-share`，完成依赖检查、部署、函数版本和线上 smoke 检查；数据库迁移账本只读核对。临时脚本位于 `tests/resume-profile-fields/`，完成后移除。
