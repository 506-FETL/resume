补充验收：

- 步骤连接线：1440 / 768 / 390 / 320px × 第 1、2、4 步，共 12 组，三条连接线均有正宽度，无横向溢出，减少动效时过渡归零。`stepper-results.json`。
- 首页真实预览：使用独立浏览器的本地样本记录、公开的默认与阿酥模板及示例正文，读取和渲染均经过产品现有实现。1440 / 1024 / 768 / 390 / 320px 无横向溢出；离屏不启动排版，缺失记录可重试，减少动效归零，深色正常，控制台无业务错误。`home-real-preview-results.json`。
- 真实首页复核：在同一独立浏览器进入正式首页路由，1440px 卡片实际高 156px（含边框）；390px 为 142px；320px 操作自然换行，高 180px。桌面纸张约 92 × 130px，手机约 68 × 96px，正文与所选模板一致，未更改用户原浏览器数据。`home-real-page-1440.png`、`home-real-page-390.png`、`home-real-page-320.png`。
- 缩略图和通过 Portal 挂到 body 的测量副本都设置 inert；带真实链接的正文验证两者均不参与交互。`home-preview-focus-results.json`。
- 初次预览夹具缺少主入口的字体导入，触发原分页字体检查失败；补齐与正式入口一致的字体后通过，没有放宽产品校验。真实首页同时验证通过。

证据目录：`.superpowers/interaction-layout/`。控制台记录中仅保留隔离夹具 favicon 404，以及主动开启减少动效时 Motion 的开发提示；上述最终验收没有业务异常或 animation 属性冲突。

初轮分享下拉滚轮曾在单点采样记录 top=0；后续 6 个独立页面及稳定入场后的四种尺寸均成功滚动，未确认产品滚动故障，因此没有臆测性更改滚动锁。最终脚本使用实际滚轮并断言 scrollTop 增加。

## 动效复核

按 review-animations 检查，并以仓库公共时长、缓动和减少动效规则优先。

| 发现                             | 修正                           | 验收                                                     |
| -------------------------------- | ------------------------------ | -------------------------------------------------------- |
| 退出时清空目标，正文在消失前改变 | 展示快照独立于 open            | 主流程、批量确认和岗位定制退出内容稳定。                 |
| 运行中减少动效移除 animationName | 保留名称，仅将时长归零         | 创建、跟进确认、历史比较实际卸载；公共浮层重复开关通过。 |
| Radix Popper 与业务长属性混写    | 在共享包装层转为 CSS 变量      | 四种浮层保留原预设，无冲突警告。                         |
| 移除入口后焦点落入退出层或空白   | 保留入口引用并提供稳定备用目标 | 分享、会话、批量确认及普通弹窗完成回焦。                 |

未新增复杂时间轴或持续装饰动画。列表、页签、展开和浮层继续使用现有预设；本轮没有改变模板正文尺寸、分页或打印样式。
