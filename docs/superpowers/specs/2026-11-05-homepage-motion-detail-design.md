# 宣传首页的动作与内容细节修整

本轮沿用用户已确认的手绘封面、同一张简历与八幕演示。用户授权继续打磨，先实现、验证，再交付审查；不重新选择视觉方向。

## 发现与边界

- 逐帧测量证明铅笔在两次换笔画时位置连续，不能将 MotionPath 自动补入起点误报为坐标跳变。问题是移动距离很长、滚动区间太短，且检测预览只有很短的完整停留段。
- 标题和部分正文的新旧内容交叉淡化，产生重字。助手两行内容几乎同时写入，完成勾早于最后一行写完。
- 印章工具是镜头的子节点，印迹是已旋转、位移纸张的子节点，两者不能落在同一点；印迹还压到技能栏。
- 排版清单在内容尚未完成时勾选了导出；分享旁白先声称已经投出；“岗位副本”没有对应创建动作；保存版本的长文字被确认标签盖住。
- 跟进只淡入确认结果，缺少确认发生的动作；日期圈虽有绘制进度，却缺少与前文一致的落笔、收笔。

## 调整方式

保持统一滚动时间轴和同一简历节点。每幕遵循进入、动作、结果停留、退出；标题先退出再进入。为检测预览、确认差异和历史对比留出阅读区间，完成标记放在实际写入之后。铅笔用明确的抬笔弧线连接实际路径端点，笔迹仍与笔尖共用进度。

印章与印迹放进纸张的共同坐标系，在正文下方留白处接触后落印；日历先就位，再确认结果与落笔画圈，反滚按相反顺序还原。正文示例仍分别取自产品设计、前端开发项目及本人提供的笔记，不添加成果数字或自动投递能力。

导出能力移到内容完成后的分享说明；排版只勾选实际已发生的步骤。版本保存文案缩短，移除无对应动作的岗位副本标签。分享描述创建固定稿链接，下一幕才记录实际投出。

## 验收

实际页面覆盖两份岗位稿，检查连续滚动、停在半途、倒放、快速反向；采样笔尖/笔迹及印章/纸的共同坐标。核对检测到改写、两人同编、历史版本、分享和投递的内容因果。桌面、手机、平板、短横屏与运行中减少动效均需检查。生产构建与改动文件检查通过后交用户审查。验证脚本放 tests，结束后删除。

## 动效复核

| 修整前                               | 修整后                                             | 原因                                   |
| ------------------------------------ | -------------------------------------------------- | -------------------------------------- |
| 换笔画的长距离移动挤在很短的滚动区间 | 笔尖经过抬笔弧线，再接上下一个笔画的起点           | 笔迹与移动共用进度，正放、倒放都可检查 |
| 标题和历史原句交叉淡化               | 旧字退出后才显示新字                               | 避免不同文本叠成重影                   |
| 助手两行同时显现，完成勾提前         | 先确认，再逐行写入，末行结束后打勾                 | 完成状态对应真实可见的结果             |
| 印章工具在镜头坐标、印迹在纸张坐标   | 二者随同一张纸变换，接触后落印                     | 纸张转动时仍能对准，印迹也不挡正文     |
| 日历和面试状态先出现                 | 确认更新后改变状态，日历落稳后笔尖画圈             | 跟进动作有明确的先后关系               |
| 排版清单提前勾选导出，岗位副本无来源 | 清单只展示排版；导出放到写完的简历旁，去掉副本标签 | 不暗示尚未发生的动作                   |
| 变短后的 scrollY 被当作转屏前的位置  | 保存最近一次真实滚动的相对进度，再按新尺寸还原     | 避免浏览器裁回滚动位置造成倒退         |

滚动时间轴中的时长表示滚动进度，沿用公共 DURATION 控制 scrub。SVG 的笔迹和裁剪进度是本页解释功能所必需的绘制，不替换成整段文字淡入，也没有引入 HTML 尺寸逐帧重排。
