# 求职跟进页面性能优化

本轮覆盖工作台的求职跟进。入口包括桌面看板、桌面列表、窄屏列表、岗位深链及其已有操作。

- 首访并行准备登录会话、当前视图和岗位摘要。看板按阶段呈现首批，列表按默认顺序取首批，继续浏览时取下一批。统计单独读取，归档范围单独缓存。首批之外的目标岗位按主键打开。
- 摘要保留卡片、筛选和历史响应口径所需的信息。阶段笔记、事件和轮次详情在实际需要时读取。缺页时由数据库匹配关键词、公司、关注、阶段和指标。已有完整范围的搜索复用本地摘要。仅公司分组、中文公司名排序和显式全选需要取得全部匹配摘要。加载、故障、真实空结果和完整统计分别处理。
- 操作面板和非当前视图按需加载。滚动中限制同一屏附近需要新建的条目数量，保留完整的筛选范围、拖动目标、键盘操作及原来的退出动效。
- 简历、版本、公司候选按实际用途读取。保留目标写入、数据库时间戳、归属、保存队列、版本冲突和投递幂等机制。已确认的保存结果就地合并，只更新受影响的数据。
- 以真实岗位、详情字段和保存结果出现为终点。同机生产构建对照，另核验小数据、大数据、单个接口变慢、读取失败、换账户和写后重读。

本期按用户已授权的先实施、后验收流程推进。
