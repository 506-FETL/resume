# 个人应用布局优化

## 授权与范围

用户已要求彻底改善全站卡片同质化，强调主次、个人 App 的自然感及自身特色，并明确「首页不用动，主要修改其余页面」。本次直接实施后交用户审查，不重复询问授权。首页所有源文件及现存改动保持原样；不修改导航、数据模型、真实数据、模板正文、分页与导出。

实施状态：完成。验证状态：通过，覆盖与边界见[验收记录](2026-10-31-personal-app-layout-acceptance.md)。用户审查状态：视觉未通过；用户反馈「只是把卡片换成列表，主次和设计感不够」，已进入[二次调整](2026-10-31-personal-app-character-design.md)。

## 方向与参考

采用「文档、链接、报告各有结构」的内容布局。保留现有中性色、中文排版、灰 / 蓝 / 紫简历类型语义及评分语义色。特色来自文档标题、清晰章节、舒展条目和可读批注，而非大卡片、背景装饰或强行增加表格。

- Things：以标题和间距组织连续任务，辅助字段退后。参考 <https://culturedcode.com/things/features/>。
- Notion：轻量列表适合文档及少量属性；真实视觉材料继续用画廊。参考 <https://www.notion.com/help/lists>。
- Craft：文档内容与组织结构相配合。参考 <https://www.craft.do/organize>。
- Linear：按任务分组、选择必要属性；仅借鉴信息组织，不复制后台密度。参考 <https://linear.app/docs/display-options>。

比较过三种方案：只缩小卡片无法解决结构重复；全站表格会变得生硬；本方案根据内容分别使用文档条目、链接列表、报告章节、设置分区。模板画廊、求职看板对象、时间线和对话保留本身合理的结构。

## 页面规格

### 简历库

将等权卡片网格改成无表头的文档列表。名称是第一层，类型、来源、模板及日期是第二层。主动作「继续编辑」清晰可见；岗位版本、分享、更多为次级操作。条目之间使用细分隔，悬停 / 聚焦才出现轻背景，不为每条信息画完整边框。手机纵向排列，长标题自然换行。保留创建、删除、复制、分享、派生、岗位准备和所有状态。骨架与空态同步。

### 分享管理

连续链接条目替代卡片网格。左上角用途保持 label → purpose 分类 → 未设置用途；主标题仍为 display_name，不将自由备注写入权限分类。版本、权限、有效期作为辅助说明，访问数据退为小字；复制为主动作，预览和更多为次级。桌面左右排布，手机纵向自然增高。移除每条底部整块分栏工具条，保留所有菜单、密码、失效、统计与焦点交接。加载、失败、空态均与列表一致。

### 简历优化

从卡片仪表盘改为诊断报告。保留真实评分水印，问题分析为主体，处理清单为辅助。严重程度按章节分组，问题仍可折叠；减少父卡、问题卡、对比卡重复边界。评分依据作为报告正文，保留雷达、维度理由及可读性建议，桌面直接显示、手机继续折叠。工具入口改为紧凑列表，工具弹窗内部使用标题及分隔组织内容，保留所有真实动作、费用说明和修改对比色。

### 编辑器、设置与求职跟进

编辑器仅调整侧栏章节边框与间距，保留常驻节点、拖拽、显隐和折叠，不碰纸张。设置页额度成为同层开放分区，骨架匹配实际分区。求职跟进保留桌面表格 / 看板 / 抽屉契约，仅去掉列表多余外框，手机岗位使用连续行；看板卡保留对象意义。历史仅整理详情内指标、说明、标签与编辑态的重复外卡，时间线与预览保持原样；助手对话和模板画廊不作无意义重写。

## 实现及验收约束

- 组合现有 Button、Badge、Tabs、Dialog、DropdownMenu、Collapsible、Empty、Skeleton 等；普通语义布局不新增 UI 库。不修改全局 Card primitive。
- 复用公共动效及动态减少动效；不新增固定时长、数据请求或全局状态。交互顺序与 DOM 顺序一致。
- 桌面、390 / 320 px，长标题、空态、加载、失败、深色及键盘焦点必须覆盖。对实际变动的菜单、折叠、弹窗做重复开关检查。
- 使用真实业务组件的隔离样本进行可重复验收，不写入真实账户，不触发 AI 付费请求。临时脚本和样本放 tests/，结束删除。
- 局部 Prettier、ESLint layout 修复，类型检查、构建与最终差异检查。记录实施、验证、用户审查三种独立状态。
