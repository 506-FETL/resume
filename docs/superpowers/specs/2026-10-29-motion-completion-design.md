# 六项动效补齐设计

日期：2026-10-29。用户已明确授权按六个方向写计划、直接实施、实测并修复发现的问题。本设计记录这次授权的具体范围，不重复索要批准。上一轮依据见[全站验收](2026-10-29-frontend-refinement-acceptance.md)，文件重复与排版问题已先行修复。

## 目标与边界

缩短高频交互等待，补齐手势、视口与异步状态的连续反馈，降低流式输出期间的动画成本。保留当前页面布局、首页局部渐变、ATS 字体与分数语义，不改简历正文、模板几何、分页、数据库或模型协议。当前分支开发，不提交、不推送，不操作用户真实业务数据。

使用 brainstorming 明确取舍，writing-plans 编排实施，transitions-dev 的数字、页签、面板、状态及流式参考指导设计，animation-performance 定位成本，review-animations 做最终复核。按仓库已有组件和 token 适配参考，不复制不适用的 primitive 属性和昂贵的默认效果。本轮没有复杂时间轴或滚动编排，不新增 GSAP 依赖。

## 1. 数字

首页 NumberTicker 的 stiffness=100、damping=60 无明确完成时间，小幅统计变化也长时间收尾。改为公共 slow 档 280ms 有界插值，首次可见从 startValue 进入，更新从当前显示值接续；保留 direction、小数、延迟与实际最终值。写入单个文字节点，不通过逐帧 React state 更新卡片。减少动效途中切换立即落在目标值，恢复后不回放旧数字。跟进 useCountUp 已为 140ms，先验证再决定是否修改。

## 2. 高频页签与视图

现有退出 140ms + 进入 200ms 合计 340ms，快速连续操作显得迟缓。新增有语义的共享切换档：退出 fast/2=70ms、进入 fast=140ms，总计 210ms；位移缩至 4px，使用完整 transform 字符串。公共 Tabs、跟进抽屉页签/看板列表与历史详情常驻面板复用，助手画布按相同档位衔接。

继续先退后进，避免两组文字同时可见；选中指示及时响应，快速反向从当前状态接续。保留 forceMount 的 DOM、输入、滚动和焦点交接。按本仓库约定保留短过渡，减少动效归零，不照搬技能中删除全部键盘过渡的通用建议。

## 3. 移动抽屉

共享 CSS 已覆盖旧字面时长为 280/140ms，不把源码旧值当作实际性能证据。已复现编辑抽屉在 visualViewport 缩小时不避让键盘；复用 Base UI DrawerVirtualKeyboardProvider 与既有评论抽屉模式，接通 viewport inset 约束，避免另写 keyboard hook。表单滚动、选字与下拉交给现有 primitive，不用大面积手势捕获抢输入。

清理不需要的 height/filter 过渡；保留必要的嵌套抽屉反馈。验证上下滚动、手柄拖动与取消、两轮开关、退出反向、焦点和实时减少动效。模拟 visualViewport 和 CDP touch 属于浏览器模拟，不宣称已完成 iOS/Android 系统键盘实机验收。

## 4. 拖拽

已确认自动滚动在到达边界后仍续帧，且缺少另一轴命中限制；指针事件每次做多组几何读取；鼠标拖拽缺少 Escape；源节点卸载保护只覆盖键盘；预览释放时立即移除。

按帧合并最新坐标，滚动按实际 delta 决定是否继续，越过容器另一轴时停止。取消、失焦、pointer/touch cancel 与源移除共用清理；正常单击不受影响，拖动后的合成 click 不误开详情。合法提交保留业务回调并短淡出；取消回到当前真实源位置。跟进按状态排序，不添加暗示自由排序的插入线；终态确认/请求成功之前不假装卡片已完成业务移动。新拾取、取消途中重开和减少动效可打断预览收尾。

## 5. 助手流式输出

Shimmer 的 backgroundPosition 无限动画与 Markdown 更新争用主线程；实际对照确认的是样式与脚本工作，当前 Chrome 没有记录到等待动画的逐帧 Paint；改为小面积固定文字高亮的 opacity 呼吸。消息及输入器的全 store 订阅、历史气泡缺少 memo 使每次 token 更新重复执行无关 UI；仅收窄真实依赖与稳定历史节点，不改流式合帧、取消、持久化和工具调用协议。

工具 pending/result/error/cancelled 分别显示真实状态；只给流中新增内容轻入场，历史加载不重播。保留用户主动上滚的位置和停止后的焦点。使用相同合成长历史、10 秒流式输入对比渲染、帧间隔、长任务及 Paint/Layout，不把桌面 CPU 降速等同真实手机 GPU。

## 6. 异步反馈

覆盖保存 idle/pending/saving/saved/error、失败重试、加载完成、操作取消与通知。优先修复真实反馈组件，不为测试增加产品内入口。跟进保存反馈现有重试按钮瞬间出现/消失、文字串行延迟且失败消失时可能丢焦点；将状态文字和可操作入口作为一次语义切换，保留即时读屏状态，退出入口不可重复提交，重试后焦点回到稳定状态容器。复核 Sonner 的加载→成功/失败、手动关闭及减少动效；已有实现合格则保留。

## 验收与交付

使用真实组件的隔离合成场景覆盖正常/异常/取消，真实登录页面只读抽查。至少 320/390/1440px；重点浮层两轮开关及反向；减少动效在运行中开启与恢复；检查焦点、aria warning、文字叠帧、最终值与残留动画。临时脚本分别放 tests/motion-finish-\*，验收后只删除本轮脚本，证据保留 .superpowers/motion-finish-20261029/。最后类型检查、ESLint、Prettier、生产构建与差异复查；实施、验证、用户审查分开记录。
