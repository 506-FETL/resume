# 当前简历更换模板设计规格

日期：2026-10-23。状态：讨论结论已获用户授权，直接编写计划并实施，无需再次确认。

## 目标与范围

在编辑器「模版设置」中更换当前简历的模板。选择过程使用当前简历的真实内容预览，确认应用后才修改模板绑定；保留内容、名称、照片、条目 ID、模块顺序、显隐和全部现有外观设置。复用云端模板协议、资源缓存、分页、保存和协作链路，不引入数据库迁移，不复制示例内容，不创建新简历。

## 入口与布局

- 保留现有主题选择，在下方增加「更换模板」设置项、「选择模板」按钮及当前模板名称；有可撤销记录时提供「撤销上次更换」。
- 点击按钮关闭小菜单，打开独立的大弹窗。弹窗标题为「更换模板」，说明当前使用的模板；左侧完整分页预览，右侧模板卡片、风格/排版筛选。底部固定取消和应用按钮。
- 桌面右侧独立滚动。移动端使用接近全屏的弹窗，提供「选择模板 / 简历预览」切换，保留页数和应用入口。
- 卡片展示静态示例缩略图与模板名称；实际大预览始终使用当前简历内容。分别标记「当前使用」「预览中」，避免把示例人物误认为当前简历。
- 未筛选时当前精确版本优先显示。筛选后仅展示匹配结果，顶部当前使用名称始终可见。当前旧版与同模板新版分开显示，新版标记「新版」，不自动升级。
- 初始和每次追加最多请求 12 个目录项，接近列表底部再追加，提供手动加载与失败重试。筛选缓存和图片、定义、资源缓存复用，加载过的结果不人为增加等待时间。

## 预览状态与应用事务

1. 打开时记录当前文档会话，选择当前精确模板版本，读取当前内容和外观。
2. 选择候选仅改变页面内的临时状态，不写入表单、持久化存储或协作文档。
3. 候选定义、图片资源和真实分页准备好以前，保留上一份可见预览，并明确显示候选准备状态；首次打开尚无预览时显示真实加载状态。
4. 快速连续选择只接受最新候选。预览就绪证据绑定候选、内容、外观和参考日期；内容发生变化后重新分页，就绪前不能应用旧结果。
5. 应用时再次校验文档会话、编辑权限、选中版本及预览就绪证据，只写 `templateBinding`，不写旧的整个快照。
6. 应用成功后关闭弹窗，编辑器正常重排，并通过现有保存/协作链路同步。提示「已更换模板」和撤销入口；保存网络失败保留本地更换，由现有未同步状态与重试机制负责，不错误提示已同步。
7. 当前精确版本的按钮为禁用的「当前正在使用」。取消、关闭和 Esc 均丢弃候选，不产生保存。

只读历史/分享版本审阅时入口不可用。若打开期间进入只读状态或切换简历会话，则关闭弹窗，清除临时预览和撤销。下架的当前模板仍按其精确引用显示；候选目录只使用已上架模板。

## 内容与外观约束

更换和撤销只涉及 `source + templateId + templateVersion`。所有原始数据保持不变：姓名与简历名称分离，照片、文本、数组条目 ID、order、visibility 不改变；theme、font、字号、行高、模块间距和页边距全部保留，不使用候选的 appearanceDefaults。布局位置和页数可随模板改变，各区域继续遵从已有模块顺序。

所有模板都允许选择。根据实际模板节点树判断是否存在照片节点，包括区域覆盖。当前有照片、候选不展示照片时，选中卡片与预览说明显示「此模板不展示照片，照片仍会保留」。不根据模板 ID 写分支，也不为了提前显示警告批量下载全部模板定义。

## 协作与撤销

- 模态框内的选择只在本地，正式应用通过现有 Automerge 模板绑定同步。
- 内容、外观协作变化进入当前预览。收到另一次实际模板绑定变化时，更新顶部当前使用标识，保留本地候选，提示「当前模板已更换为 X」，应用按钮改为「仍应用所选模板」。
- 撤销保存最近一次本地应用的前后模板绑定、会话和唯一操作标识。只在当前绑定仍等于本次应用结果且会话一致时生效。
- 撤销不恢复内容/外观旧快照；期间的文字、照片、排版调整全部保留。下一次本地更换替换记录；收到其他模板变化、离开简历、切换会话或刷新使记录失效。过期 Toast 的撤销操作不得覆盖更新后的模板。
- 下拉菜单提供持续到本编辑会话结束的撤销入口，Toast 消失后仍可用。

## 缓存、离线与失败

目录分页状态独立于模板库页面，底层目录请求缓存、精确版本定义缓存与图片缓存共享。只为当前/候选真实预览准备定义和资源，不一次渲染全库简历。旧预览与待就绪候选最多同时保留两份。

缓存完整的定义及所需资源可离线应用，仍需真实分页就绪；只有缩略图不视为可用。离线未缓存时显示「联网后可使用」，禁止应用；联网失败则提供重试。离线简历沿用本地持久化，在线简历掉线沿用现有待同步处理。目录、名称和候选资源加载分别管理状态，不由共享 loading 阻塞无关区域。

## 动效与无障碍

复用现有 Dialog/Select 和 motion 预设，保留进入、退出、卡片筛选及预览切换动画。所有新增动画接入 useReducedMotion。每个 DialogContent 关联说明；焦点进入弹窗、关闭返回工具栏，键盘可以选择模板和应用。加载状态使用 aria-live，当前选择有 aria-pressed，错误可重试。

## 验收

- 更换/取消/撤销前后深比较内容、ID、顺序、显隐及外观；仅模板绑定允许变化。
- 连续快速选择、内容更新时应用门禁、过期加载响应、过期 Toast、远端模板变化和会话切换均不能写错文档。
- 目录每页 12 项，筛选往返不重复下载已缓存定义/缩略图；完整缓存离线成功，缺资源离线不可应用。
- 桌面与移动端；弹窗连续两轮打开/关闭和退出未完再次打开；减少动效模式。
- 真实导出入口验证更换后默认模板、单栏和双栏；短内容、页底临界及多页长内容，背景图形开/关。保持现有测量/展示/打印几何与保色规则。
- 类型检查、修改范围 ESLint、生产构建、独立代码审查。新增验证脚本及数据只放 tests/，完成后移出仓库；文档记录命令与实际结果。
