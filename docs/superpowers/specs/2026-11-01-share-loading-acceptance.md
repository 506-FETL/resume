# 分享链接打开耗时排查与修复

日期：2026-11-01。

实施完成；验证结果见下文；用户审查待进行。修改位于当前分支，未提交、未推送，也未发布前端。没有修改数据库迁移或 Edge Functions，无需部署 Supabase 后端。

## 根因与证据

使用用户提供的当前内容分享链接，以独立 Chrome 无缓存上下文读取。测量请求使用已有的 `refresh: true`，避免反复增加访问统计；没有修改用户简历或发布记录。

1. 应用入口静态引用 `DashboardShell`，后者经 `SiteHeader` 加载编辑器工具栏。公开阅读的 `useShareView` 又从包含分享管理逻辑的 `share.ts` 导入；其历史 barrel 会引用恢复与 Automerge。页面尚未请求正文，已下载并初始化协作 WASM。
2. 原 `tiptap-editor` 手工分组收进 `use-sync-external-store` shim，而 Radix Avatar 也依赖该模块，形成 `tiptap-editor → radix-ui → tiptap-editor` 循环，使编辑器包进入 HTML 预加载。
3. 当前 Supabase 项目数据库位于 `us-east-1`，默认分享请求实际在 `ap-northeast-2` 执行。分享读取包含多次顺序数据库查询，跨区网络等待叠加；函数日志与 `Server-Timing` 均确认接口自身耗时明显。

线上原始页面一次冷载约 8.79 秒出现阅读区，其中首个分享请求约在 2.62 秒发出，服务端处理约 5.09 秒。此数值仅记录本次环境，不代表所有用户的固定等待时间。

## 修复

- `DashboardShell`、`JobContextGate` 按路由动态加载；额度弹窗仅在应用路由加载。保留原有登录判断、恢复回调、页面过渡与 Suspense。
- 公开读取与响应解析移入 `share-view.ts`，不再经过分享管理、历史恢复和协作代码。请求体、密码、条件刷新、取消、响应校验和 `no-store` 继续沿用。
- 分享读取默认指定当前数据库区域 `us-east-1`；提供 `VITE_RESUME_SHARE_FUNCTION_REGION`，自托管可设置实际数据库区域或 `auto`，并补充说明。
- 移除编辑器手工分组，保留现有动态导入边界，让构建器拆分共享依赖。没有更改编辑器、分页、字体或模板实现。

## 性能对照

同一线上分享、同一脚本交替读取自动区域与数据库区域，返回 `content_revision` 一致：

| 轮次 | 自动区域端到端 | 数据库区域端到端 | 自动区域服务端 | 数据库区域服务端 |
| ---- | -------------- | ---------------- | -------------- | ---------------- |
| 1    | 3852 ms        | 990 ms           | 3175 ms        | 517 ms           |
| 2    | 1766 ms        | 918 ms           | 1531 ms        | 429 ms           |
| 3    | 1698 ms        | 872 ms           | 1448 ms        | 357 ms           |

自动区域响应头为 `ap-northeast-2`，指定区域为 `us-east-1`。端到端中位数由 1766 ms 降至 918 ms，约减少 48%；服务端中位数约减少 72%。没有增加正文缓存或跳过权限校验。

相同分享、冷浏览器上下文、生产构建的资源对照：

| 指标                | 修改前      | 修改后      |
| ------------------- | ----------- | ----------- |
| 已加载资源解压体积  | 6,665,452 B | 2,936,796 B |
| JS 与 WASM 解压体积 | 5,076,021 B | 1,347,365 B |
| 协作 WASM           | 2,751,061 B | 无请求      |
| 富文本编辑器        | 首屏请求    | 无请求      |

总资源解压体积减少约 56%，JS 与 WASM 减少约 73%。这是解压后体积，不能当作压缩传输流量。修改后本地生产构建配合真实云端接口约 2.39 秒出现阅读区；它与线上静态资源的加载环境不同，不将 8.79 → 2.39 秒声称为线上发布后的收益。

## 验收

- 真实云端分享：正文及精确模板正常；无变化刷新保留同一预览 DOM；缩放与适宽正常；评论面板连续两轮打开和关闭；没有浏览器执行错误或无障碍警告。
- 从真实“下载 PDF”按钮进入：字体、图片、分页签名与打印区域验证通过；取得通过校验的打印副本并输出一页 PDF，提取正文包含教育、工作、项目与自我评价章节。
- 390px、深色与减少动效：阅读区可见，页面无横向溢出，截图通读正常。
- 通过请求边界控制响应、继续使用正式前端组件：密码提示、错误密码、正确密码进入阅读；网络失败保留旧正文，恢复后更新；权限失效移除正文；历史分享保持“固定内容”与低频刷新。这些属于前端回归，不冒称线上密码与权限写入验收。
- 匿名入口回归：首页、分享管理、求职跟进、简历库、编辑页入口、登录和密码重置均可加载，没有运行时错误。
- 使用独立浏览器的临时本地简历验证编辑入口，协作 WASM 按需加载，姓名输入和富文本编辑可更新真实预览；未使用真实账户写入云端。
- 应用与工具配置 TypeScript 检查通过；定向 ESLint 无错误，分享 hook 的既有 ref 命名 warning 仍保留；生产构建通过，原编辑器循环分包警告消失，其他既有大包体积提示仍存在。
- 清理临时测试后，完整 `pnpm format:check` 通过：ESLint 为 0 errors、68 warnings，Prettier 全部通过；未扩展范围处理既有 warning。`git diff --check` 通过。

临时脚本、页面响应、截图和 PDF 均在 `tests/share-loading/` 验收后删除，保留本文作为证据摘要。
