## 焦点警告修复

用户报告公司选择框右侧箭头保留焦点，父级 input-group-addon 被 Base UI 隐藏。Chrome 中对箭头执行 Enter，复现 activeElement 为 button 且祖先 aria-hidden=true。安装版本的 Base UI 对外置输入框保持 initialFocus=false，触摸箭头及 Enter 不经过普通鼠标的输入框回焦路径。

修复仅在输入框内置箭头上处理：mousedown 捕获时阻止默认按钮抢焦并先聚焦输入框，click 捕获补齐键盘与虚拟点击；保留浮层的 aria-hidden 管理，不屏蔽日志，不用延时。箭头和清空按钮补可访问名称。

Chrome 验证两轮 Enter / Escape、鼠标选择、清空、快速反向开关，焦点均在输入框且不在 aria-hidden / inert 祖先中。抽查新增职位的职位名称与地点选择框，Escape 只关闭选择层；取消新增未写入数据。最终验证控制台 warn / error 为空。
