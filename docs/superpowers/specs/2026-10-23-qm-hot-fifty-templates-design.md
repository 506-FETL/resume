# 新增 50 套模板设计

日期：2026-10-23。沿用用户已批准的十套复刻架构，本次是新增五十套的资源扩充。用户已授权实施、云端发布和 PDF 验证；当前分支工作，不推送远端。

## 选型

热门在线模板及 Word 模板库按热度选款。在线热门页目前有 59 款，排除已有十款和原有两套的近似参考后不足五十，使用站内 Word 热门库补齐。英文翻译、仅换色、仅换示例内容不作为独立款式。以页头结构、区域分配、章节标题、时间线与装饰组合判断是否相似，最终五十条来源与排除理由单独记录。

已有来源排除：在线 1015、1044、1054、1057、1058、1012、1056、1005、1046、1011；另排除与默认及经典蓝金相近的 1045、1004。Word 与在线编号不是同一命名空间，必须按实际图片判重。

## 实现边界

- 继续使用 schemaVersion 3 / declarative-page@1；远端 JSON 定义结构、样式、矢量与区域。前端仅解释公共协议，不增加按模板 ID 分支或五十个专属 React 组件。
- 每套模板有独立稳定 ID、版本 1、名称、风格、栏数、简介与两个示例预览。保留现有十二套及其版本。
- 复用 graduate@2 和 frontend@2 示例，保留可编辑语义字段、模块排序和隐藏行为。参考站人物、姓名、联系方式、二维码与正文不作为模板静态内容。
- 优先纯资源扩充。发现协议确实无法表达的必要结构时才扩展公共能力，并对现有默认模板追加回归；不以整页截图充当可编辑模板。
- 图片与字体准备完成后生成预览。列表继续分页，每批十二套；已加载资源复用，正常进退场动效保留。
- 不恢复已按用户要求清理的 template-resources 等仓库根目录。发布输入、原图、大型截图和 PDF 存放临时工作目录，验收工具在 tests/ 执行；按后续更新的 AGENTS.md，全部完成后清理本次新增测试目录，仓库保留简明记录。

在线 1034 的左右交错卡片需要增加公共 `item-parity` 能力：重复项条件可比较 `item.parity` 的 odd/even，按过滤后可见项从第一项为 odd 计算。两个互斥分支仍绑定真实字段，不设置条目数量上限；未声明能力、错误作用域或非法比较值拒绝解析。测量、展示和打印复用相同解释器，不引入模板专属代码。

## 验收与发布

逐套检查原图和渲染结果的页头、照片、章节标题、栏宽、主色和装饰，不用协议校验代替视觉验收。文字使用项目字体和虚构示例，明确记录字形与内容差异。

每套覆盖短、接近页底的临界和长内容，经正式 useResumePrint 入口通过字体、图片、分页签名及实际裁切检查，再输出背景关闭/开启的 PDF，至少 300 份。检查 A4 尺寸、文本无缺失/重复、末尾标记及两种背景的实际栅格图。双栏额外覆盖主栏长、侧栏长、两栏长与空区域。默认模板在公共分页/打印发生变化时同步回归。

发布前校验定义、示例引用、素材哈希、预览尺寸、重复 ID 及精确数量。考虑请求体大小，不可变素材与未列出的定义分批上传，先经匿名 API 回验，再以单事务发布五十条目录；缺少资源、哈希不符或目录冲突时不切换目录。云端目录预期十二加五十，共六十二套。公开 API 回读比对哈希、版本与名称，实际浏览器验证分页、筛选、预览、创建及导出。若有数据库迁移或函数改动，负责部署、账本及版本核验；没有此类变更则明确记录纯资源发布。
