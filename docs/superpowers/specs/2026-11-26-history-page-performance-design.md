# 历史版本页面性能

本期按逐页验收安排，沿工作台历史版本的真实入口检查目标确认、时间线、详情和写入。沿用历史页已确认的双栏、手机列表和详情切换、筛选语义、真实版式、草稿、恢复确认及投递日期投影。

- 普通入口使用登录账号与当前简历启动独立读取。无云端目标时最多探测一份候选，用户展开选择器后按批读取。岗位入口先核验归属，不读取用不到的 JD 正文。选中的简历或岗位可以位于候选第一页以外。
- 时间线用当前筛选范围的一批元信息和精确计数展示，跨页搜索、重点筛选和最新版本同步状态须符合整份简历。只读选中版本的快照，按目标复用真实结果和在途请求。已确认的保存、修改、删除和恢复结果只刷新受影响的数据。
- 真实可见的预览、比较、导出按使用时机取得所需模块和内容。保持恢复和备份顺序、保存去重与打印校验，保留关闭、退出和减少动效。
- 以同机冷启动和操作后的真实版本、纸张或保存读回验收。分别记录固定延迟样本与真实服务，并区分实现、验证和用户审查。
