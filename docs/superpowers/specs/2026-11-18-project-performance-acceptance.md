# 全项目性能排查与验收

日期：2026-11-18。对应[设计](2026-11-18-project-performance-design.md)与[计划](../plans/2026-11-18-project-performance.md)。本期在当前分支实施，不推送远端。业务操作均使用隔离的合成账号与数据。

## 测量方法

- 使用本机 Chrome、Vite 生产预览与 Lighthouse 13.6.0。优化前构建独立保留，分别运行桌面和默认手机模拟配置；开发服务器的时间不计入生产收益。
- Lighthouse 工作台数据为匿名空状态。登录后的真实创建、编辑、保存、分享、档案、岗位、历史、助手与检测另走完整入口，不能把匿名跑分当作全部功能表现。
- 使用 Chrome DevTools Performance 类别的 CDP trace 检查主线程、布局与网络。按目标 frame/process 隔离编辑页记录，不将其他验收标签的活动算入。
- 请求时序记录浏览器实际网络、字段投影和 Edge 响应地区。数据库密集函数仍在 `us-east-1`，模型函数实测在 `ap-northeast-1`；未移动数据库或调整套餐。

## 确认根因与修复

### 无关资源提前加载

- 首页空态也下载含 Recharts / Redux / D3 的约 298 KB 解压分包。拆成图表外壳与实际绘图模块，只有存在可绘制数据且接近视野才加载，保留标题、单次评分摘要、原高度与局部重试。实际图表 503 仅影响该卡片，重试后正常绘制。
- 创建入口提前引入导入解析、模板流程与预览依赖。现在实际打开才加载向导，导入结果与模板列表按步骤加载。草稿、创建锁、取消、卸载提醒和原保存队列保持。
- 模板列表提前引入完整预览工作区。列表继续使用静态缩略图，打开预览后才加载正文排版。
- 管理页面全局导入多套简历字体声明。移到共同简历渲染入口，富文本编辑器保留自身需要的字体；字体文件、参数、字体等待和打印门禁保持不变。
- 空助手提前下载回复解析与代码高亮。正文解析按实际消息加载，发送通过原校验后立即预取，与会话准备和模型请求并行；仅代码块需要高亮引擎，未完成高亮仍可读取、复制和下载原文。

构建中原名 `mermaid-*` 的约 907 KB 分包实际包含助手 SDK、Markdown/HTML 解析等聚合模块，不能把它描述为删除了同体积的 Mermaid 引擎。分包名本身不代表根因。

### 新建后重复读取完整正文

基线的新建流程在 INSERT 成功后只留下摘要。编辑入口并行读取协作快照与外观，确认尚无 CRDT 后，又串行读取刚插入的完整配置；该样本的重复 GET 耗时 1287 ms。

现在 INSERT RETURNING 返回实际保存的白名单配置，仅保留一次初始化交接。编辑仍读取快照与外观，用账户代次、目标与 `updated_at` 核对；已有 CRDT 优先，版本不同、换账号、失败重试或非创建入口走原权威读取。幂等存在性查询、旧保存队列与首次 CRDT 持久化没有删除。

真实创建确认：快照 RPC 与外观读取同时发起，没有完整配置 GET，首次 `automerge_documents` POST 仍成功。修改姓名后，云端回读和刷新恢复正确。9 组直接运行真实 DocumentManager、Automerge Repo 和编解码的受控验证覆盖创建返回值、已有文档、版本变化、失败、A→B→A 与目标切换；只替换外部 I/O 边界。

首次创建与后续样本的模板缓存、示例内容和观察窗口不同，不给出总启动时间的固定倍数。一次等待 `resumeId` 查询参数的探针超时，是编辑器正常清理 URL 后的错误等待条件，页面正文和表单实际已可用，未将其记为产品失败或性能通过。

### 模型长等待与流终态

真实 ATS 检测约 152 秒中断，只有不完整 JSON，账本未即时收尾。核对线上源码与日志后确认 Free worker 的 150 秒墙钟限制，以及未明确推理强度导致的默认高强度思考。120 秒 fetch abort 未直接停止已取得的 body reader。

已保留思考模式并明确低强度，要求完整结束标记；超时直接取消 reader、发送明确 SSE 错误并按原事务释放或结算部分交付。已部署 `llm-proxy` v52，线上超时约 121 秒正确结束，成功调用也经真实 UI 落库。模型耗时仍受上游波动影响，不能承诺所有检测快速完成。日期判断基准、最终质量核对、迁移账本及部署文件验证见[ATS 专项记录](2026-11-18-ats-performance-acceptance.md)。

### 按需加载的交互回归

实际故障测试发现并修复两类新边界：

- 分包内的 `<form>` 尚未挂载，外层提交按钮仍可点击。改用真实 form ref 启用创建按钮，桌面与手机分别跟踪；草稿或模板数据 ready 不能替代表单挂载。
- 历史搜索先按正文骨架定位，高亮在正文加载前结束。改为等真实正文后调用原滚动组件并启动高亮；其他已经失败且高度稳定的消息不阻塞目标独立重试。慢分包、503、切会话取消和减少动效均经实际浏览器验证。

## PDF 与 Performance 验收

- 默认与经典蓝金两模板，Noto Sans SC 与 Tinos/中文回退；短内容、页底临界和长文；优化前后及背景关闭/开启共 24 份 PDF、36 页。
- 12 次真实导出按钮通过正式字体、分页签名与区域校验。六组前后高度/签名相同；临界距页底分别为 4.45 px、11.27 px；长文分别两页、三页。
- 24 组前后/背景图像对照逐像素一致，1108 次唯一标题与完整段落计数正确；人工查看临界页和多页续页，无缺色、空白页、裁字或重叠。
- 首轮验收工具在 `about:blank` 重放导致样式未完整应用，两版都出现裁切；改用同 HTTP origin，并逐次核对重放高度与正式测量一致后重新导出。该工具失败未记作产品通过。
- 编辑 Performance 样本中，基线最长主线程任务约 115 ms、最长 Layout 37 ms；优化后样本约 80 ms、10 ms。两段 trace 的时长、内容与操作窗口不同，主线程累计值不作直接收益对比；主要可归因收益采用相同条件的 Lighthouse 与已消除的请求证明。
- PDF 覆盖 Chrome 桌面，不代表 Safari、iOS 真机、全部字体或全部 100 套模板均已回归。
