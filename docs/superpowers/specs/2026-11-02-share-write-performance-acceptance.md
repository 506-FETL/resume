# 分享创建与设置保存性能验收

日期：2026-11-02。用户已授权本期实施。实现已完成，功能与页面验证通过，用户审查待进行。当前分支，没有提交、推送或改动暂存区。

## 根因与修复

- 管理端没有沿用公开读取的区域配置。数据库位于 us-east-1，真实旧版管理写请求在 ap-northeast-2 执行；鉴权、归属查询、限流、UPDATE 和通知涉及多次跨区域往返。现在公开读取和管理写入共用区域 URL，默认 us-east-1，保留环境变量及 auto 选择。
- 保存成功后仍等待评论范围查询、事件写入和两频道广播。现在 UPDATE 同步完成并返回实际生效的发布、版本与评论策略，再使用已有后台任务机制发通知；去掉一次重复分享查询。公开及评论权限继续每次重查数据库，授权不依赖通知到达。
- 创建来源准备完成后，原链路需要 INSERT、publish、一次被丢弃的 GET、启用 PATCH、最终 GET；带密码还需调用 Edge。新增 SECURITY INVOKER 创建事务复用原 publish，普通创建变为 RPC + 最终 GET，有密码为 RPC + 设置密码并启用的 Edge + 最终 GET。没有提前关闭弹窗或假报保存成功。
- 正式投递从当前版本创建时，复用冻结操作返回的完整版本，去掉一次重复版本读取；仍等待编辑器保存，保留正式投递固定版本、岗位归属、来源和修订检查。
- 分享 store 的写入回填复用已有账户代次门禁；慢写期间切换账户，再切回同一账户，旧请求不能污染新会话或移除新请求的 pending 状态。

没有发现秒级 SQL 热点或锁等待证据。原 publish 累计平均约 26–36 ms、最大约 107 ms；没有盲目增加索引、降低 PBKDF2 强度或删掉权限检查。authenticated 请求仍保留 Authorization 和必要的 OPTIONS 预检。

## 真实公网对照

同机独立 Chrome 上下文、相同合成账户与合成简历、真实默认模板、生产构建、本地 preview 连接真实云端。基线使用旧前端与 resume-share v46；优化后使用新前端与 v47。无 HTTP 模拟或限速。创建各测 1 次，设置连续测 3 次；计时从按钮操作开始直到弹窗退出完成，包括真实请求与 UI 过渡，不是单独的函数耗时。

| 操作              |    本期前 |   本期后 |
| ----------------- | --------: | -------: |
| 无密码创建        |  6.579 秒 | 5.061 秒 |
| 带密码创建        | 16.669 秒 | 5.015 秒 |
| 设置保存，第 1 次 |  8.625 秒 | 1.551 秒 |
| 设置保存，第 2 次 |  5.564 秒 | 1.557 秒 |
| 设置保存，第 3 次 |  4.555 秒 | 1.056 秒 |
| 设置保存中位数    |  5.564 秒 | 1.551 秒 |

无密码创建约减少 23%，带密码约减少 70%，设置保存中位数约减少 72%。样本有限且包含公网波动、预检与冷启动，不能解释为所有用户的固定收益或 SLA。无密码创建仍要读取简历、模板、当前版本及最终管理记录，本轮没有消除这些必要网络成本。

三次设置 Edge 请求从 7841 / 4918 / 3922 ms（首尔）变为 772 / 721 / 617 ms（us-east-1）；新 Server-Timing 为 334 / 190 / 158 ms。密码创建中的 Edge 从 12655 ms 变为 1440 ms，新函数内部 384 ms。客户端总时长与 Edge 内部时间分别记录，不能混用。

作为区域因素的辅助验证，旧 v46 仅指定 us-east-1 的三次同类 API 请求为 2127 / 1009 / 1041 ms，内部 1427 / 448 / 442 ms。说明区域本身是主要问题之一；这不是与真实 UI 完全等价的基准。

## 权限、事务与兼容验证

- 独立 PostgreSQL 17.11，以云端纯结构恢复后应用新迁移，19 项真实数据库检查通过：匿名/无主体/跨账户拒绝、敏感列拒读、current/history、密码预备状态、隐私触发器、正式投递约束、修订/日期/锚点失败零残留、旧 publish、双连接锁序、冻结并发和 3 秒锁超时。
- 真实 Edge handler、Supabase SDK、ES256/JWKS 和 PBKDF2，在 HTTP 边界隔离验证 20 项：UPDATE 完成前不返回成功，通知不阻塞；使用真实 UPDATE 返回策略；密码与启用同一 UPDATE；鉴权、类型、限流、更新失败/缺行拒绝；通知失败记录日志；旧 set_password 兼容。
- 真实前端模块与 SDK 在 HTTP 边界验证 15 项及 3 种区域配置：两种创建请求链、密码失败清理、发布去重、冻结版本复用、错误和账户往返隔离。不是把实现逻辑复制进测试。
- 云端合成数据 smoke 通过：密码访问；改密码后旧密码、分享凭据和评论凭据失效；隐藏电话/邮箱后正文脱敏、实际评论策略为 false、旧凭据拒绝；后台 settings_changed 事件使用实际策略；跨账户读写拒绝；非法激活类型及密码哈希读取拒绝；过期后正文/评论不可访问；旧 set_password 仍可清除密码。
- 不写入、修改或删除真实用户的简历和分享；两个测试账户由本任务创建。
