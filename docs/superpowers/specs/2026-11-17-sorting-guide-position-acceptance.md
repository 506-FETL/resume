# 手机排序引导位置与残留修复

日期：2026-11-17。用户明确要求移动遮挡操作的提示，并修复打开排序面板后的箭头残留。本次为轻量返修，沿用现有引导规格直接实现，不另设规格审批或开启新一期。

## 触发场景与根因

在实际 `/resume/editor` 页面打开手机编辑抽屉：提示位于排序按钮下方 80 px，覆盖栏目导航与表单顶部。打开“调整模块顺序”后，Base UI 隐藏父抽屉 Content，挂在其中的提示随之隐藏；箭头单独挂在 body，且排序引导仍处于活动状态，所以留在新面板的列表上。

已阅读防回归清单及原引导的设计、计划、验收记录，重点核对仅主动关闭、同一退出生命周期、箭头只画一次、手机布局与减少动效约束。本次保留已有 Popover、Drawer 和引导动画，不新增组件或依赖。

## 实现

- 手机排序提示改到入口上方，挂载在原编辑抽屉 Popup 内，避免 Content 的 overflow 裁切；位置根据提示实际高度留出 12 px 顶部边距。桌面继续使用原来的左侧提示。
- 编辑工作区在排序面板打开期间暂停排序引导，复用原有 140 ms 退出与清理。取消或确认恢复未主动关闭的引导，不写入 dismissed，也不重置账户记录。
- 不修改正式排序、保存或其他引导的业务协议。本次工作期间同一排序文件的第二行提示被移除，该并行修改予以保留；最终验收依据当前单行提示。
