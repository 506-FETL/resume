# 侧栏首页专项验收

范围为工作台首页 `/workspace`。浏览器对照使用本机新旧生产构建，同一版本 Chrome、已链接的 Supabase 项目和临时账户。大数据量对照使用隔离 PostgreSQL 和合成数据，字节数均为未压缩 JSON。

## 首开实际读取

| 首页内容                                           | 浏览器业务请求                | 返回范围                                                                                      |
| -------------------------------------------------- | ----------------------------- | --------------------------------------------------------------------------------------------- |
| 最近简历                                           | `dashboard_resume_cards`      | 云端最新 2 条卡片字段及总数。与本地 IndexedDB 合并后显示前 2 张；可见缩略图另外按目标取预览。 |
| 求职提醒、岗位概况、待办、漏斗、岗位动态和本周投递 | `get_workspace_job_summary`   | 全量统计，下一场面试 1 条，到期跟进和重点关注各最多 2 条，动态最近 5 条，7 个自然日的投递数。 |
| ATS 均分与待办                                     | `get_dashboard_ats_summary`   | 一行，包含已检测简历数、有数值分数的简历数、分数之和及待处理项数。                            |
| ATS 分数趋势                                       | `get_dashboard_ats_trend`     | 最近 8 次有效数值及时间。                                                                     |
| 最近版本动态                                       | `resume_config_versions`      | 最近 5 个版本的简历 ID、版本号、时间、来源和简历名。                                          |
| 本周编辑次数                                       | `get_dashboard_version_edits` | 本地周一到周日的 7 个计数。                                                                   |

对只有一个岗位、没有简历的登录账户，首页首开有上述 6 次业务读取；访客不发这些请求。两种身份都另有公共导航的 GitHub 星标请求。表中没有计入预检、静态分包与实际打开其他页面的请求。各资源分别就绪，多个卡片共用一次岗位汇总。

## 页面操作

- 仅有收藏岗位时，旧首页不显示投递待办。新版在 ATS 请求仍挂起时已显示可用的投递入口。单独让版本接口失败，岗位动态仍可用，点击版本重试只产生一次版本读取。
- 分别让云端和本地简历读取失败，另一来源仍可见。重试云端只增加一次云端读取，重试本地不增加云端请求。离开页面和切换账户后，旧请求不会覆盖新账户的最近简历。
- 通过首页真实创建简历、进入编辑器、保存版本并返回。旧包从提交到离开首页会多发一次卡片 GET；新包此阶段为零，回到首页重新读取一次并显示真实预览。点击版本动态能打开本次新建简历。
- 同一个既有简历版本又有正式投递的临时账户，分别挂起版本和岗位接口。旧包两次都隐藏了另一来源的动态；新包两次都先显示 1 条，放行后补到 2 条。分别让岗位和周编辑接口返回错误，活动图保留另一来源的柱，重试恢复两组数值。
- 在 375 像素宽、开启减少动效的浏览器打开首页，文档宽度为 375 像素。点击岗位动态到达对应岗位 ID；点击版本动态到达对应简历 ID。
- 新包连接线上数据，从编辑器返回首页到新卡可见为 840 毫秒，到缩略图 ready 为 1,658 毫秒。旧包单次样本分别为 845 和 1,079 毫秒。此次测量确认了少一次无用读取，预览耗时没有观察到改善。
