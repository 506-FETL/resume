# 职业档案布局与批量删除验收

日期：2026-11-16。对应[设计](2026-11-16-career-library-management-design.md)与[计划](../plans/2026-11-16-career-library-management.md)。实施完成；功能验证和工程检查通过；用户审查待进行。

## 实施结果

- 网格从最多三列改为按容器宽度自动计算，最小目标卡宽 18rem，手机允许缩至可用宽度。骨架使用相同规则；少量资料不会被拉满整行。
- 卡片与列表行直接提供删除，打开动作与删除、复选框互为同级控件。批量选择支持逐项勾选、全选本页、清空、跨页保留和统一确认；搜索及类型切换清空选择。
- 删除通过已有领域 store/API 完成，成功项清除，失败项保留，重试仅处理剩余项。未知结果继续核对 metadata。批量期间暂停本页列表重读，收尾统一刷新；源缓存、原件和正文仍按已有逻辑失效。
- 页面 store 持有管理状态，账户代次改变立即取消任务；取消信号传入现有删除与核对请求，在等待 session 后仍能阻止旧任务发送。

## 验证环境与边界

独立 Vite 5196，Chromium 与 WebKit，渲染真实 ExperiencePage、导航、页面及领域 store、API FormData 请求和 UI 组件；仅在远端网络边界提供合成资料与失败响应。所有其他远端请求阻断，未读取或删除用户职业档案，没有进行真实云端删除。本轮没有修改数据库或 Edge Function，复用已部署接口；后端原件/版本清理能力以既有真实云端验收为基础，不冒充本轮重新验证。

## 删除、缓存与隔离

- 23 项按 10/10/3 读取。第一页选一项，第二页全选后共 11 项；切列表与返回第一页保持勾选，第一页全选框为部分选中，列表请求总计两次。取消确认不发删除请求；清空、搜索与切分类按约定清选择。
- 三项批量删除中第二项模拟 403：成功两项从列表及选择中移除，失败一项留在确认中；三次 delete 后只有一次 list。点击重试仅增加失败 ID 的一次 delete，不重删成功项。
- 模拟服务端已删除但返回 503：现有 metadata 核对确认缺失，界面收尾成功，不重复删除。
- 最后第三页三项删除完成后，自动回第二页，显示 10 项，总数 20。唯一资料删除期间暂停列表响应，不提前展示真实空库；列表返回零后才显示空态，焦点回上传入口。
- 批量首个删除响应挂起后切账户，后续九项 delete 均未启动，旧选择和弹窗清空。另挂起 getSession 后切账户再放行，首个 delete 也未发出。两浏览器均验证此取消路径；未声称测试过真实跨账户数据库拒绝。

## 动效复核

使用 review-animations 复核，按仓库动效约定保留公共预设与运行中减少动效。

| 发现                                           | 修正                                   | 原因                                      |
| ---------------------------------------------- | -------------------------------------- | ----------------------------------------- |
| 手机确认框通用 max-width 被 data-size 规则覆盖 | 用同一 data-size 选择器限定手机宽度    | 320px 需要真实边距，不能只看 class 已写入 |
| 删除最后一项后管理入口禁用                     | 优先聚焦可用的批量入口，否则返回上传   | 焦点不能落在消失或禁用控件上              |
| Radix 弹层退出时仍有内联 pointer-events        | 本页确认内容退出时 inert               | 视觉退出中的删除按钮不能继续操作          |
| 删除后缓存暂为空、列表仍在刷新                 | 等待真实读取完成后显示空态，并保留过渡 | 未确认状态不能冒充真实空库                |

- 每个浏览器连续两轮确认框开关，遮罩和内容均记录 enter/exit，进入使用 0.2s 公共时长；关闭期间保留资料名称及数量，内容 inert。关闭 30ms 后重新打开仅保留一个弹窗。
- 逐帧采集真实删除：存在透明度介于 0 和 1 的退出帧，退出项同时 inert，最终移除。邻项按位置过渡，不用退出副本继续响应点击。
- 选择模式快速退出后重开，运行中切减少动效，最终只保留一组可用复选框，无残留 inert 卡片；CSS 公共时长和确认框动画降为 0。一次固定 100ms 采样早于反向切换稳定，验收脚本改为等待实际状态与可见节点后检查，不把该次失败记为通过。
- 结论：本轮动效复核通过。高度过渡只用于本页短小选择工具区，列表移动使用 transform，未引入循环或装饰动画。
