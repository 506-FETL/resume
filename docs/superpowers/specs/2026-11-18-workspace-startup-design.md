# 工作台首屏依赖优化

## 授权与现状

用户提供 18:49 的 Lighthouse 报告并明确要求继续彻底优化。报告目标为 `/workspace`，不是上一轮的 `/resume`：开发环境性能 55，FCP 3.826 秒，LCP 10.431 秒，TBT 73 毫秒，总传输 12.30 MB；其他三项 100。LCP 是首页说明文字。按已授权范围在当前分支实现和验证后交用户审查，不重复审批，不推送。

已阅读防回归清单第 23–27、41–42 节，以及全项目性能设计/验收、简历库预览分页设计和上一轮 Lighthouse 验收。首屏有 497 个请求；只读首页经混合 barrel 加载模板验证、正文恢复与 ATS 编辑逻辑，路由骨架静态导入其他页面控件，Radix 汇总入口扩大开发依赖。真实预览带来约 1.31 MB 必要字体，不能以删除预览或系统字体替代。

## 方案与边界

采用按职责隔离依赖、缩短首屏加载链并修正样式扫描来源。仅改开发压缩不能证明产品收益；预生成云端缩略图需要新的存储及写入协议，本轮先不引入。保留真实模板、正文、字体、打印几何及账户隔离。

- 只读摘要与写入/修复实现分离；轻量类型、模板引用检查不加载完整 Zod 模板树。公开 API 保持兼容，正文边界仍校验。
- 路由骨架只加载当前页面所需内容；公共外壳不因未展示页面加载其控件。必要首屏路由和外壳避免逐级串行下载。
- 已安装 Radix primitive 直接导入，避免汇总包加载整套组件；不改变交互及动画实现。
- 样式生成只扫描真实源码，排除技能、文档及验收材料，保留实际界面所有工具类。
- 首页请求按账户/页面生命周期共享在途结果，消除 StrictMode 与多个消费者造成的实际重复 GET；OPTIONS 单独计数，失败仍能重试。

## 验收

保存本轮修改前生产构建。使用同机、相同两份真实模板合成内容，分别记录开发/生产、桌面/手机、资源传输、LCP 与预览 ready 时间。受控 API 延迟与真实公网分开；不拿匿名空表与用户报告比较。首屏依赖闭包与实际网络双重检查，统计前后 CSS、JS、字体和业务请求。

浏览器检查桌面/手机、浅深色、创建入口、账户菜单、侧栏、路由骨架、预览失败重试与返回复用；验证账户切换、请求失败、重复挂载与取消。没有修改分页/打印几何时保留既有协议。类型、格式、生产构建通过后删除临时 tests 脚本/夹具，保留非敏感证据。

## 实测后的补充

第一轮仅拆分文件后，固定样本手机模拟 LCP 仍约 6 秒，生产 JS 还因分包压缩边界略增；没有把这些变化计为收益。进一步追踪确认 App → 用户 store / 密码恢复 / 菜单 / 首页读取都静态引用认证 SDK，连静态标题也等待它。

将认证订阅原样移到独立初始化组件，与真实工作台外壳并行加载；SDK 和 API 的权限检查不变。已知标题保持同一节点，身份未知时正文显示对应骨架、创建入口禁用。密码回调仍走原恢复 store/校验，在有回调意图时加载门禁；额度菜单和全局额度弹窗在打开时加载。SDK 分包错误交给原全局错误边界，不能默认为匿名。增加 SDK 慢加载、模块失败、恢复无效链接、匿名/登录与账户切换验收。

尝试按 React/Motion 运行库合并碎片，必须同时确认公开首页没有下载工作台/编辑器。SDK 手工 chunk 出现共享 browser shim 环，被撤回；其他手工 chunk 规则也已撤回，最终没有引入手工分包配置。手机导航引擎仅在首次打开时加载，失败后重试与尺寸切换保持可用；路由骨架自身失败回退到带已知标题的公共骨架。第三方开发预构建启用压缩，保留业务热更新。
