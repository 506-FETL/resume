## 选区存档实现

使用现有 `@tiptap/react/menus` 官方 BubbleMenu，Floating UI 负责选区定位、翻转和边缘避让；复用 Button、Spinner、Sonner 及任务 2 的 persistExperienceUpload。不新增依赖、模型调用、Edge 或数据库变更。顶部格式工具保持原样。

真实非空 TextSelection（含单字）才显示。点击冻结文字、字段名、账户 generation 与 operationId；失败后同一字段/文字沿原操作重试，不同选区有独立任务，旧 Toast 重试保持旧载荷。已成功同段点击不再创建重复档案。旧任务与新任务按各自 saving 状态防重复，Toast 重试不会因另一任务占用而丢失动作。

共享 persist 在账户 generation 改变时同步取消原 controller，覆盖 operation 查询/哈希等等待间隙；旧账户不写新账户，也不回填提示。普通字段卸载让已授权保存真实收尾，仅停止组件状态更新；未知结果仍可通过原 Toast 核对。刷新页面后的任务恢复不是本期新增能力。

浮层进入/退出使用公共 DURATION/EASE、transform/opacity 和 useReducedMotion。官方插件 hide 立即移除宿主，因此只将同一个原宿主保留至退出完成，不克隆选区、不重写定位；快速重开取消退出并从当前计算样式衔接，退出节点 inert。运行中减少动效立即完成当前动画。

## 复盘约束

- Radix Tooltip 不应在 `open=false` 与 `open=undefined` 间动态切换受控/非受控，否则桌面缩到手机可能仍不出现提示。按调用点条件组合 TooltipContent 或有无 Tooltip 的完整分支；验收同一挂载实例桌面→手机。
- 保存失败后，当前选区按钮不能静默重试另一段原文；任务按冻结字段/文字匹配，旧 Toast 只操作原任务。验收 A失败→B保存→A重试及未知只核对。
- 编辑器实际 DOM 可能带临时选区装饰，正文不变验收同时检查文本和持久化字段，不能把 span.selection 当成正文写入，也不能只比较可见字数。
