# README 流程与图标精修

沿用已确认的 SVG 源文件精修、Excalifont 主字体及中文回退、纸底与涂鸦风格。

## 本轮问题

Agent 图混合网络请求与工具循环，双向线和回流线挤在卡片之间；解析结果没有清楚连接到展示或工具分支。部分图标只是方框、横线或勾号，无法表达浏览器、模型与文件导出。评论、分页和协作节点缺乏视觉区分。

## 设计

- Agent 上排按“用户请求 → 请求模型 → 解析响应 → 展示回答”排列。工具调用从解析节点向下进入执行，结果向左回传，再向上进入下一次模型请求。仅保留一条矩形循环，无交叉线。代理转发放在模型节点说明中，保留最多 12 步、调用标识、推理上下文与取消边界。
- 图标采用同一套自绘开口线条，保留轻微不规则轮廓。浏览器包含标签栏和地址栏，文档、分享链接、历史、评论、测量、打印各有明确符号。只给实体和关键操作添加图标，分支条件与辅助说明保持文字。
- 重点修改 Agent、架构、评论与分页图，同时检查时序、协作、工作流及总览中的同类图标。已有明确图标的技术标签图保留。
- 文字与图标一起重新分配留白，不能压缩字体换取空间；新增图标不遮住箭头、正文和卡片边框。

## 验收

对照 Agent 实现核实循环含义；逐张浏览器目检；检查文字与图标碰撞、SVG 内部引用及字形覆盖。桌面 1000 px 与 390 px 缩略显示均验证，复杂图通过原 SVG 放大阅读。保护现有修改、README 正文和业务源码，不提交或推送。
