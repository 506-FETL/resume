# README 图示中文化与箭头精修

## 已确认的要求

沿用用户已选择的直接精修 SVG 方式，保留手绘涂鸦风格。本轮修正箭头，将图中说明改为中文，参考 Excalidraw 的中文手写字体。README 正文、产品截图和业务代码不变。

## 方案

- 修改 README 引用的 9 张 SVG，保留纸底纹理、不规则卡片、倾斜构图、手绘图标与装饰笔触。
- 按用户补充要求，以 Excalifont 为主字体；其字库不含汉字，中文采用 Excalidraw 配置的 Xiaolai 回退。每张 SVG 只嵌入自身需要的两种字形子集，保留可编辑的文本，附带字体来源与 OFL 许可；不依赖读者安装字体或访问字体服务。
- 说明、标题、流程和状态均用简洁中文，GResume、DeepSeek、React 等专有名词保留原名，不把程序字段名当作说明。
- 根据中文实际字宽调整字号、对齐与间距。主体说明不压缩字形，不以极小字号解决越界。
- 箭头保留开口尖端和手绘线条，修正 Agent 图贴边的两处转折；回流线从主流程外侧绕行，尖端前保留明确的直线段。逐图检查其余连接。

## 验收

- 9 张 SVG 的文字完整，无说明性英文残留（专有名词除外），字体子集覆盖全部可见字形。
- 单独 SVG 与 README 的图片引用模式都能正确加载字体，字形无替换或丢失。
- 逐图目检文字、卡片与箭头，无重叠、裁切或误导连接；检查 1000 px 阅读宽度及手机缩放。
- SVG 可解析，资源引用有效，保留全部原图；保护已有修改与暂存区。
