# 模板页原地填写与创建

用户已明确要求“使用此模板”在当前模板页面完成，与我的简历保持相同效果和创建逻辑，但不复用其创建界面。本修正已获授权，在当前分支实施；不提交、推送或部署前端。

## 界面与交互

模板预览的 Dialog / 手机 Drawer 保持同一个打开实例。“使用此模板”将该窗口的正文切到填写信息，标题变为“填写简历信息”；不关闭预览后打开 CreateResumeCard，不进入其选择来源、人群或模板目录。名称默认为“示例简历”，描述为空，两项可留空，最终提交才创建简历。

桌面保持选中简历向左展开并向右渐隐、右侧居中表单；手机沿用已确认的全宽向下渐隐背景，高度约 320–384px，顶部 40% 清晰，表单衔接末端。标题和底部操作固定，正文独立滚动。返回恢复当前模板预览、所选示例和阅读位置；输入保留。关闭回到当前目录入口，目录滚动位置保持。创建成功后才进入简历编辑器。

预览正文保持挂载，填写时复用已选精确模板/示例的现有预览资源，不重新查询模板列表；存在成品图片则用成品渐隐，没有成品则显示当前真实排版，不能展示其他示例。复用已有 Dialog / Drawer、Button、Field、Input、Textarea、Spinner 与 Motion，不新增组件库。保留统一动效预设和减少动效，验证两轮切换、关闭与反向。

## 状态与保存

模板页持有自己的预览步骤、名称、描述和未确认操作，不能读写“我的简历”的 create-resume-card store 或导入草稿。现有创建核心、精确模板解析、幂等持久化及示例来源证据继续复用。模板页草稿使用现有 IndexedDB 的独立键，按账户和精确模板区分；不新增数据库或后端接口。

第一次最终提交前冻结名称、描述、模板、示例、模式与操作 ID，并保存到本设备；未知响应、关闭重开和刷新后重试使用同一身份。写入前明确失败允许修改；已提交或结果待确认保持冻结。账户切换和关闭重开时旧响应、catch、finally 不能污染当前页面；成功后更新真实列表并进入编辑器。原有本地/云端模式规则不变。

## 验收

- 当前窗口实例与遮罩在“使用此模板”前后保持，路由不变，不挂载 CreateResumeCard；返回仍是原模板/示例。
- 名称/描述默认、留空与 trim；非默认示例对应真实保存正文；点击使用此模板写入次数为零。
- 我的简历既有导入草稿在模板页进入、输入、保存、失败和关闭后保持原值。
- 本地真实写入、失败、响应未知与同 ID 重试，关闭重开及账户 A→B→A；只隔离外部数据边界，测试生产实现。
- 桌面与 390/320px、400px 短屏、深浅色、输入和焦点、两轮开关/返回及中途反向；加载、错误与缺失分开。
- 格式、类型、构建与实际页面分别记录；测试放 tests/，完成后清理。
