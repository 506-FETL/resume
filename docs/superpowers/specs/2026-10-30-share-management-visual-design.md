# 分享管理卡片视觉设计

## 已确认范围

用户先选择保留网格的 A 方案，再审查桌面、手机和卡片细节效果稿，并于 2026-10-30 回复“可以”。本期按该稿实施管理首页，不再次扩展视觉方向。效果稿使用示例数据，正式页面全部使用原有真实记录。

参考 Vercel 的卡片信息层级、Cal.com 的组合操作、Dub 的紧凑筛选。沿用项目黑白基调、Inter 与中文系统字体、10px 卡片圆角和现有导航。不增加缩略图、趋势图、装饰渐变或业务字段。

## 页面

- 标题与新建分享同排，真实分享总数、有效数和访问次数收进标题下的一行辅助信息。去掉重复介绍与概览分隔线；加载显示骨架，失败显示未知符号，不显示假零。
- 保留五个状态页签、数量、搜索、简历多选和重置。手机搜索与简历选择同排，重置可另起一行；桌面保持紧凑工具栏。保留现有排序，不增加只有外观的排序入口。
- 同一网格适配桌面和手机；按 2026-10-31 的尺寸反馈，卡片最小约 280px，列间距 12px，宽屏可排四列。少量分享也不无限拉宽。保持 PageLayout 和当前页面模块结构。

## 卡片

- 顶部用途图标与用途文字，右侧固定小圆点加状态；只在状态上使用语义色。按 2026-10-31 的纠正，左上角优先显示用户手填的 label，再回退到 purpose 对应的分类；两项都为空才显示“未设置用途”，不猜测历史记录或改写权限分类。
- 主标题只显示简历名称，不再把用途备注作为主标题或重复显示简历名。版本、评论权限、联系方式、密码和有效期来自现有字段，不因简化样式丢失信息。
- 普通卡片自然高度约 219px：正文内边距 16px、标题 16px、信息段距 12px，底部上下内边距 8px。按钮保持 36px 高，长名称及有效期按内容增加高度，不设置裁切内容的固定高度。
- current 显示“随保存更新”；history 显示“固定版本 · Vn”，可查看历史名称；历史原件删除仍说明发布快照保留。
- 手机、邮箱都公开显示“显示联系方式”，都隐藏显示“隐藏联系方式”；仅一项公开明确写出手机号或邮箱。
- 访问次数和最近访问分居活动行两侧。文字不宣称是访问人数或招聘者阅读。
- 浅灰操作区内统一排列“复制链接 / 预览 / 更多”。更多菜单保留设置、换版、开关、归档和删除，沿用原有确认与权限规则。复制保留成功反馈；归档仍禁用原有不允许的操作。
- 长名称允许合理换行，不能撑出卡片；同行操作区对齐，键盘焦点不能被圆角容器裁掉。

## 组件与动效

复用 Button、Tabs、Popover + Command、DropdownMenu、Tooltip、Skeleton、AnimatedContent 和 PresenceDiv。项目没有通用 shadcn ButtonGroup，已检查官方 Radix Button Group 文档与当前 radix-vega registry，采用其分组容器样式适配现有 cn，不引入新依赖；不使用编辑器专用 ButtonGroup。

保留列表重排、状态切换、复制反馈和浮层动效，使用 DURATION / EASE / SPRING 与 useReducedMotion。新建分享继续使用既有最大 720px 右侧抽屉；不修改共享弹层动画、创建表单流程、后端、公开阅读页、模板或导出。

## 验收与边界

验证 TypeScript、ESLint、Prettier、构建和差异；浏览器覆盖 1440 / 1024 / 390 / 320px、深浅配色、长名称、所有状态、不同版本与权限、加载/错误/空列表、筛选与清空、复制反馈、菜单与抽屉回焦及减少动效。用真实组件与隔离数据验收特殊状态，临时文件置于 tests/，完成删除。真实账户仅只读检查，不创建分享或修改权限。
