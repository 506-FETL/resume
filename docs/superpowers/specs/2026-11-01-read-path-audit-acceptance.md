## 只读线上测量

当前账户小样本，JSON 序列化后的 UTF-8 大小，不等同于压缩后的传输字节。单次耗时只用于发现串行等待，不作为稳定性能承诺。

| 场景                               | 原读取大小             | 本次读取大小                   | 测量说明                                                |
| ---------------------------------- | ---------------------- | ------------------------------ | ------------------------------------------------------- |
| 助手岗位概况，2 行                 | 7,193 字节             | 228 字节                       | 减少约 97%；单次请求约 0.55 秒，网络等待仍存在          |
| 简历名称选项，2 行                 | 785 字节               | 211 字节                       | 去掉 JD、改写数据和模板绑定                             |
| 优化冷载，2 份历史报告属于同一简历 | 9,421 字节             | 摘要 128 + 当前详情 4,939 字节 | 最新摘要 1 行；并行冷载实测 580ms；原整批单次实测 624ms |
| 首页 ATS                           | 未用同次基线作速度比较 | 1,797 字节                     | 2 条历史分数、1 份最新建议；并行实测 589ms              |

曾验证过“摘要后读取详情”的中间方案：562ms + 575ms，虽减少字节却增加等待，已改为并行。完整历史分数与只读最新建议的首页查询也没有此串行依赖。重复访问的收益以真实请求数验证，不只看加载动画。
