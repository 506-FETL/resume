# 宣传首页大屏首屏修复验收

日期：2026-11-15。用户要求首页顶部整体填满屏幕，修复大屏内容集中在正中的问题。本次按既有设计修复响应式样式，不另开产品期次。

## 原因与修复

在 2560 × 1440 的真实首页中，导航和封面内容仍只有 1536 px 宽，左侧偏移 512 px；文件夹固定在 640 px，封面实际高度约 781 px。单纯铺满蓝色背景不能让内容适配大屏。

- 导航和封面使用全宽容器，左右边距继续随视口变化；页脚保留原来的 1260 px 阅读宽度。
- 导航高度统一为一个 CSS 变量，封面最小高度为可视高度减去导航；取消桌面、平板和手机原有的高度上限。
- 标题、说明、回形针与文件夹按视口宽高适配，文件夹保持 4:3 比例，岗位签文字随容器放大。短屏以视口高度约束尺寸，内容必要时自然撑开。
- 继续使用原有 Button、Tabs、单张简历与滚动时间轴，没有新增交互控件、动画驱动或数据请求。

| ------------------------------ | -------------------------------------------- | ---------------------------------------------- |
