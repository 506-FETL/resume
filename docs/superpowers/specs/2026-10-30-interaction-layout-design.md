日期：2026-10-30。用户本轮十项反馈及岗位定制结果页补充，已明确授权实现和验证后交审；不重复请求实施确认。当前分支工作，不提交、不推送。

## 方案与边界

采用现有页面内的信息层级重组：保留导航、看板/列表、详情抽屉三个页签和全部业务入口。相比只换颜色，此方案能解决嵌套边框和滚动阻塞；相比重建全站，它保持已有操作路径和数据契约。复用现有 shadcn/Base UI Drawer、Dialog、Button、Select、Collapsible 与公共动效。

首页最近简历按用户后续反馈改为现有简历内容与精确模板版本的真实首页缩略图，替换模拟文档图标。只为最近两份简历在进入可见区域后加载快照和只读预览，复用既有模板、外观与分页组件，不改打印几何。缩略图桌面约 92 × 130px、手机约 68 × 96px，右侧排列名称、类型、更新时间和操作，避免预览撑高首页。加载与失败独立显示，提供重试，编辑入口始终可用；账户、简历或更新时间变化时重建预览。今日待办整行悬浮区域带圆角。准备简历使用标题/绑定控制和操作工具栏、单层纸张预览，去掉重复卡片边界。

分享新建和简历内快速分享统一改为宽抽屉，桌面右侧、手机适配；标题固定、正文可滚动、主动作明确。保留用途、隐私、版本、密码、有效期和已有链接的全部能力。

流程图点击仅预览阶段并打开阶段详情，不写入状态；已越过但未记录的阶段仍显示勾和“未记录”，使用中深色。详情标题右侧明确显示推进/回到该阶段动作，终态继续原确认流程。关闭确认时保留最后一次展示的目标直到退出完成，避免取消时文案变成另一操作。

岗位定制四步之间保留连接线，已完成和待处理使用不同色阶；四步统一为紧凑步骤导航、独立滚动正文和固定操作区。解析/改写中使用真实状态文案，取消“已提取/正在提取”矛盾；长过程文字不能挤占结果和操作区。结果以分区前后对照呈现，去掉卡片套卡片，宽屏双列、窄屏上下对照，保留修改依据和覆盖率的真实含义。进行中/保存中/失败均有即时可见反馈。

修复 animation 与 animationDuration 混写导致的 React 警告。绑定准备简历按钮点击立即显示进行中并阻止重复发起，成功和失败均明确反馈；保留账户/岗位隔离和现有串行保存。

## 扩展审查

对首页、简历管理/创建/编辑、求职跟进、分享、岗位定制、优化、模板、历史、助手、账户设置的可见入口及次级弹层建审查清单。检查桌面、390/320px、短视口、长文本、加载/空/失败、键盘与焦点、滚轮、两轮开关及退出中重开、运行中减少动效。针对确认的问题修复，不把未验证状态标为通过；不触碰模板几何、PDF、后端或用户内容。

参考：Base UI Drawer 官方文档建议标题/页脚在滚动正文之外（https://base-ui.com/react/components/drawer）；shadcn Base Drawer（https://ui.shadcn.com/docs/components/base/drawer）；Carbon progress indicator 状态和辅助文字层级（https://www.carbondesignsystem.com/building-blocks/core/components/progress-indicator/specifications）。保留本仓库时长/缓动优先级。
