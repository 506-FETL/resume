# 加载图标统一验收

日期：2026-11-10。

实施完成；下列验证已通过；用户审查待进行。改动保留在当前分支，前端尚未发布。

## 范围与实现

用户最终要求为所有加载图标使用 Swirling，页面切换也不再使用双眼样式。本轮属于加载展示的集中替换；按 brainstorming 梳理现有调用和组件来源后直接实施，无新增业务流程，不另写功能规格和分期计划。

- `src/components/ui/spinner.tsx` 是唯一加载图标入口，同目录 `spinner.css` 集中管理动画。沿用 [Loading UI Swirling 官方源码](https://loading-ui.com/r/swirling.json)的圆弧、虚线变化与循环节奏，并保留 MIT 许可说明；无需新增依赖。
- 保留现有 `size-*`、颜色、`data-icon`、ref 和无障碍属性。默认名称为“加载中”，业务层可提供更具体的名称。裁去官方 SVG 的外围留白并同步居中圆心，让现有按钮和状态行的尺寸继续有效。
- `PageLoading`、通知、上传、AI 改写、评论、模板预览、协作同步、求职保存及历史版本操作统一复用 `Spinner`。删除双眼组件和未使用的旧波浪动画样式；移除调用方重复的旋转类和专门为加载图标设置的减少动效逻辑。
- 在公共组件调用仓库 `useReducedMotion()`，系统偏好改变时立即停止或恢复动画。停止时保留可辨识的圆弧。已有内容切换、弹窗退出、骨架屏、进度条、保存队列和请求时序保持原逻辑。
- ESLint 限制 Lucide 的 `Loader*` 与 Hugeicons 的 `Loading*` 导入，组件目录也接受这条检查。既有图标聚合文件只转出原库，保留这一入口；实际消费方继续接受限制。同步更新 `AGENTS.md` 和防回归清单，业务层不再自行选择图标或设置循环动画。

## 浏览器验证

使用独立 Chrome 上下文，复用正式 Spinner、PageLoading、Button、DeferredContent、TemplateResourceStatus、WorkflowSaveFeedback、Dialog 和 Sonner。夹具与脚本位于临时 `tests/loading-ui/`，没有接触真实账户数据。

- 12 / 14 / 16 / 20 / 24 / 32 px 六种实际 SVG 尺寸正确；1440 / 390 / 320 px、深浅色组合均无横向溢出，已查看截图并通读状态文案。
- 读取实际动画时间线及不同帧的虚线和旋转值，确认两条官方循环均运行。12 个跨完整周期的采样点中，圆心与图标中心的偏移均为 0。
- 不刷新页面开启减少动效：所有 Spinner 的活动动画数量归零，虚线稳定为 `400px, 400px`；关闭偏好后恢复两条动画，原页面和组件实例保留。
- 保存按钮与保存反馈至少两轮状态切换，覆盖保存中、成功、失败和重试；未保留旧加载图标。
- 延迟内容先显示 Swirling，再显示真实加载结果。弹窗覆盖重复开关和退出中重新打开，最终卸载且焦点返回入口。
- 通知覆盖加载→成功、再次加载→失败和手动关闭；各状态切换正常。隔离组件验收未出现浏览器执行错误或无障碍警告。
- 本地生产构建在 5174 端口验证 `/login` 的慢分包加载，以及点击“忘记密码？”后的真实路由切换，均显示同一个 Swirling。
- 生产登录表单在 390 px 深色、减少动效下显示静态 Swirling；请求期间禁用提交，失败后恢复按钮。请求在浏览器边界拦截并返回合成错误，没有向云端提交测试账号。生产页面未出现执行错误。

## 动画复核与修正

按 review-animations 检查本轮差异；循环承担真实的等待反馈，使用用户指定的官方旋转及 SVG 虚线效果，外围状态过渡继续复用仓库已有组件。1.5 秒与 2 秒为循环周期，不是界面进入或退出时长。

| 发现                                                                             | 修正                                                              | 验收依据                                                     |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------- | ------------------------------------------------------------ |
| 加载图标和减少动效在各处单独实现                                                 | 公共 Spinner 与实时偏好订阅                                       | 旧实现检索、运行中切换、导入约束                             |
| 初次裁去 SVG 留白时采用非零 viewBox 原点，CSS 旋转中心与圆心不一致，圆弧会被裁切 | viewBox 从 0 开始，圆心同步改为 250 / 250，半径和官方动画保持一致 | 实测旧版本中心偏移约 20 px；修正后 12 帧偏移为 0，截图无裁切 |
| 首轮脚本在浏览器动画时间线开始前取了两次相同样式                                 | 等待真实动画时间推进后再比较帧                                    | 已观察虚线长度和 transform 连续变化                          |

复核结论：通过。未改动共享 Dialog 动画、模板正文、打印样式、数据库迁移或 Edge Functions；本轮不涉及 PDF 排版或后端部署。
