# 简历模板页面性能验收

本期覆盖工作台「简历模板」的首屏、筛选、追加、预览、填写与创建。本地已实现，用户审查待完成。目录迁移和 100 张卡片小图已部署到当前链接的 Supabase 项目，前端交付为当前分支代码和本地生产构建。

## 首屏实际取了什么

- 云端上架 100 套。首批按展示顺序取 13 条摘要，显示 12 张卡片。第 13 条只判断能否追加。筛选项另取一次，响应 65 B。两个读取互相独立。进入其他工作台页面时不会预取模板目录。
- 原目录对每套模板读完整 metadata，包含其他示例、所有预览配置。按同一顺序比较首批，真实 PostgREST 响应解压从 20,743 B 降至 7,687 B，实收 gzip 从 3,197 B 降至 2,527 B。第二批解压 21,495 → 8,239 B；「创意＋双栏」21,820 → 8,538 B。空结果均为 2 B。
- 列表只加载可见范围附近的默认示例图片。桌面 1365×900 的 9 张图共 1,765,686 → 347,360 B；窄屏 390×844 的 2 张共 392,382 → 91,068 B。100 张默认图合计 25,141,381 → 3,368,628 B，此合计用于核对发布资源。
- 卡片使用按原图 SHA-256 定位的 512×724 WebP。没有小图的新默认示例用自己版本的原图。打开完整预览才取这套模板的详情、精确定义、选中示例和渲染所需的素材。只打开列表不会请求完整预览、创建草稿及提交代码。桌面浏览不下载移动抽屉。

## 测量口径

对照基线为当前分支改动前的生产包，入口 index-BZTr8AIn.js。使用无扩展 Chrome 158，分别测试桌面和窄屏。受控数据来自真实云端公开目录、示例及图片的录制，固定 65 ms 延迟、1.5 MiB/s 下载、CPU 2 倍减速，对模板 GET 加 220 ms、图片加 80 ms。每个视口各跑三组旧新交替，比较中位数。网络计数区分业务 GET、图片、分包、OPTIONS 和 HTML。静态显示按实际图片出现，正文按精确示例完成分页，填写按名称输入框能够输入且已经可见计时。

公网单独使用本地生产静态站连接真实 Supabase 和 Storage CDN，无人为节流，含本机网络代理。三组交替样本中，固定阿酥卡片的首图在桌面为 3,270 → 2,937 ms，窄屏 3,053 → 2,636 ms；全部可见卡片在桌面为 3,436 → 3,070 ms。桌面目录 GET 发出从 378 提前至 81 ms，该 GET 自身的公网耗时中位数为 1,108 → 1,538 ms。独立 Node 长连接交替七次则为 380 → 338 ms。两组测量条件不同，公网往返随网络变化。后续焦点及离开页面的收尾修复另做生产包验收。

## 筛选、预览与创建

- 近底只发对应 offset 请求。已加载 24 项后切走再返回保留 24 项，创意 → 简约 → 创意回访零目录请求。隔离数据库以 100 项逐页核对稳定顺序、末页和双条件筛选。首个目录或筛选项立即 503 时，3.5 秒内该请求只有一次；点击重试后只重读失败项。分页失败保留 12 项，重试后追加至 24 项；后发筛选不会被迟到数据覆盖。
- 快速划过或聚焦前三张卡片不下载定义或示例。稳定意图只取选中的定义和示例。人为挂起精确目录详情时，已选示例的真实分页正文可以先出现；详情 503 后保留正文并支持局部重试。模板下架或换版时重新核对目录，停止使用旧选择。
- 默认模板切换示例后正文从「陈知远」变为「林知夏」。阿酥双页模板在初次打开、同宽重开、改变宽度重开时，真实分页测量源分别为 1、0、1；重开页数、断点、纸张尺寸和照片一致。关闭弹窗、重开、退出期间反向打开、桌面与窄屏切换、减少动效、焦点恢复均经过实际页面核对。DPR 2 桌面从已打开的预览离开，浏览器前进返回目录后保持 12 张卡片，全程各一次 HTML、目录及筛选项请求。
- 只预览，创建草稿读取从 1 次降至 0 次；实际填写读取 1 次。逐键输入 9 个字符，预览容器的 React 提交从 9 次降至 0 次。提交已预览的示例不再发模板请求，重复 SHA-256 校验从 2 次降至 0 次。进入填写、返回、重开均不创建简历；填写变更保留。
- 使用真实浏览器分别验证本地创建和关联项目中的临时登录账户。默认及非默认示例的 14 个持久字段逐项相符，保留 39 条示例证据。双击只建一份。云端首次读取只取目标 ID 的 5 个字段，INSERT 返回持久化结果，编辑器再核对 6 个字段；编辑姓名、保存、刷新读回一致。模拟写入成功后丢响应，刷新后保留冻结的名称、示例和操作 ID，重试确认同一份简历，总计一次 INSERT。真实登出、游客草稿、重新登录原账户互相隔离。临时账户和业务记录已删除。
- 首次打开分包延迟和返回 503 时，可取消或局部重试。检查手机抽屉分包加载中按 Escape、点击取消、失败后重试及最终关闭，焦点均还给原卡片。切换到填写后提交分包失败会显示中文提示，用户可留在当前步骤重试。

## 数据库与发布

通过隔离 PostgreSQL 核对匿名和登录角色、跨所有分页组合、非首项默认示例、上架与下架边界、映射缺失、错误 MIME/尺寸/字节数及重复映射。两角色只有读权限。已有编辑器仍可取得完整模板、全部示例及精确版本。

云端连接池 SSL 握手超时后，使用同一项目的官方迁移接口原子执行并登记 20261126065557_official_template_card_summaries。云端与本地迁移账本 92/92 一致，迁移 SQL 逐字核对，9 个 Edge 函数版本均未变化。100 张 WebP 上传后分别回读 SHA-256、MIME、尺寸和缓存，100 条原图映射有效，重复发布写入 0 项。维护命令见[简历模板维护手册](../../resume-template-maintenance.md)。

本次复用既有只读分页结果，未改动模板定义、分页计算、纸张尺寸或打印样式。测试使用的脚本、测试账户、媒体副本和浏览器服务在验收后清理。
