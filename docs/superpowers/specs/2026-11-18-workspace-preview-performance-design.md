# 工作台缩略图生成优化

## 授权与依据

用户已要求“按照你总结的进行优化”，授权实施根因复核中的首页缩略图、准备队列与尺寸读取优化。已读取手机根因复核、防回归清单相关性能与导出条目、简历库统一预览规格和验收、模板维护手册第 10–12 节及前轮 PDF 验收。保留当前分支和已有修改，不提交或推送。

## 方案

采用原模板引擎的首页展示模式与两阶段预览队列。仅调整开发压缩无法解决真实排版成本；云端图片成品会引入存储、权限与更新协议，本轮不采用。保留真实字体、完整正文的测量、现有分页签名、图片解码门禁和成品缓存。

1. `CanonicalPagedDocument` 增加仅渲染首页的显式选项，默认仍渲染全部页面。首页模式只限制展示页数量，不限制正文测量或改变分页算法。缩略图生成器直接组合该组件与模板运行时，绕过展示用缩放组件和重复模板解析。
2. 预览准备阶段同时开始目标正文读取和生成器模块加载，正文恢复后预取精确绑定的模板定义。复用现有归属读取、模板 store 与在途请求，不猜默认版本。模板素材仍由既有 hook 管理生命周期。
3. 页面预览 store 将准备与渲染分开：最多保留两份准备中、已准备或正在生成的任务，重排版始终最多一个。准备完成的可见任务可以先生成，不等待另一份慢读取。缓存仍按账户、目标、版本、模板与日期组织，最多 40 份 / 32 MiB；同版本返回复用真实成品。
4. 取消未开始的不可见任务；正在读取的任务在完成后若已无消费者则释放，不进入重排版。账户切换取消全部旧任务，迟到响应及成品不得回填；失败显示原重试入口。保留 StrictMode 重挂载期间在途复用。
5. 手机断点使用既有 MediaQueryList 的 matches，避免重读窗口布局。成品纸张宽度使用 ResizeObserver 已提供的尺寸，保持同一容器、纸张比例与原有进入/退出/减少动效。共享完整文档缩放仍用于真正需要缩放的页面，缩略图不再调用它。

## 范围与验收

页面布局、按钮、动效预设、字体与正文内容不变；组合现有预览、Skeleton 和 Button，不引入新 UI 组件或依赖。重复 JS 的文件名误归类不通过删除组件处理。旧头像独立于本次手机链路，本轮不自动改写用户已存资源。

在修改前保留生产构建和相关源码基线。固定相同合成正文、官方精确模板与真实字体，使用生产构建比较桌面/手机、冷/热启动、正文请求时间和真实预览 ready；开发报告另列，不把换环境写成优化收益。轻量状态验证覆盖准备并发上限、渲染串行、失败重试、可见性取消、返回缓存、写后版本失效与 A→B→A。

通过正式预览及打印 hook 检查默认和 Tinos/中文回退模板，覆盖短文、接近页底与多页。逐项对比首页 DOM/几何、完整分页签名、PDF 文本与渲染结果，背景打印开/关分别输出。真实页面检查 320/390px、桌面、深浅色、连续两轮进入/返回、重试和动态减少动效。

工程检查执行改动文件 Prettier → ESLint layout、应用/Node TypeScript、全量格式检查和生产构建。临时验证代码及数据放 `tests/workspace-preview-performance/`，完成后清理，保留非敏感文档证据。没有数据库或 Edge Function 变更，不需要云端部署。
