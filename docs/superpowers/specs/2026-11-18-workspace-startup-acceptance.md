# 工作台首屏优化验收

## 范围与结论

用户最新提供的 `localhost_5173-20261118T184903.html` 测量的是 `/workspace`，开发环境桌面性能 55，FCP 3.826 秒、LCP 10.431 秒，总传输 12.30 MB、497 个请求；其他三项 100。本轮针对工作台启动链路继续优化，保留上一轮简历库、日历、头像与无障碍修改。

生产构建桌面最终三轮均为 95 分，基线均为 96 分；手机由 77 到 80–81 分。桌面本轮没有净分数提升，手机改善较明显。手机尚未达到 90 分。没有把开发报告与生产分数当作直接前后对照，也没有把模拟 LCP 的改善写成真实预览加速。

实施：已完成。验证：已通过本轮范围内检查。用户审查：待审查。前端未发布，没有提交、推送或云端结构变更。

## 测量方法

- 修改前保存本地生产构建，在 4186 端口提供基线；当前构建在 4187 端口提供对照。5173 保持原开发服务。
- Lighthouse 13.6，隔离的无扩展 Chrome，每轮新浏览器配置、冷资源；桌面使用正式 desktop config，手机使用默认模拟节流。用户原报告为 Lighthouse 13.5，版本及数据有差异。
- 两份固定的合成云端简历使用真实默认模板 v3、真实完整字体和照片。所有业务 API 均在隔离浏览器拦截，统一 150 ms 延迟；模板定义首次只读取得后使用同一缓存响应。不使用真实账户凭据，不向业务表写入。
- 手机前后交错执行三轮；桌面因最终构建分数波动补充重复测量。每轮串行，测量期间不运行构建、类型检查或其他浏览器回归。每轮明确等待两个 `data-resume-preview-state="ready"`。
- 额外记录真实、未节流的标题 DOM 与两份预览 ready 时间。这些时间不同于 Lighthouse 模拟网络/CPU 后的指标，不能互换。

## 实际修改

- 摘要读取、模板引用检查和简历类型归一化移入轻量入口；原导出继续兼容。离线正文恢复、云端修复及写入只在实际调用时加载；保留原权限过滤、完整字段和错误处理。
- 首页避免经 tracker、ATS、schema、resume 的混合 barrel 提前引入编辑与模板验证逻辑。独立数据源仍并发加载，各自完成后显示；按账户代次共享在途请求，失败不缓存为空结果。
- 认证订阅从全局用户 store 移至独立初始化组件，与外壳/首页并行取回。标题保持原节点，身份未知时创建按钮禁用，正文使用对应骨架。恢复链接仍按原会话与 claims 验证；普通启动不加载密码恢复门禁。
- 其他页面的详细骨架按路由加载，公共回退保留已知标题。骨架分包失败降级为通用骨架，不能让实际页面加载失败。
- 手机导航首次打开时加载原 Base UI Drawer，保留关闭后的组件状态、退出动画与焦点。加载/失败使用现有 Dialog、Skeleton 与 Button；额度菜单和升级弹窗也按实际打开加载。
- 共享 UI 改用已安装的 Radix primitive 入口，不新增依赖。Tailwind 仅扫描真实源码，排除技能、文档和临时验收材料。Vite 只压缩第三方预构建依赖，业务源码保留开发热更新。

## 发现并纠正的问题

- 单纯拆文件曾使 gzip 压缩边界变差，JS 略增，手机仍约 6 秒；继续追踪认证与 UI 的静态链路，没有把失败实验计为收益。
- SDK 手工分包形成 browser shim 环，其他运行库手工分包也没有稳定收益，最终全部撤回。最终重试与骨架容错修复后的桌面分数从阶段性 98 变为 95；再做三轮确认，以最终构建为准。
- 最初夹具照片字段不完整、桌面配置使用错误、CORS 通配允许头造成工具警告；均修正后重测。并发构建/浏览器工作期间的早期性能结果未纳入正式表格。
- 手机加载占位关闭曾丢失焦点；重试后的模块级 lazy 还会在尺寸切换时重放失败。改用共享触发器 ref、每次挂载稳定的 lazy 实例，并补充真实回归。
- 隔离菜单测试起初用 DOM `.click()`，未触发 Radix 的 pointerdown 打开逻辑；改用真实鼠标事件后完成两轮开关和登出，没有据此改写产品交互。
- 全量格式检查首次误扫描临时构建副本；清理测试产物后再运行正式检查，不把该次报错记为通过。

动效复查沿用仓库约定：复用现有 Drawer/Dialog 的进入与退出；快速反向、重复操作、焦点和动态减少动效均已实际检查。未增加新时长或缓动。
