# 全站动效与历史版本交互修正

## 需求与范围

以用户本轮明确要求和仓库现有动效规范为设计依据：保存当前版本恢复标准 shadcn Dialog；历史页复用持久化 current resume；检查其余所有页面的状态切换与动效。只修改交互反馈相关代码，保留业务行为和已有未提交工作，不提交或推送。

## 保存版本

使用现有 Radix 版 shadcn Dialog、DialogContent、DialogHeader、DialogTitle、DialogDescription、DialogFooter，加普通单列表单。删除该弹窗的 ResponsiveDialog 侧栏、分节导航、专用动效样式注入。保留版本名、重点标记、说明、标签、保存中禁用和失败后草稿。弹窗宽度遵循默认值，长内容在可视高度内滚动。

## 当前简历

追踪 URL resumeId、current-resume-storage 和历史页选择的关系。有效 URL 显式选择优先，其次当前云端简历；手动选择同步 current resume 的 ID 和类型。无效 URL 回退到有效 current resume。离开再返回不清空选择；离线简历、未登录、空列表和加载失败保留真实空态。

## 全站动效

检查首页、简历列表与编辑器、分享管理与公开页、求职看板、模板工作台、简历优化、AI 助手、个人资料、登录/注册/找回密码、更新日志以及共享浮层。

共享层优先修复 Radix 状态选择器与缺失的 reduced-motion 降级。保留原有 shadcn 结构，不扩展自定义弹窗视觉系统。应用层通过 useReducedMotion 接入 MotionConfig 和 CSS 降级；页面级仍使用现有 DURATION、EASE、SPRING。进入约 8px 位移或轻缩放，退出更短，列表错峰限制总延迟。加载、空态、错误和成功切换均保留反馈，不阻塞无关异步模块。拖拽不加额外入场干扰；流式文字不逐 token 重播。

## 验收

类型检查、定向 ESLint、生产构建、最终改动范围审查。浏览器核验历史选择离开返回、标准保存表单、首页和各主要页面切换；共享弹窗检查创建简历、创建分享、简历优化，遮罩和内容至少两轮开关以及退出中重开。检查减少动效、移动端尺寸、键盘焦点与表单草稿。浏览器验证不提交真实业务写操作。
