# 模板页资源加载优化规格

## 已确认目标

用户已确认保留分页、缩略图改用图片 URL/CDN、收紧鼠标悬停预取，并验证请求次数和加载速度。本次在当前分支实施，不推送；保留原有 `vite.config.ts` 修复。

## 现状与范围

目录每页 12 条，距底部 480px 追加；缩略图提前 600px 请求。当前每张预览通过 PostgREST 下载 Base64，逐张触发跨域预检；鼠标进入卡片立即加载定义、示例和全部素材。当前公开目录为 63 套，首批 12 张预览原始大小约 2.34 MB。

只修改模板页缩略图交付和预取链路，以及这条链路必要的发布保障。缩略图 hook 的共享调用点必须同步兼容；不改变模板布局、正文、导出、分页算法和已有精确素材读取。

## 方案

1. Supabase Storage 新建专用公开桶 `resume-template-previews`，仅受控维护凭据可写。已有已发布预览按原始 SHA-256 复制到 `<hash>`，保持图片字节和 MIME 完全一致，缓存一年。浏览器按可信项目 URL 和严格校验的哈希生成公开图片 URL，不接受目录内任意 URL。
2. 保留不可变资产表作为完整预览/导出的校验来源。维护同步工具只接受已发布资源，上传前检查 SHA-256、字节数和图片头尺寸，已存在对象必须匹配，禁止覆盖。未来目录发布先完成 CDN 同步，数据库目录写入门禁检查预览对象存在及元数据一致，避免发布后出现缺图。
3. 列表通过原生 `img` 加载 CDN 图片，由浏览器负责网络缓存；保留可视范围加载、占位、失败重试与原有动效。缩略图不再进入 Base64/Blob 图片 store。共享 hook 调用点保持接口一致，完整素材依旧使用校验后的 Blob。
4. 鼠标悬停停留 200ms 后仅预取模板定义与示例；离开、失焦、卸载和目标变化时取消尚未触发的任务。键盘聚焦采用同样意图判断，鼠标/触笔主按钮按下立即预取必要数据，触屏按下不预取，点击后的真实预览仍会加载。完整素材由打开后的真实预览加载；示例选择不因鼠标划过下载素材。复用现有资源去重与缓存。
5. 保留 12 条分页及 480px/600px 阈值，不同时调整多个性能变量。

## 验收

- 同一浏览器、视口、网络环境记录修改前后模板资源请求数、响应耗时、首批图片完成时间和传输量；区分应用资源、OPTIONS 预检和本地 Blob。
- 首屏只取当前页；滚动近底部才追加，返回已加载位置不重复下载；快速划过卡片不取定义/示例/素材，稳定悬停只取定义/示例，点击仍能显示完整预览。
- 覆盖筛选、重试、键盘聚焦、窄屏和减少动效；共享编辑器模板画廊维持正常显示。
- CDN 所有当前预览真实 GET 核对 MIME、长度、哈希与缓存响应；验证匿名不能写桶、草稿不能被同步，目录发布门禁拒绝缺失对象。
- 运行类型检查、相关 lint 和构建；部署数据库迁移并核对云端账本。没有 Edge Function 修改。
- 临时验证代码与数据仅放 `tests/template-performance/`，完成后删除；结果记录在计划配套验收文档。
