日期：2026-11-15。范围：用户本轮九项问题及新增全项目悬浮提示审查。用户已授权实现、验证后统一验收；不重复确认，不提交或推送。实施、验证、用户审查分别记录。

## 调研与既有问题

已读取防回归清单中 UI、动效、账户、文案、读取链路、助手与档案条款，以及 2026-11-14 Harness 和资料库重构规格。最新版用户要求覆盖旧规格的“全库必须手动选用”和“本对话资料常驻入口”；历史数据与账户隔离约束不变。

源码根因：上传区选择文件即保存，而底部只关闭；文字另有提交入口，形成不一致。`useSourceList` 即使命中缓存也先 loading，筛选页不能从已完整加载的全部摘要派生。已有下载 API，但阅读默认仅渲染段落。旧会话资料 UI 和权限快照将用户限定为手动选来源。标签现有颜色映射要用实际 DOM 验证，不能因命令单色截图盲改所有类型。

## 方案

采用“职业档案”：保存项目记录、周报、旧简历与补充说明。保留 `/experience` 路由与内部数据键，更新用户可见名称，避免无意义迁移。

在“全库正文每次注入”“让用户逐份勾选”“自动按需检索”三种方案中，采用自动按需检索：账户档案可被本轮工具访问，正文只在相关检索或指定读取时进入上下文；加号仍可选择或上传重点文件。不添加向量服务，不自动生成额外收费摘要。

### 档案保存与阅读

- 上传/粘贴切换固定桌面与手机弹层高度，标题、说明和底部操作不移动，内容区滚动。两个 tab 保留草稿。
- 选文件进入待保存队列，底部唯一“保存”实际提交当前待保存内容；保存中显示 Spinner、防重复提交。全部成功后关闭；失败保留内容，可按原 operationId 重试/核对。关闭通过既有 X/Escape，不把关闭命名为保存。
- 列表真实每页 10 项，稳定排序与 total。完整已加载集合可派生分类页；不把不完整页当全集。缓存命中无 loading 闪烁，不新增网络；未缓存页只请求必要摘要，返回保留上页内容，失败可重试。写后失效、账户代次继续有效。
- 文件详情默认文件预览，明显“下载”入口。PDF 复用已有按需 PDF 渲染能力；DOCX 使用已有成熟渲染器（若没有原件渲染能力，展示文件信息和下载，不冒充排版原件）；TXT/MD 原件按安全纯文本。禁止私有文件提交给第三方在线文档查看器。
- 原文出处仍能指定版本/段落定位；原件 Blob 按账户/版本共享成功与在途请求，object URL 由展示生命周期释放。首屏元信息不加载解析器。

### 助手

- 删除常驻“本对话资料”区以及“本轮查找全部”按钮；加号保留选档案、上传文件。当前账户可用档案自动进入按需查找范围；只读取元信息建立版本快照，不预先注入全文。
- 每轮与排队项固定实际提交时来源版本，显式文件引用优先；旧历史快照不授予跨账户访问。新增/删除/更新使对应缓存及摘要失效。
- 聊天直接选文件、拖放或粘贴文件后形成附件任务，成功后变可发送的文件标签；失败可移除/重试，不丢用户草稿。原件私有持久化，历史可查看/下载；现有输入仍能继续编辑。
- 类型区分保留：简历蓝、岗位绿、命令使用各命令已有语义色、技能紫、选区青、档案中性。宽度桌面 100px、手机 88px，圆角 8px 不变；关闭动作不会发送。
- 使用官方 shadcn Context 组合，输入区放紧凑入口，展开显示当前上下文占用、真实预算与整理状态。以最新模型调用的 usage 为准，不把多步 totalUsage 累加当窗口占用；尚未调用的估算单独标示。不恢复每条回复的 token 行，不新增成本估价依赖。

### 选区与悬浮提示

- Tiptap 选中文字后只显示“存入职业档案”。点击保存冻结选中文字与字段名称，成功可打开档案；不改简历原文、不扣 AI 额度。失败保留操作身份并允许重试，换账户不回填。
- 全项目逐处盘点 Tooltip、自定义 tooltip props 和原生 title。移除“回复”“编辑”“保存”等文字按钮上重复名称；缩小屏幕只剩图标的入口继续需要说明。保留图标用途、可读全文、额外规则与快捷键信息；保留 aria-label，不能全局禁用 tooltip 组件。
- 遵循现有 transitions-dev 模式和 motion 预设；所有新增动效接入减少动效。布局不因状态文本长度改变，手机与键盘可完成同一动作。
