# 职业档案首开与资料操作

范围为侧栏职业档案、资料阅读、上传和直接相关的数据读取。录制中的列表在导航后 910 毫秒发出，1,695 毫秒返回。首次内容绘制为 335 毫秒，最后一个文本 LCP 候选出现在 2,005 毫秒。第一屏还加载了上传、选择器和阅读界面的开发模块。

沿用已确认的通栏资料库、每页十份、真实摘录和按账户清空的缓存。登录确认后，外壳和列表各自准备。直达原文时只准备实际目标，尊重指定的版本和段落。上传和详情操作按实际打开加载并保留失败重试、关闭、焦点、草稿和版本归属。核查首次保存和重试的区别，保留服务端对相同操作 ID 和内容的校验。

交付以真实卡片、正文及保存完成为准。用相同样本和固定延迟对比本地生产包，核对访客、账户变化、分页与筛选、跨页选择、冷开深链和未知文件格式。真实云端核验只使用专用临时资料，保留非敏感结论。
