# 首页与手机编辑体验返修规格

本轮依据用户八张截图和八项明确修正要求实施，属于已授权返修。保留本期之前所有功能与改动，在当前分支工作，不提交、不推送。实施、验证、用户审查分别记录。

## 布局决定

1. 剩余 8 个格式文件只运行项目 Prettier。JSON 比较解析值，Markdown 比较去除排版空白后的内容，禁止修改字段、指令和生成逻辑；生成状态通过格式化工具处理，不手写内容。
2. 首页三个提醒在桌面同排拉伸至相同高度；手机自然高度。各标题右侧放现有 Button + Link 的“查看全部”，进入真实求职跟进页面，重点关注接续已有筛选能力，不发明无效参数。
3. 求职概况采用统一的“标签、数字、辅助说明”纵向节奏，数字靠近所属标签；两列边界清楚，说明缺省不让下一行错位。复用 NumberTicker 和原加载状态，不改统计口径。
4. 我的简历使用宽度有上限的自适应网格，桌面不再把少量卡片拉伸到半屏；手机占满可用宽度，保留完整菜单和操作。
5. 求职跟进“准备中的简历”直接展开，删除外层折叠按钮与箭头。绑定简历 Select 仍是必要的实际选择控件，保留；预览只在真实数据就绪后展示，保留精确模板引用、失败和权限状态。
6. 优化页的评分依据、维度理由和可读性建议在桌面全部展示；手机保留现有折叠交互和过渡。同一内容只挂载一次，切换视口不丢内容或产生双图表。
7. 手机编辑页图标按钮使用现有 Button 尺寸体系，目标为 36px，压缩不必要间隔，能放一排时不强制折行；极窄屏保留可访问的排列，不压缩图标至不可用。排查并移除编辑操作区重复边界，保留区域必要分隔、所有动作、Tooltip 与读屏名称。不改全局 Button 或打印几何。
8. 手机历史时间线和详情切换保留状态与滚动，通过轻位移和淡入淡出呈现前进/返回关系，允许快速反向；不因手机宽度设置 duration=0。只在用户开启减少动效时降级，运行中设置变化即时生效。AGENTS.md 未发现手机端禁用动画规则，新增明确约束，不删除无障碍偏好要求。

## 实施方案与边界

选择局部容器、响应式披露和现有动画修正。全局缩小按钮会影响其他入口，另做一套手机页面会增加重复状态，两者均不采用。继续组合现有 Card、Button、Collapsible、Accordion、Tabs 与 motion 预设，无新依赖、无数据库变更、无模板正文或导出改动。

共享状态保持原 store；只增加必要局部 UI 状态，不对内部已知数据重复校验。先记录触发与根因，再修正，不能用隐藏内容或固定大高度掩盖问题。

## 验收

- 1440px / 768px / 390px / 320px：提醒等高、真实查看全部链接、统计节奏、单卡和多卡宽度。
- 优化桌面直接显示完整内容、手机折叠两轮与反向、视口切换；求职准备区无外层折叠且原动作保留。
- 编辑工具栏和操作行的按钮实际大小、行数、图标、边界、键盘焦点；保留导出/编辑/协作处理器。
- 历史手机时间线→详情→返回至少两轮，退出中反向、当前内容与历史内容、减少动效；逐帧检查中间状态及焦点、滚动保留。
- 隔离合成内容验证真实组件，不触发用户数据的保存、检测或 AI。临时脚本全部在 tests/responsive-refinement，完成删除。
- 改动文件 Prettier → ESLint layout；类型、构建、全项目 format:check；格式文件内容等价比较。

用户最终审查待确认。
