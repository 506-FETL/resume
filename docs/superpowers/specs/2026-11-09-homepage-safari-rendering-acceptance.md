# 宣传首页 Safari 滚动显示修复验收

日期：2026-11-09。

本次修复用户截图中的两处 Safari 回滚异常，沿用已经确认的单张简历演示、手绘样式和时间轴。涉及 `editing-art.tsx` 与 `folder-opening.ts`，没有新增页面或产品功能。

## 复现与根因

### 协作文字与助手正文重叠

在本机 Safari 27.2 中，先滚到实时协作，再退回 AI 助手：蓝色协作文字会与黑色旧句同时显示，日期也会提前出现。读取实际时间轴和裁切属性时，进度已经正确回退，未来字段的裁切宽度均为 0，说明不是旧动画仍在播放。

将同一裁切矩形的宽度从 0 改为 0.001 后，未书写的文字立即隐藏。最终在公共 `InkField` 中保留这一不可见的非零初始宽度，后续书写仍由原时间轴扩展裁切范围。

### 返回封面时文件夹出现横向缺口

从内页反向滚回封面，文件夹与简历已经移到上方，但根 SVG 的实际视口仍位于内页。复现时，SVG 视口上缘约在页面可视区域的 704 px，文件夹已经画到约 297 px。Safari 原生滚动重绘未完整覆盖视口外的画面。

给绘制容器添加 `translateZ(0)` 只恢复了静止画面，继续滚动仍会复现；取消祖先横向裁切也没有解决。两项实验均未保留。

最终复用现有布局刷新入口，按封面到内页的实际范围设置 SVG 的位置、尺寸和 `viewBox`，保留原 640 × 450 坐标的缩放与留白。单张简历和文件夹继续使用原有坐标转换，滚动每帧不重新设置画布尺寸。

## 动效复核

使用 `systematic-debugging` 定位复现条件，按 `brainstorming` 收敛为现有设计内的兼容性修复，参考 `gsap-scrolltrigger`、`gsap-performance`，最后按 `review-animations` 复核。

| 修复前                            | 修复后                                       | 原因                                |
| --------------------------------- | -------------------------------------------- | ----------------------------------- |
| 倒放到零宽裁切时整句漏出          | 未书写状态使用极窄裁切，文字仍连续写入和退回 | 避开本机 Safari 的零宽 SVG 裁切异常 |
| 文件夹越出内页 SVG 视口后回滚缺图 | 视口覆盖完整路径，原画面坐标与比例不变       | 让原生滚动重绘包含实际可见的插画    |

复核结论：Approve，本次两处修复通过本地验收。没有新增时长、缓动、滚动监听或强制合成层，继续使用现有减少动效逻辑。
