# 职业档案常用文件预览

日期：2026-11-15。实施已获用户授权；完成实现与验证后交用户验收。

## 问题与目标

DOCX 已保存原件且能提取文字，但预览入口仅识别 PDF/TXT/Markdown，其余格式直接返回下载卡片。图片和表格连上传协议也未覆盖。此次完整接通上传、原件预览、下载及真实文字读取；不改变助手的显式资料范围。

## 调研与选型

| 类型                       | 采用库                                                                             | 能力与边界                                                                                                                           |
| -------------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| DOCX                       | [docx-preview](https://github.com/VolodymyrBaydalka/docxjs) 0.4.1，Apache-2.0      | 本地排版、分页、表格、内嵌图片；浏览器字体和 Word 排版可能有差异                                                                     |
| XLSX/XLS/CSV               | [SheetJS CE](https://docs.sheetjs.com/docs/api/utilities/html/) 0.20.3，Apache-2.0 | 库负责解析及 `sheet_to_html` 渲染；多工作表、数字格式和合并单元格。展示已保存的公式结果，不运行宏、公式；不承诺 Excel 图表和完整样式 |
| PNG/JPEG/WebP/GIF/BMP/AVIF | [react-photo-view](https://react-photo-view.vercel.app/docs/api) 1.2.7，Apache-2.0 | 本地原件、放大、缩放、触摸手势；不新增 OCR 或模型视觉能力                                                                            |
| PDF                        | 现有 PDF.js                                                                        | 保留分页和原件缓存                                                                                                                   |
| TXT/Markdown               | 现有安全文本展示                                                                   | 保留原文，不将文件文字当 HTML 执行                                                                                                   |

[SheetJS 官方安装文档](https://docs.sheetjs.com/docs/getting-started/installation/frameworks/)要求使用官方 0.20.3 发布包，npm 同名旧版不适用。`@js-preview/excel` 基于 ExcelJS + x-data-spreadsheet，若用于本项目还需要另一套文字提取链路；故选可复用解析结果的 SheetJS。`react-doc-viewer` 的 Office 在线模式需要公网地址，不适用私有档案。旧 DOC、PPT/PPTX 暂不增加上传入口，也不声称可预览；不接付费或外部在线转换。

`pick-ui-library` 现有清单没有 Office 文件渲染器；上述专用库按官方文档选型。文件工具条、工作表选择和翻页复用现有 shadcn Button、Select、Skeleton、Spinner，不自建文档/表格解析引擎。

## 行为

- 旧 DOCX 无须重新上传，打开详情即可读取原件并排版。标题、下载操作先显示，预览单独加载和重试。
- DOCX 在隔离容器中排版，关闭 HTML altChunk，阻止文件中的外部资源请求。保留原始纸张比例，窄屏适配，不让页面横向溢出。
- 表格解析放到按需 Worker；工作表可切换，长表分段查看，切换不重复下载原件。单份沿用 10 MB、60000 字符上限；只处理有界工作表范围，防止稀疏表格拖住页面。遇到限制给出具体原因，不能静默截断成完整资料。
- 图片可保存原件、查看及下载。其文字和段落真实为空，页面明确无可供 AI 读取的文字；不伪造 OCR。自动资料目录排除图片；显式读取空文字版本返回明确能力说明。
- 文件原件仍通过已有所有者校验获取；Blob 缓存按账户、版本隔离，URL 在组件退出时释放。渲染库按类型懒加载，目录和助手首屏不下载 Office 引擎。
- 上传入口在职业档案及助手加号同步覆盖；已上传状态使用“文件已保存”，不能将图片读入描述为识别文字成功。

## 后端兼容

共享 kind 增加 image、spreadsheet。仅图片允许空文字/零段落，其他格式继续验证完整原文对应关系。入口使用成熟文件识别库并沿用原 DOCX/PDF 校验；表格原件签名与格式相符。新增约束不改变旧记录、权限、事务、幂等和原件下载路径。迁移与 Edge 按仓库要求部署并做线上 smoke。
