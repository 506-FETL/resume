# 产品开发防回归清单

更新日期：2026-10-30。适用所有后续分期开发。

本清单来自当前会话、仓库 `AGENTS.md` 和已有规格、计划、验收复盘。它是可追溯的持久规则，不代表已经读取所有历史聊天。后续发现新问题时补充“触发场景、根因、约束、验收方式”，避免只记住一次性的修复。

## 1. 分期与产品承诺

- 按已授权的期次完成实现和验证，最后交用户审查。已明确授权的范围不重复索要批准；重大范围变化或无法取得的外部权限才请求用户介入。
- 用户未要求下一期时，不自动进入下一期。实施状态、验证状态、用户审查状态分别记录。
- 不提供点击无结果、上传无后续、升级未开放却仍可点击的假功能。状态未知、加载中、失败与真正空数据明确区分。
- 评分名称与依据相符，不把关键词比例包装成概率或行业样本结果；AI 不编造经历、数字或招聘效果。
- 开始前阅读涉及模块的历史资料，选择必要回归项；存在冲突时以最新用户明确要求为准并更新文档。

## 2. UI、布局与交互

- 组件必须先复用：项目已有的 shadcn/ui、Magic UI 与封装 → 官方组件或 registry → 成熟的 shadcn 风格组件 → 确实不适用才自建。先查再写，业务组件通过组合实现，不用原生下拉框、手写弹层或按钮重复已有能力。自建原因记录在计划中，并保持当前 shadcn 的视觉、键盘、焦点和禁用行为。普通语义布局与隐藏文件输入无需多余封装。
- 交付检查覆盖本次新增/修改的交互控件，不能仅凭“引入过 shadcn”认定符合规范。此次填写建议和导入核对都绕过了已有 Select，导致原生下拉框风格不一致；回归检查选择、方向键、Escape、滚动、禁用状态和关闭后的焦点。
- 沿用现有 PageLayout、PageHeader、表单、空态和反馈组件；优先调整任务层级与内容密度，不无关更换字体、颜色或导航体系。
- 第三期 UI 设计复盘（2026-10-26）：用户要求在求职跟进中增加岗位与投递能力时，首版原型把岗位详情当作主页面，并重组了看板、列表和抽屉，导致用户指出“完全变了”。根因是只复用了外层导航，没有按真实页面保留布局和操作路径。后续功能增量须以用户现有截图和实际页面为基线，保留看板 / 列表、工具栏位置、阶段列、详情抽屉及其三个页签；未获明确授权不改成独立工作区。验收先逐项对照原页面，再确认新增入口和完成路径。相关决定见[第三期设计](superpowers/specs/2026-10-26-product-phase-three-design.md)。
- 验证桌面、窄屏、长标题、空内容和错误消息。容器可收缩，长内容不能撑出水平溢出；同组信息对齐，主动作清晰。
- 求职工具栏与看板宽度补充（2026-10-28）：关注、公司筛选等入口增加后，共用一行 flex 会把手机搜索框压到只剩图标；固定列宽又使宽屏看板右侧留下空白。按最新要求，关注、归档、批量管理统一为右侧图标按钮，保留读屏名称、选中态和 Tooltip。窄屏将搜索与阶段筛选单独成行，公司选择与三个图标同排，分组、排序和筛选标签另行容纳。普通看板列改为最小 256 px、剩余空间等分，已结束折叠仍为 44 px；宽度不足仅在看板内部横向滚动。这替代旧规格中固定 256 px、不随屏宽拉伸的要求。验收覆盖 320 / 390 px 的看板与列表、筛选和批量状态，以及宽屏已结束展开 / 收起后的等宽铺满。
- 公司选择器对齐复盘（2026-10-28）：Base UI Combobox 生成的隐藏表单字段使外层 `space-y-2` 给可见 InputGroup 增加 8 px 底部 margin，工具栏居中的是包含空白的 44 px 外层，36 px 输入框因此向上偏 4 px。CompanyPicker 使用 `flex-col + gap-2` 排列可见内容，避免隐藏字段引入间距；不能用 translate 或负 margin 抵消。验收实测搜索、阶段筛选、公司输入的 top、height 和中线，并检查窄屏及新增职位中的复用入口。
- 会话列表等行内操作覆盖长标题时，遮罩必须覆盖整组按钮及间距，并使用半透明背景、背景模糊和边缘渐隐；仅渐变透明会让文字穿过图标。检查选中/未选中、悬停与键盘聚焦。
- 各模块独立使用真实加载依赖；已有内容在重取时尽量保留，错误提供重试。不能以跨模块共享 loading 或 Promise.all 阻塞无关模块。
- 异步完成、自动回填与远端更新不抢焦点、不打断输入。关闭弹窗和折叠内容后焦点回到有效触发点，退出内容不参与点击和键盘导航。
- 聚焦节点不能先被 aria-hidden 或 inert。抽屉、确认框要在内容节点实际就绪时交接焦点，记录并恢复入口；Portal 延迟挂载时，父组件 effect 不保证早于背景隐藏。入口已移除或只是 body/documentElement 时回到有效的备用控件。
- 无障碍回归同时检查浏览器 warning 和焦点，不只检查 pageerror。覆盖鼠标、键盘、取消、确认后节点移动和快速关闭；不得通过删除 aria-hidden 或屏蔽日志掩盖问题。
- 每个 DialogContent 都有 DialogDescription；Radix 与 Base UI 使用各自状态属性，不能照搬选择器。
- 全局额度弹窗焦点复盘（2026-10-29）：弹窗通过 store 打开，没有关联的 DialogTrigger，Radix 默认关闭处理无法返回入口，焦点落到 body。此类弹窗须在打开自动聚焦前记录入口，在关闭时返回仍存在的节点；不能只验证弹窗已消失。验收覆盖连续两轮关闭、快速重开和减少动效。
- 投递弹窗嵌套复盘（2026-10-26）：在 Base UI 岗位抽屉内打开 Radix 留档弹窗后，Escape 曾同时关闭两层。两套组件不共享浮层树，外层已有的 Escape 保护须包含 `dialog-content`；验收覆盖留档和记录投递两轮开关、快速重开、焦点回到触发按钮且原岗位抽屉保留。
- 组件复用复盘（2026-10-26）：第三期曾用 `Input type="date"`、手写加载图标、卡片和错误块替代已有封装。仅替换标签或保留组件 import 不等于复用完整能力；日期优先用现有 `WorkflowDateField` / Calendar，加载、反馈和空态优先组合 Spinner、Alert、Empty。验收检查真实控件、键盘与焦点，文件 Input 和普通语义布局不为形式重复封装。
- 日历嵌套补充（2026-10-26）：Radix 处理 Escape 时可能先卸载日期按钮，外层再调用 `event.target.closest()` 会丢失祖先，误关 Base UI 抽屉。使用 `event.composedPath()` 判断事件原始所属层；日历退出前把焦点移回触发按钮，退出节点设为 inert。验收选择、清空、连续两轮开关与快速重开，Escape 逐层退出，表单取消后仍在原岗位。
- 首页提醒卡片（2026-10-26）：标题与说明同字号、同粗细造成层级不清。标题使用 16 px / 600，空态说明使用 14 px / 常规灰色；面试、跟进、材料分别用相符的淡色大图标作左上角背景，渐变在左上局部消退，不铺满整张卡片。数量 Badge 须随卡片使用紫色、琥珀色、蓝色，并提供深色配色；不能只检查无数量的空态，遗漏默认灰色 Badge 与主题不一致的问题。验收桌面三列与 390 px 单列、标题与说明对比、有数据时的数量颜色，以及装饰不遮挡内容和操作。
- ATS 结果卡片（2026-10-28）：原卡片只有行内分数，缺少首页的左上装饰和局部渐变。按用户要求，使用本次评分作为淡色大号背景数字，数字与渐变复用已有评分等级颜色；背景数字使用本地加载的 Racing Sans One 字体，正文分数继续清晰显示。装饰不参与布局、点击和读屏，加载及无报告时不展示分数。验收覆盖桌面、320 / 390 px、深浅色、0 / 两位数 / 100、字体实际加载，以及现有状态切换和减少动效。

## 3. 动效

- 简历检查的原文定位高亮使用现有 Magic UI `Highlighter`，设置 `action="highlight"`，不叠加圆角色块、文字变色或下划线。按用户 2026-10-25 的明确要求，这一处设置 `animate={true}`，即使开启减少动效也保留一次荧光笔划过动画；该例外不扩展到其他交互，组件未指定 `animate` 时仍遵循系统偏好。
- 使用 `src/lib/motion.ts` 的 EASE、DURATION、SPRING 和已有 variants；新增动效全部接入 `useReducedMotion()`。除用户明确指定的上述高亮例外，减少动效时归零时长或去掉位移、缩放。
- 覆盖进入、退出、重复操作与快速反向切换，不能以首次挂载成功代替完整验收。
- 弹窗至少两轮完整打开/关闭，加一轮退出中再次打开。共享 Dialog 动画变化同时检查遮罩、内容和创建简历、创建分享、简历优化三个代表入口。
- 折叠使用仓库既有动画及 overflow-hidden，退出短于进入。避免用延时或重复 remount 掩盖生命周期问题。
- Tab 切换让选中指示条连续移动，内容容器保持稳定。退出面板禁用交互前先将焦点移到目标 Tab，不能假设 pointer down 已完成默认聚焦；保留语义、方向键操作和切换时的草稿保存，减少动效时归零。
- 在 AnimatedContent 或带 key 的过渡容器中重挂载 variants 子项时，必须由同一新子树的显式 initial/animate 驱动，不能等待外层已经完成的动画再次触发。验收要检查实际 opacity 与可见性，DOM 中存在文本不代表用户看得见。
- 内容切换残留复盘（2026-10-26）：popLayout 的旧、新文字同时淡入淡出，会在同一区域叠成残影。新内容可提前初始化和测量，但可见进入应与旧内容退出衔接，退出不能继承进入延迟；保持焦点交接与退出节点隔离。验收逐帧检查两组文本是否同时可见，并覆盖快速往返、内容高度变化和减少动效。

## 4. 数据、账户与异步任务

- 重点关注与投递详情复盘（2026-10-28）：无原件的投递被展示成“待补材料”，加上外卡/内卡重复描边，造成已完成流程仍像欠任务且边缘被滚动容器裁切。以最新重点关注规格替代旧材料待办：首页红旗仅汇总未归档且非结束/录用的手动标记岗位，终态保留标记；无原件不显示补传或假预览，投递事实用分区信息行，已有原件单行展示并可更正。验收覆盖首次无原件、旧 pending、PDF/DOCX/平台原件与修订、320/390 px 边界和真实焦点。
- 红旗与业务时间分离：关注经过旧更新时间触发器会改变“久未跟进”的判断；company 专用触发器仅对关注变化保留 updated_at，其他业务字段仍更新时间。客户端使用已有串行字段保存队列，点击时捕获明确目标，不在请求失败回滚后的队列里重新取反。验收覆盖关注/取消时间不变、普通更新、第一请求失败后排队取消以及跨账户隔离。
- 流程字段完整性：通用差异过滤曾删除未变化的面试数组，导致结束流程的 RPC 被拒绝。状态转换保留接口要求的 status、stage_details、interview_sub_stages、activities；普通字段仍按差异写入。验收须实际结束、恢复与拖动推进，不能只验证数据库函数。
- 重载后的焦点：编辑投递事实保存会替换触发按钮，旧 DOM 引用失效。关闭时读取当前按钮 ref，加载期间回到稳定的详情 section；验收保存和取消后的 activeElement，不能只测首次打开。

- 公司与一次投递重构复盘（2026-10-28）：回填公司引用会触发旧的更新时间触发器，必须在迁移局部禁用并恢复该触发器，逐字段比对原数据。真实 PostgreSQL 并发曾复现确认投递、草稿保存与阶段转换之间的锁顺序冲突；涉及名额的事务统一先锁公司、再锁岗位，普通笔记保存不获取公司容量锁。SECURITY DEFINER 新建入口须显式检查准备简历的账户归属，不能依赖被提权绕过的原 RLS。验收使用 authenticated / service_role 的真实连接，包含两岗位并发开始、归档仍占位、恢复冲突与跨账户简历绑定。
- 主投递的 submitted_on 是已投递阶段日期的唯一来源；在面试或结束后补记也要同步日期，但不推进或回退当前阶段。旧多条凭据保留到明确选定主记录，更正材料前保存旧快照和文件引用。恢复使用原活动 ID 去重，保留结束详情和历史轮次结果。验收覆盖未知日期、重复请求、两次恢复、PDF / DOCX 下载字节一致及旧材料回看。

- 请求、缓存和 finally 都受账户/目标/操作版本约束；旧账户响应不能覆盖新账户，登出清理相关状态。
- 简历切换、模板切换、离开编辑器的保存捕获目标 ID 与快照；实际成功前不标记“已保存”，迟到响应不覆盖新编辑。
- 本地同步只移除成功项，失败项保留并可重试。上传新头像与更新引用成功后再清理旧资源。
- 本地同步的持久映射只固定目标 ID，不提前锁定正文。首次上传失败后继续编辑时，旧签名曾在查询云端前永久阻断重试；应由上传入口校验实际云端副本是否与本次内容一致，删除本地副本前再检查上传期间是否有修改。验收覆盖失败后编辑重试、结果未知后的重复请求、云端冲突、上传中编辑和账户切换。
- 历史比较、恢复、投递快照保持正文、外观和精确模板绑定一致。JD 改写核验目标条目、原文与可写字段，未知路径不能静默成功。
- 求职跟进预览字段复盘（2026-10-26）：展开“准备中的简历”时，接口返回 `template_binding`，预览却读取 `templateBinding`，使有效引用被误判为缺失并触发整页错误。数据库行类型须使用真实字段名，在预览转换处映射为渲染字段；不得用默认模板掩盖映射遗漏。验收覆盖数据库形态的默认与非默认精确版本，并在真实抽屉展开、收起后再次展开检查预览。
- 岗位绑定复盘（2026-10-26）：选择准备简历后切换岗位，旧请求完成曾写回当前岗位上下文；连续选择还可能使早发请求最后落库。发起与完成都须核对账户、岗位和操作代次，离开页面时失效；同页绑定按次序落库，跳过尚未开始的过期选择。验收覆盖切岗、切账户、卸载、连续三次选择及失败重试，检查最终数据库关联和页面上下文一致。
- 补记投递的 JD 复盘（2026-10-26）：记录保存的是创建记录时的 JD，并不能证明过去投递时的招聘内容。展示须称“记录时保存的 JD”，明确历史原文无法确认，缺少更新时间只表示未记录时间。验收覆盖未知、过去和当前投递日期，以及未知或晚于投递的 JD 更新时间，不能借时间字段推断不存在的历史事实。
- 助手停止、重试和编辑消息必须尊重持久历史与取消状态，不能在取消后继续写入。

## 5. 分享、评论与协作

- current 分享随已保存内容更新，history 分享固定快照；正式投递与持续审阅使用明确语义，不能偷偷改变已有链接契约。
- 隐藏模块与条目在服务端公开投影中也要过滤。分享权限、有效期和密码变更应真实生效。
- 岗位上下文使用服务端归属读取，在验证岗位及关联简历后才挂载编辑、优化、历史等页面；异步结果同时核对账户代次和当前岗位。正式投递分享只能使用自己的固定版本，创建分享不产生已投递事实。公开展示和隐藏联系方式的分享不得签发评论访问凭据，既有评论凭据也须在每次请求时重新检查策略，防止正文、锚点绕过快照过滤；隐私策略参与内容修订号，修改后不能误返回“无变化”。验收同时覆盖响应正文、旧评论凭据、实时与固定分享、换版和账户切换。
- 协作需要有效授权；评论绑定真实文段和版本。无法唯一重连时保留待处理状态，不错误附到另一段原文。
- 评论分页按实际返回事件推进游标；通知只是提示，断线要补齐。订阅销毁后不复活，不对同 topic 重复断连。
- 协作人数按服务端校验的 userId 去重，不能直接统计 peerId；底层仍保留各标签页的连接用于同步。连接初始化必须保留首次发现的成员，退出提示只在该用户最后一条有效连接离开时显示；未知连接、自身与过期回调不提示。验收覆盖双页面重入、多标签页、旧连接过期和同步消息传递。

## 6. 性能与模板资源

- 模板目录只加载摘要和必要静态图；按可见范围、打开详情与用户意图加载资源，不能每张卡片都启动完整分页引擎。
- 复用请求、缓存和并发限制；测量稳定前保留已有展示，避免文档突然缩成一页导致滚动跳动。
- 已发布模板与素材保持精确版本与不可变引用；缺少指定资源明确报错，不静默降级成其他模板。
- 模块可见性只由隐藏开关决定。清空正文、删除全部条目或隐藏全部子条目后，未隐藏的模块仍保留标题与模板装饰，正文为空；只有隐藏模块才移除整项。此前内容适配层按非空内容块过滤模块，导致清空自我评价后标题一并消失。验收覆盖富文本空串、空段落、空列表、隐藏子条目、模块开关及预览与 PDF 一致性；此规则取代早期模板规格中的空模块过滤约定。
- 优化前定位真实瓶颈，比较加载、交互和内存表现。不能以删掉验证、内容或降级正确性来制造“变快”。
- 编辑检查不能在每次按键时反复扫描整份正文。停笔后合并执行，排版结果变化复用文字规则；关闭的导出弹窗不计算检查摘要。高频订阅放在独立组件，不能让检查结果带动整个编辑页重绘。
- 来源证据转换也在停笔后的检查中执行。此前转换发生在防抖前，且每条 JD 改写重复解析整个模块；相同不可变模块引用应复用解析结果，正文修改或条目重排、删除后使用新引用重新核对。验收对比相同数据的解析次数，并在实际输入、粘贴、保存恢复和导出中确认使用最新内容。
- 延迟检查必须保留正确性：导出读取最新正文，确认和采用建议前重新校验当前内容，切换简历时丢弃旧结果；正文改变后立即取消过期 AI 校对。性能验收使用相同数据和连续输入场景，对比实际调用次数，不能只凭主观感受。

来源：[模板页性能](superpowers/specs/2026-10-24-template-page-performance-design.md)、[模板加载](superpowers/specs/2026-10-23-template-gallery-loading-design.md)、[模板维护](resume-template-maintenance.md)。

## 7. 分页与导出

- 测量、展示、打印正文几何和字体一致；装饰不占正文布局。不放宽布局签名来掩盖差异。
- 所有模板复用 print-color-adjust；打印背景开和关都要验证。
- 触及模板、公共打印或分页时，覆盖短内容、临界页底、多页长内容、默认模板，并通过真实导出检查 PDF 的文本、样式与分页。
- Word 独立核对实际排版；构建与协议校验不替代真实文件验收。

## 8. 代码与交付

- 在当前分支工作，保护已有未提交修改；没有明确要求不 push。中文提交信息遵循仓库格式。
- 页面创建或重构遵循 history-style 结构，组件用文件夹 index.tsx；页面共享状态与动作放 store，避免多级 props。
- 全局与复杂状态用 Zustand，组件子树 UI 状态才用 Context，临时单组件状态用 useState；不要为简单局部状态增加全局耦合。
- 按职责留空行，遵循两空格、单引号、无分号；改动文件先 Prettier 再 ESLint layout 修复，格式调整不得夹带逻辑变化。
- 重复代码修复复盘（2026-10-29）：文件整理时发现同一导入、变量、对象属性和整段 JSX 被重复保留，并混入已移除的首页接口调用和工具配置字段，导致编译失败、重复界面及 `asChild` 多子节点错误。后续应用或调整补丁时须核对当前文件与差异，避免同一逻辑保留两份；格式整理只调整空白，不顺带改写逻辑。验收同时检查类型、构建、重复 JSX 和组件调用约束，不能只以 Prettier 通过为准。
- 不强制 TDD，不创建只复述实现的测试。需要的临时验证和夹具统一放 tests/，结束删除；scripts/ 不放验收脚本。
- 根据变更执行必要类型、lint、构建和产品流程验证，记录实际结果与限制。没有最新证据不能声称已完成。
- 检查规则替换后核查旧实现的运行时引用；无调用方的旧引擎应删除，避免签名、忽略条件与提醒文案分叉。本次删除了已被 resume-checks 替代的 preparation 检查引擎，验收以引用检索、类型检查和编辑/导出实际调用为准。
- 涉及 Supabase 迁移或 Edge Functions 时，开发与隔离验证后完成当前链接项目的部署、账本、函数版本与线上 smoke；只有确实缺少权限或凭据才请求用户介入。
- 投递记录部署复盘（2026-10-26）：前端开始查询新表而迁移仍停留在本地，线上返回 `PGRST205`；PostgREST 的普通错误对象又被页面当成“未知错误”。新增后端依赖必须核对云端迁移、函数版本和真实请求后才能交付；分批部署只包含已验证的迁移。接口边界将普通错误对象转为可识别的错误并保留原因，界面不能把失败当作空列表。验收覆盖缺表提示、真实空列表、写入后重读及跨账户拒绝。
- 分享字段授权复盘（2026-10-26）：新增用途和联系方式列后，管理端读取返回 `42501`，因为既有表按列授权，新列不会自动继承。新增字段同时检查现有 SELECT/INSERT 授权清单，不能改为全表授权绕过密码哈希隔离；验证须使用真实 authenticated 角色读写、匿名拒绝及敏感列拒绝，不能只用数据库 owner 跑触发器测试。

## 9. 文案与沟通

一期审查中，用户指出文案像 AI 生成的，读起来不自然。问题包括首页堆叠“下一次机会”“从真实经历开始”等口号，把内部分析术语写进页面，以及反复强调真实性，让普通操作提示像一份规范。

- 标题说清页面或任务，按钮说清点击后的动作。例如“继续编辑简历”，不用“继续打磨你的下一次机会”。
- 说明写用户当下需要知道的内容。例如“暂时不能购买额外额度”，不用“尚未提供付费扩容”。能删掉而不影响理解的口号、重复标题和套话直接删掉。
- 建议落到具体内容。例如“补充你负责哪部分、做了什么”，不用“强化能力证据、完善内容画像”。确实需要专业术语时，用一句话解释它指什么。
- 用正常、克制的中文，不为了显得亲切加入语气词、网络用语或刻意鼓励。不要把所有提示都写成三段排比，也不要用“不是……而是……”反复说教。
- 简短不等于省略事实。文件支持范围、数据保存位置、额度状态和评分依据仍需说明；AI 提示保留不编造、不清楚先问、由用户确认事实的要求。
- 文档和日常回复也遵守这些要求。先讲结果或问题，再讲必要细节，不用一串流程术语代替说明。

验收时先在实际页面按标题、说明、按钮、状态提示的顺序通读：是否像正常中文，是否知道下一步能做什么，有没有重复或无关的劝导。再检查桌面和窄屏的换行、按钮宽度、空态与错误态；不能只靠关键词扫描判断文案是否合格。

## 10. 求职跟进布局与统计

来源：[统计与布局修正](superpowers/specs/2026-10-25-tracker-layout-counts-design.md)。

- 最新业务规则（2026-10-26）：公司管理单个 / 多个同时进行的岗位流程，同一岗位流程只投递一次，已投递阶段与提交材料共用一次事实。单流程公司结束后可申请其他岗位；被捞回接续原流程并保留结束和面试历史，不增加投递次数。旧多次投递规则已撤回，后续按[公司流程重构设计](superpowers/specs/2026-10-26-company-process-design.md)实施；公司归并和历史材料不得静默覆盖。前述投递记录 A / B 版式调研不再单独落地，材料布局随新模型审查。

- 阶段计数使用当前状态，与列表筛选和看板使用相同的搜索、归档范围。历史投递与响应率使用独立字段，不能让“已投递”把面试、录用职位一起算入。无数据、加载失败与零分开显示。
- 看板普通列固定为合理宽度，超出时内部横向滚动。不能为了填满屏幕，让唯一有内容的列和卡片无限拉宽，也不能把空列压得标题无法阅读。验证宽屏、手机和侧栏展开/收起。
- 职位卡片以职位名、公司和必要辅助信息为主，默认紧凑两行；跟进内容存在时再增加一行。长公司、地点、薪资和批量复选框一起验收，不能只测短字段。hover 使用轻微边框、背景与阴影过渡，避免突然位移；先确认底层组件实际使用 border 还是 ring。
- 整卡拖动复盘（2026-10-26）：标题按钮被共享拖拽的交互元素过滤规则排除，导致同一卡片部分区域无法拖动。标题和装饰的指针命中交给整卡，标题继续保留键盘按钮语义，批量复选框保持独立操作；不能为修复标题而取消共享拖拽对真实表单控件的保护。验收从标题、Logo、边缘空白分别拖动，普通单击与 Enter 打开详情，复选框只选择；验证时取消状态变更，不改用户岗位数据。
- 定位、筛选和归档提示放在阶段筛选旁，不额外占据一行职位展示空间。窄屏可在工具栏自然换行。批量操作按用户最后要求保持原有位置与样式，不套用标签上移规则。
- 跟进安排使用紧凑入口和 Popover，保存摘要在入口可见。编辑草稿与保存值分开，关闭弹层后重开不丢草稿，失败不假装保存成功；日历与外层弹层逐层关闭，退出节点不参与交互。验收重复开关、反向切换、失败重试、手机尺寸和减少动效。
- 面试轮次删除复盘（2026-10-26）：只淡出卡片、立即移除连接线，会让“添加下一轮”先跳过间距，再在卸载时跳过卡片宽度。复用 PresenceDiv，同步收起卡片占位和连接线，退出节点不可交互；按桌面与窄屏使用明确宽度，退出期间暂停自动定位，完成后再定位。删除被撤回时及时恢复定位。验收中间轮、末轮、窄屏滚动到末端、退出中恢复后新增，以及减少动效；必须观察中间位置，不能只看最终截图。
- 投递记录布局调研（2026-10-26）：用户反馈边框被截断、标题与正文层级接近。代码中 Card 的外侧 ring 紧贴可裁剪的滚动区域，size=sm 又使标题与正文同为 14 px。后续修正应在业务区域内解决边框与留白，区分标题、状态和说明，复用已有 Card / Empty / Button；不能通过取消抽屉滚动裁剪或全局改 Card 影响其他页面。验收需覆盖空态、有记录、失败与加载，以及窄屏和键盘焦点。当前仅完成调研与对照图，布局尚待用户审查。

## 11. 简历导入与核对

- 解析结果是待核对的内容，不自动当成事实。原文完整保留；不确定的字段留空或未归类，不把职责、技术栈猜成公司或岗位。
- 日期正则覆盖 1～12 月、两位月份的完整边界、单独日期行和“至今”。经历不能只凭日期或分隔符切段；标题识别与分组使用同一份依据，缺少标题时安全保留内容。
- DOCX 的文本框、正文、页眉和页脚可能存在嵌套段落，每个文本节点只能计入一次；解析限制同时检查压缩输入和实际展开体积。
- 文件读取与自动整理、填充预览和最终创建是三个状态。取消读取或整理不覆盖原输入；确定未发送创建请求时允许返回修改；结果未知时保留操作身份，先查询再重试，刷新后也不能重复创建。
- 本设备保存不等于不需要账户隔离。导入原文、草稿和检查记录都按账户隔离，游客使用独立范围；异步继续动作核对发起时的账户和操作。
- 保存失败时不能同时显示“已保存”。从其他页面打开既有组件时，按组件的实际依赖加载数据，不能假设用户此前访问过某个列表页面。
- 富文本与纯文本互转不能在每次输入时裁掉换行和末尾空格，核对输入框必须实测连续输入、多行和刷新恢复。
- PDF 文本块不是词。按基线和实际字间距恢复行与字段，避免给相邻汉字强行插空格；兼容字形只在提取副本中规范化。须用平台实际导出的中文 PDF 回读，覆盖姓名、中文标题、公司岗位分隔及 10～12 月日期。
- 本地转云端和岗位定制产生新简历 ID 时，要同时接续本浏览器中的原文、示例、AI 来源和处理记录。来源读取或保存失败不能当成“没有记录”；只读取当前账户和明确同步的游客内容，不能扫描其他账户的数据。
- 重试身份必须来自稳定的用户操作，不依赖模型返回的关键词或随机结果。同步删除本地副本前，确认上传内容与当前本地内容一致；云端记录存在不等于本次内容已成功保存。重置未完成的派生内容失败时，不能继续标记完成。
- 导出检查忽略不打印的“不填”选项及纯展示配置；经历已有正文却缺少公司、学校或项目名称时要提醒。忽略理由与确认结果绑定具体条目和内容，不能把旧确认套用到新内容。
- 编辑检查只处理正确性和阅读提醒；经历表达、职责成果、岗位相关性与关键词证据留在第四期 P4-05。
- 明确错误标红，待核对标黄，建议标蓝。AI 来源只汇总提醒。按用户 2026-10-26 的要求，导出不要求勾选确认：有明确错误时按钮标红并允许直接导出，只有提醒时维持默认样式；只有文件本身不能生成才禁用对应格式。
- AI 校对必须匹配可见字段、原文证据和内容签名。不能靠编辑距离把“前端”改成“后端”、把“本科”改成“专科”；未知词只提示核对，明确错词表才能提供一键更正。大小写风格不当作红色错误，命令与代码语境保守处理。
- 定位覆盖层与正文、测量及打印副本分离；页内重复源内容必须按实际页面和区域裁剪，不能高亮其他页的隐藏副本。采用、保留和撤销都核对稳定条目与内容签名，撤销不得覆盖后续编辑。
- 检查入口、填写/检查切换、字段反馈和导出摘要使用相同等级；总体颜色取未处理问题的最高等级：错误 > 待核对 > 建议，全部处理后恢复默认。不能只给检查列表上色，其余入口仍为中性样式。
- 预览高亮必须同时核对面板可见、当前检查 tab、问题展开和筛选可见性。切换填写、收起问题、关闭面板或进入历史版本后清除；原有定位状态不等于当前仍在查看检查。定位换目标前不能复用上一处的测量矩形。
- 填写字段直接标记标签与控件边框，说明复用 shadcn Tooltip 并提供无障碍描述；不另占一行显示遗留问题标题。重排后按稳定条目 ID 匹配字段，确认或修改后清除，签名校验依赖不能误标成问题字段。
- 编辑页的工具栏居中，不展示面包屑；填写/检查切换与保存、协作、分享共用操作行。手机工具栏全部用有明确名称的图标按钮。窄屏换行时页头高度必须随内容变化，不能用固定高度让按钮覆盖正文。
- 模块内部滚动触顶或触底后应自然传递给外层列表，不能用 overscroll-contain 把滚动困在模块中。验收必须用真实滚轮连续滚动，不能仅检查 overflow 样式或设置 scrollTop。

## 12. 创建简历向导

来源：第二期用户审查，2026-10-25；覆盖此前“从零创建空白页”和自动恢复步骤的设计。

- 从零创建按求职阶段填入明确标记的示例，并记录来源供导出检查；不能只显示“姓名”的空白页。导入创建只使用从原文填充或用户修改的正文，不混入模板示例，不要求逐模块勾选确认。
- 两种创建方式都先选模板，再保存。使用已发布模板的精确版本，保留正文顺序与可见性。返回修改同份内容时保留选择；请求发出后冻结正文、模板和操作身份。
- 导航与草稿内容分开。每次打开固定在三个入口，只有主动点击继续才恢复草稿；保存结果未知的操作仍能继续确认，不能因回入口而重复创建。
- 标题与主动作固定，正文在有高度边界的容器中滚动。长输入尽量由主容器滚动；保留独立原文滚动时，触底后滚轮必须能交给父容器。验收需记录连续滚动、中段反向、触底反向，不能只看到滚动条就判通过。
- 选择页只保留简短差异说明，去掉重复保存提示和空页脚。文件类型、上限、数据用途保留简短提示；详细错误在发生时说明。
- 同一创建操作刷新重试时，正文条目 ID 必须稳定；不同创建使用不同身份。示例证据按最终正文条目记录，不能出现简历已恢复但检查记录无法匹配的情况。
- 步骤切换的标题、正文、页脚必须同步进入新布局。不能让旧正文等待退出时仍参与高度计算、而新标题和页脚已经改变尺寸；外框按实际测量的宽高平滑过渡，内容保持目标宽度，避免文字跟着外框反复折行。测量使用布局尺寸，不能把弹窗入场缩放后的视觉尺寸作为下一次布局依据。
- 模板选择高亮画在卡片内侧，不改变卡片尺寸。不能依赖超出边界的 ring，导致第一行、首列或滚动边缘被裁切；同时检查鼠标选择和键盘焦点。
- 填写建议分清“写什么”和“参考示例”，每条建议只说一件事。原文仅在存在时提供折叠入口；保存位置说明跟随原文，不把来源记录、存储实现和无关空态堆在建议上方。

## 13. 自动填充与免费识别

来源：2026-10-25 用户反馈上传后的手动核对过于复杂，且基础导入成本不应由用户承担。规格见 [自动导入设计](superpowers/specs/2026-10-25-automatic-resume-import-design.md)。

- 文件选择后自动提取、归类、填入并进入预览；上传和粘贴作为两个替代入口。“修改内容”按需打开，主动作直接选择模板。未知内容显示非阻断摘要并保留原文，空结果不能宣称成功。
- 本地提取与解析用于回退，字段非空不能证明分类正确。登录后非空导入使用一次独立免费识别（沿用缓存与限额），不接入付费 llm-proxy 或任何积分预留/扣减动作。文字会发送服务端及模型的事实必须在上传前明确说明，不能继续声称全文仅本地处理。
- 模型只归类原文，服务器返回校验后的行/字符范围；原始提取文字独立保存，规范化正文不冒充原始字节。账号＋摘要＋协议版本原子去重，限额按上游尝试计数，缓存仅保存位置索引，失败重试与租约都有上限。
- AI 合法但不完整的结果不能清空本地字段。经历比较先规范化日期，使用同一来源中的完整公司/岗位去重；部分岗位名称不能变成第二条经历。删除元数据时先合并重叠索引，相同起止日期不能重复删除正文。
- 正文去重和未归类清理使用完整行/明确来源匹配；禁止任意子串去重，例如 Java 不能被 JavaScript 吞掉，AI 未映射的 Java 必须仍有未归类提醒。
- 回归覆盖真实 PDF/DOCX、公司简称、重复年月、年份中文格式、部分字段、未映射技能、取消/更换/关窗的操作版本保护、跨账户缓存、并发限额和租约恢复。线上使用合成简历与临时账户验证积分不变，清理测试账户。配置必须核对既有函数使用的实际环境变量名；当前 DeepSeek 服务兼容 OPENAI_API_KEY。
- 来源依据：[真实 PDF 分类修复](superpowers/specs/2026-10-25-import-source-ownership-design.md)。模块及条目须按来源行号合并，`·`、`|` 等展示分隔符不能成为岗位/专业字段。不同标题行的任期不能靠同公司同岗位合并；字段匹配只兼容无来源旧结果。
- 同源字段允许采用 AI 的语义角色；仅当本地值是同字段连续原文的严格扩展时保留长值，不能用“非空且在原文”维护已经反转的公司/岗位。明确原文模块优先于 AI 的工作/实习标签。
- 续页标记接续前条经历，不把下一页内部技术小标题升级为新公司；保护依据原文父级，不依赖 AI section。续页标题冒号后的正文必须保留。“技术栈：React”等经历内说明不能无条件切成顶层模块。
- 文本模块或新识别经历转移时，从原条目移走对应来源行，避免同一正文归属两处。只消费实际保留的行，不能将因本地范围裁剪而未保留的文字同时从未归类中清除。验收覆盖实际 PDF、构造合法映射与正式 organize 入口；区分本地回放和真实模型调用。

## 14. 编辑输入性能

来源：[编辑输入卡顿复盘](superpowers/specs/2026-10-26-editor-input-performance-design.md)，2026-10-26。

- 性能验收必须测实际输入事件，普通字段和富文本分别连续快打至少 10 秒，并测 10 秒反复粘贴（含多段与单段）。不能以检查次数减少代替打字响应；覆盖中文组合输入、已有警告、多页预览，记录处理时长、长任务及内容完整性，区分输入期间和停笔后的预览更新。
- 表单数据同步在独立子组件订阅，复用字段级更新和光标保护；禁止让整个 FormProvider 随每个字符重绘。字段反馈上下文只随问题或条目路径变化，不能因无关正文更新重新创建。
- 测量页与各展示页共用同一快照的评论及内容投影。预览仅订阅正文和外观，缓存键包含投影日期；旧快照用 WeakMap 释放。HTML 缓存仍必须走原有净化，不能为提速关闭安全处理。
- 预览可以低优先级更新，输入写入与保存不能因而推迟到失焦。导出同时验证预览包含最新正文及外观、分页已就绪；不得导出旧快照或放宽打印签名校验。
- 拆分订阅后必须验证远端字段更新、经历新增/删除/重排、光标、保存刷新和最终导出末尾文字，不能只测渲染次数。

- 顶层布局不能用扫描整页后代的 `:has()` / `group-has-*` 判断侧栏状态；优先使用已有状态，结构判断限定直属子节点。输入卡顿同时检查浏览器样式重算与布局，不能只看 React 重绘。
- 富文本工具栏只订阅按钮需要的 can/isActive 等状态；不要订阅完整 EditorState。隐藏的浮层不应因滚动发送定位事务，选区变化后仍需验证按钮与浮层行为。
- 连续输入可合并预览更新，但必须保持即时写入、既有保存策略，以及导出最新快照检查。测试输出应放在开发服务已忽略的目录，避免生成 HTML 等文件触发热更新、污染测量或中断保存。

## 15. 全站界面与动效精修复盘

来源：[本轮设计](superpowers/specs/2026-10-28-frontend-refinement-design.md)、[验收记录](superpowers/specs/2026-10-29-frontend-refinement-acceptance.md)。

- 系统偏好运行中变化：安装的 Motion 12 同名 hook 只保留挂载时的值，导致开启减少动效后 CSS 已停止、JS 动画仍在运行。统一从 `@/hooks/use-reduced-motion` 订阅媒体变化；不能靠重挂载页面生效，否则会丢表单和预览状态。MotionConfig 只是补充，组件自己的时长、位移、自定义滚动及 WAAPI 仍要降级或取消。验收必须覆盖不刷新页面的开启、关闭和进行中的动画。
- 数字动画中断：切换减少动效后，React 文本可能恢复初始值，而 MotionValue 已等于目标、不再触发 change。订阅前立即同步当前值，减少动效时停止 spring 并写入目标；连续目标更新从实际显示值接续。验收包含动画途中反向和结束后的偏好切换，不能只看首次动画。
- RHF 列表退出：AnimatePresence 保留旧索引的 Controller，会让延迟卸载影响已经移动到该索引的字段。条目删除时实时字段立即卸载，仅保留不含 id/name、不可交互的静态视觉副本；相邻字段继续按稳定 id 挂载。列表后的添加入口也要有持久布局容器，防止先跳到终点。验收中间/末项删除、新增、重排、剩余输入、保存刷新，并采样退出中间位置。
- 常驻页签：需要保存预览、编辑草稿及滚动的 forceMount 面板，不能以 hidden 立即切走，也不能改成卸载重建。区分目标与显示页签，旧内容退出完成才切换显示，快速反向回到当前面板；隔离退出内容前交接焦点。只保留一层活动指示器，不能让静态底色盖住公共滑动指示器。验收输入值、DOM 身份、scrollTop、方向键、编辑触发切换和减少动效。
- 评论入口的焦点：入口随抽屉打开而卸载时，primitive 默认返回的旧节点已失效。使用已有 Drawer 的 finalFocus 返回重新出现的有效入口；入口淡出前先释放自身焦点，再隔离退出节点。验收两轮关闭、退出中重开、减少动效与浏览器 aria-hidden warning；公开分享复用相同约定。
- 资料会话信息：已有用户数据能提供注册/登录等静态元信息时，直接使用已加载的用户对象，不另发重复请求并留下无恢复入口的骨架。
- 浏览器验收要等待真实数据状态：优化报告首次加载数秒仍可能是正常等待，不能把骨架截图当成完成页面，也不能仅据短等待宣称永久加载故障。截图、过渡中间帧、交互结果分别记录。
- 模板待核对项：本轮默认模板 v3 的两页合成简历出现空“自我评价”标题在第一页底、分隔线在第二页顶。根因尚未定位，不能宣称是本轮引入或已经修复。后续模板维护须用该打印副本复现，按短文/页底临界/多页和背景开关验证；不能放宽打印签名校验掩盖问题。

## 16. 六项动效补齐复盘

来源：[设计](superpowers/specs/2026-10-29-motion-completion-design.md)、[计划](superpowers/plans/2026-10-29-motion-completion.md)、[验收](superpowers/specs/2026-10-29-motion-completion-acceptance.md)。

- 数字和高频切换：统计弹簧的长尾使 0→100 在一次隔离采样中约 3.17 秒才显示终值，页签退出与进入串行也累计等待。数字使用有界 280ms 插值，从当前值接续；高频内容统一 CONTENT_SWITCH 的 70/140ms，保留先退后进、常驻 DOM 和焦点交接。验收实际终值、反向、中途减少动效、逐帧叠字及草稿/滚动保留，不能只核对配置数值。
- 移动键盘和短视口：编辑抽屉未使用已有 VirtualKeyboardProvider，可视区收缩后字段仍在键盘下面。Provider 放在 Drawer Root 内，Viewport 消费 primitive inset，Popup 相对可用区定位；横屏不足时仅在编辑抽屉局部压缩留白，保留控件尺寸与滚动。验收普通字段、底部字段和富文本选字，以及评论、导航、嵌套抽屉；模拟 visualViewport/CDP touch 不等于系统键盘实机验证。
- 运行中减少动效：把 CSS transition-duration 改为 0 不保证浏览器已经启动的过渡立刻结束。抽屉偏好变化时还要结束 Popup/Overlay 自身及直属 content/handle 进行中的 CSS 过渡，保留最终位置及原有 ref；不能遍历任意业务后代或结束独立无限动画。验收检查真实 transform、遮罩与嵌套内容 opacity、活动动画及 ref 清理，不以 computed duration=0 单独判定通过。
- 拖拽与滚动：无溢出或已经触底的容器仍因尝试 scrollBy 被当成“已滚动”，持续续帧；高频 pointermove 还重复测量几何。合并每帧最新坐标，按真实 offset 变化续帧，限制另一轴命中；提交前同步核对最终落点，所有取消和卸载清理帧、捕获及 body 样式。验收真实滚动到边界、容器外、源移除、取消回源中间位置和收尾重入。预览不是业务成功信号，仍须保留终态确认和异步保存。
- 拖后点击：350ms 抑制曾把紧接的标题 Enter 一起吞掉。只抑制当前拖动的合成指针 click，detail=0 的键盘操作正常执行，新 pointer/touch down 清除旧抑制。验收拖后立即 Enter、普通单击和独立按钮，不能只测拖动成功。
- 助手流：稳定历史和输入器全量订阅 store，导致每次 token 更新重复执行无关组件。非流 UI 只订阅实际字段，消息保持不可变引用与 memo；等待提示使用小面积 opacity。相同历史和至少 10 秒流分别记录组件执行、Profiler、脚本、长任务及 Paint/Layout，不能把渲染次数下降说成所有绘制或手机 FPS 都改善；同时回归停止、失败重试、取消、上滚与画布快切。
- 保存反馈：视觉文字、图标和重试入口按同一个语义状态切换；读屏状态立即更新。退出前先把按钮焦点交给稳定节点，再设 inert/aria-hidden；新状态不能仍触发旧重试。通知复用 Sonner 的更新/取消机制和公共时长，验收加载→成功/失败、重复更新、取消与运行中减少动效。

## 17. 「专注编辑」视觉重设计复盘

来源：[设计](superpowers/specs/2026-10-29-visual-redesign-design.md)、[计划](superpowers/plans/2026-10-29-visual-redesign.md)、[验收](superpowers/specs/2026-10-29-visual-redesign-acceptance.md)。

- 首页模块增加时，不能默认给每块同等重量的大卡。继续编辑、求职提醒与待办优先，统计和动态作为辅助；桌面和手机分别检查阅读顺序。保留用户确认的三提醒语义色、大淡图标、局部渐变及 ATS 真实分数水印，不机械套用反装饰规则。
- 去除包装组件前先核对它承担的真实动作。GitHub 粒子与简历光晕被移除时，链接、按钮、菜单、状态和键盘交互必须由现有组件继续承接；验收不能只看截图。
- 条件空态仍属于列表切换。新建卡不能只有进入没有退出，使用公共时长、缓动和减少动效；覆盖有数据与空筛选切换，并确认焦点仍有效。
- 普通设置区从卡片改为信息行时，检查基础 Card 默认 ring、阴影和内边距，不能只删外层 class 就认为边界已消失。实际查看浅色、深色及窄屏，字段焦点样式保留。
- 圆角需核对 token 的实际数值。当前 rounded-xl 是 14 px，超过本轮普通容器 12 px 上限；本轮首页最近简历、待办、简历对象、分享卡和 ATS 摘要显式选用 rounded-lg（10 px），加载与空态同步。验收结合源码数值与真实截图，不能只凭 class 名称判断，也不修改全局 token 影响浮层或纸张。
- 岗位抽屉的准备简历和投递原件是兄弟组件，分别使用带角色前缀的岗位 key。相同业务 ID 在同层不同组件中不能直接复用；保留切岗位重挂载语义，回归三个页签并查看 React 警告。
- 浏览器验收先确认业务入口处理器。“开始检测”会立即发起真实 AI 请求，不能当作仅打开弹窗。检测、生成、发送、保存和创建等操作使用明确授权的隔离数据；误触后立即说明、终止客户端并核实可见数据，不宣称关闭页面就一定取消服务端或免除模型成本。
- 分开记录实施、验证和用户最终审查。静态检查、真实页面交互、运行中偏好切换和 PDF 导出各自给证据；未覆盖的失败/权限/长内容状态不能用“全部通过”代替。

## 18. 八项视觉反馈返修复盘

来源：[修正规格](superpowers/specs/2026-10-29-visual-feedback-design.md)、[计划](superpowers/plans/2026-10-29-visual-feedback.md)、[验收记录](superpowers/specs/2026-10-29-visual-feedback-acceptance.md)。本轮实现与代码审查已完成，最终验证和用户审查分别记录。

- 首页整页留白：短待办和长动态共用贯穿页面的两列，另一列因此留下大段空白。首页按最近简历、提醒、待办 / 概况、三图表、快捷 / 动态逐行组织，各行自然高度；验收保存桌面与手机整页，不能只看首屏。三提醒使用完整轻容器，继续保留原语义色、数量标签、淡图标和局部渐变。
- 简历类型不清：去除装饰时同时弱化了本地、云端和岗位版本的语义色。类型图标与文字 Badge 联动，岗位版本优先于保存类型，同时显示真实保存位置；验收同屏放入三种合成卡片，覆盖长名称、来源与 320px。
- AI 入口过重：本轮初稿用全幅高饱和渐变强调入口，用户明确否决。后续沿用中性背景、40px 高度、细边框和小紫色图标；悬停 / 聚焦只给短促图标与箭头反馈，不再恢复全幅渐变。验收普通 / 当前页、折叠、手机导航、键盘与减少动效。
- 向导尺寸与文字不同步：标题、正文、页脚分别切换，正文又与外框叠加动画；读取入场缩放后的尺寸还会造成反向变化。步骤内容统一披露，测量布局尺寸，正文保留目标宽度；关闭重开回入口时重置尺寸。验收必须包正式 MotionProvider，逐帧记录可见步骤数、遮罩、宽高和焦点，覆盖两轮开关、退出中重开、步骤反向与运行中减少动效。
- 手机分类撑高：桌面筛选按钮直接换行用于手机，选项增加后占据大量页面。手机每组一行标签与现有 Radix Select，已选值常驻，浮层同时限制固定上限与实际可用高度；验收 12 条以上长选项、滚动、End / Enter、Escape 回焦、加载、失败重试和重置，不能向云端添加测试分类。
- 优化详情两侧空白：独立雷达与可折叠依据绑定外部网格同一行，收起与展开都会相互撑高。评分详情共用折叠状态和自然高度区域，内部紧凑雷达配判断理由，参考内容在下方全宽；摘要使用响应式网格，无报告不重复放空雷达，加载保留紧凑反馈。验收报告 / 无报告 / 旧协议 / 加载、折叠与展开的整页布局，不删除依据或处理操作。
- 星标完成时机：计数器包含数字位的独立 spring，只依据外层计数结束或估算时间，图标可能提前完成。由每位 spring 的真实完成状态聚合触发一次反馈；减少动效直接显示目标值，关闭后不从 0 重播。验收零值、目标更新、反向、运行中减少动效、失败与仓库链接。
- 隔离夹具与证据：只替换数据加载边界，继续渲染真实组件、布局与聚合计算；本地存储使用内存，IndexedDB 使用独立名称，远端请求阻断，写入与模型调用禁止。截图证明布局，逐帧记录证明过程，静态检查证明源码约束，三者不得互相替代；本轮临时 tests 目录完成后删除。

## 19. 首页与手机编辑体验返修复盘

来源：[返修规格](superpowers/specs/2026-10-29-responsive-refinement-design.md)、[计划](superpowers/plans/2026-10-29-responsive-refinement.md)、[验收记录](superpowers/specs/2026-10-29-responsive-refinement-acceptance.md)。实施已授权，完成、验证与最终用户审查分别记录。

- 提醒内容数目不同时，父网格的 items-start 使空态卡比有内容卡短。同排使用拉伸与 h-full，每张右上角保留真实“查看全部”链接；重点关注沿用已支持的 focus=1。验证一条、两条、空态同屏及手机自然高度。
- 统计标签与数字贴两端，让关联信息距离过大；各项统一标题、数字、说明三行，并给缺少说明的项目保留一行空间。简历对象列宽上限 24rem，不能因只有一张简历就铺满整行；骨架与正式网格一致，验收一张、三种类型与 320px。
- 桌面准备简历和评分详情的额外折叠增加操作与空白。准备区直接展示且挂载时开始原资源加载；绑定 Select 保留。优化桌面展示全部依据、维度理由、可读性建议，手机保留原折叠。静态标题替换 AccordionTrigger 时，必须同步维护 Content 的 aria-labelledby，不能引用不存在的 trigger ID。
- 手机按钮局部 size-11、粗指针 min-size 与组间距叠加导致不必要换行；使用当前 36px icon 规格，模式切换内部 32px。390px 下八个工具按钮须在一排，320px 允许合理换行；编辑抽屉操作行不加重复 border-b。验证实际几何而非只看 class。
- 历史手机列表和详情同时交叉淡化，视觉方向不清；使用 CONTENT_SWITCH 先退后进和轻微左右位移。面板常驻、退出先移交焦点，再 inert/aria-hidden；快速反向从当前状态接续，返回保留列表 scrollTop。验收至少两轮、退出中反向、运行中减少动效及宽窄断点。
- AGENTS.md 原本没有“手机禁用动画”条款。明确新增手机也保留自然过渡：优先短时长、transform/opacity 与局部更新，只有系统减少动效偏好按约定降级；不能把窄屏当作减少动效开关。帧采样证明过渡存在和状态正确，不等同于真实手机硬件帧率保证。
- 格式修复只使用仓库 Prettier 与 ESLint layout；Markdown 比较去空白内容，JSON 比较解析值。自动 hook 元数据可能在工具运行后更新时间与缓存，不应误称为业务修改，也不能为清除提示而回滚工具真实状态。

## 20. 编辑器弹窗关闭坍缩复盘

来源：[填写建议与导出退出修复](superpowers/specs/2026-10-29-editor-dialog-exit-acceptance.md)。

- 关闭时正文先变成短加载态、外框仍在退出，会造成高度瞬间坍缩。读取条件与摘要快照应持续到 Dialog 实际卸载，不能仅由 `open` 决定；保留原有身份校验与关闭后的编辑、检查跳转，不用固定高度或估算清理延时掩盖问题。验收逐帧对比退出前后布局高度，覆盖两轮关闭、Escape、退出中重开和手机尺寸。
- 退出途中开启减少动效时，直接改成 `animation: none` 可能令 Radix Presence 无法匹配取消事件，造成正文或遮罩残留。优先保持动画名称、将时长归零，并验证实际卸载和回焦；不能只以 computed duration 为零作为通过依据。

## 21. 操作界面与布局修正复盘

来源：[修正规格](superpowers/specs/2026-10-30-interaction-layout-design.md)、[计划](superpowers/plans/2026-10-30-interaction-layout.md)、[验收记录](superpowers/specs/2026-10-30-interaction-layout-acceptance.md)。

- 阶段节点承担查看记录的动作，不能顺带写入岗位状态。推进、回退、恢复和终态操作使用明确按钮，继续经过原保存与确认入口；验收点击多个节点后真实 store 状态不变，再验证明确动作。已越过但未记录的节点显示勾与中深色，并保留“未记录”说明。
- 长弹层必须限制真实外框，而不是只给内部组件设置宽高。ResponsiveDialog 的宽度用 contentClassName 传到外层；标题与页脚固定，中间容器 min-h-0 并滚动。去掉正文不必要的最小高度，覆盖 320px、400px 短视口、长名称与真实滚轮。表单与文档分区不再重复包多层 Card。
- 取消确认时，打开状态不能兼任展示目标；保留目标、数量和任务结果到退出完成。丢弃岗位版本时，清理 store 会产生 idle，须阻止自动跳步重新生成；删除尚未完成时不允许关闭并切到另一任务。验收慢删除、失败重试、关闭次数和生成调用次数，不调用真实模型制造样本。
- Radix Popper 会在定位前注入 animation 简写；调用方动态设置 animationDuration 或 animationTimingFunction 仍会引发 React 冲突，即使业务没有直接写简写。浮层包装统一把这两个长属性转成 CSS 变量，由 CSS 承接；保留调用值与全局减少动效优先级。复核 Select、Popover、Dropdown、Tooltip 的重复开关和运行中偏好切换，禁止用删除动画名称掩盖警告。
- 程序打开的 Dialog/AlertDialog 不一定具有 Trigger，关闭需要返回实际入口。菜单打开二级确认前先完成菜单退出；确认删除后入口消失时回到稳定的页面动作，不能聚焦退出中、inert 或隐藏节点。验收取消、Escape、确认后删除入口、手机菜单及减少动效。
- 长标题所在 flex 子项要能收缩，关闭按钮保持可见；长名称 Badge 允许换行。手机页签组合现有 Tabs，保留方向键、选中状态及关联面板，不能只手写 tab 角色与点击事件。
- 全站审查同时记录主页面、弹层入口和次级操作。静态清单不等于每条业务链路都已运行；真实组件隔离验收不等于云端与模型验收。滚轮须在浮层完成入场后命中内容，并验证内层滚到底能继续滚动外层；单次延迟采样不足以证明滚动锁故障。

- 首页真实预览复盘（2026-10-30）：模拟纸张图标无法区分内容；改成大比例预览后又挤占首页。最近简历使用已保存快照与对应精确模板的真实第一页缩略图，桌面约 92 × 130px、手机约 68 × 96px，信息与操作在右侧。只为可见的最近两份加载，复用只读渲染并按账户、简历、更新时间重建；不把完整分页扩散到模板目录每张卡片。验收不同模板、现有内容、真实首页桌面/手机、失败重试与减少动效，不能用样例图替换用户简历内容。

- 历史详情手机操作行补充（2026-10-30）：恢复、对比、导出 PDF 和编辑信息在手机显示纯图标，使用现有 Button 的 36px 点击区域，与更多菜单同排；桌面保留图文。读屏名称、Tooltip、加载图标与原动作保留。验收 320 / 390 / 767px 同排且无可见文字，768px 及以上恢复图文，同时检查键盘提示、取消回焦和减少动效。

- 求职漏斗空态补充（2026-10-30）：仅显示“添加岗位”的弱操作行无法解释空白图表。复用 Empty，明确“暂无在办岗位”，说明与添加入口放在同一区域，保持约 140px 的图表高度；加载、错误和有数据的分支保持独立。验收桌面与手机、空态/加载/图表切换及原求职跟进入口。

- 评分建议位置补充（2026-10-30）：可读性建议单独占据全宽，而雷达下方仍留空。评分 2.0 的建议放在左侧雷达和分数列表下，用分隔线划分，避免再次包卡；手机顺排并保留折叠。无报告、旧报告和加载态仍保留建议，页面只挂载一份。验收四种数据状态、宽窄屏几何、折叠两轮与减少动效。此决定替代此前建议独立占据整行的布局。

- 评分图标语义补充（2026-10-30）：判断理由重复使用星光图标，无法表达维度差异。岗位定位、ATS 解析、阅读体验、内容充分度和成果证据分别使用目标、文档检索、书本、清单和增长柱状图；按稳定的维度 key 映射，不依赖列表顺序。验收桌面与手机展开后的五种对应关系，并反转数据顺序复核。
